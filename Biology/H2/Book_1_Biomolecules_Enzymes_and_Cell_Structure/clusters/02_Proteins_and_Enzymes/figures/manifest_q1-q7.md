## Notes

1. **`q4a.png` is a low-resolution photocopy scan.** The 2007 VJC paper itself is not in the archive
   (the `Older papers` folder starts at 2008 and the Prelims tree starts at 2011), so the HCI topical
   bank's embedded bitmap is the only surviving copy. The ribbon model is legible — helices, sheets
   and loops are all distinguishable — but it will not sharpen further. It is the correct figure for
   the correct question, so it is marked CONFIRMED rather than BEST-GUESS; the caveat is image
   quality, not identity.

2. **Provenance discrepancy on `q4a.png`.** The drill sources this to "2007 / **H1** / VJC Prelim /
   P1 Q4". The topical bank's own header reads "2007 / **H2** / VJC PRELIM / P1 Q4". Same paper, same
   question number, same stem and same four options — only the level tag differs, and the topical
   bank is the primary here.

3. **`q3b.png` — the RI year.** The drill note says only "RI Prelim P2 Q1, Fig. 1.2". RI 2023 P2 has
   no PFK question, RI 2024 P2 Q1 Fig. 1.2 is the Anfinsen RNase diagram (that is `q4b.png`), and RI
   2025 P2 Q1 Fig. 1.2 is a Gramicidin A membrane pore. The match is **RI 2018 P2 Q1(b)**, whose
   Fig. 1.2 is the PFK molecule and whose (b)(i) is "Describe the structure of PFK. [4]" — the exact
   stem and mark allocation the drill reproduces. That is consistent with the drill's own citation of
   "Topical 2018/STQ/Q7b(i)", since the 2018 topical collation reprints this same RI question.

4. **`q1b.png` shows eight amino acids, not four.** The drill's bracketed description names only
   valine, leucine, isoleucine and phenylalanine. The real ASRJC figure prints eight (adding alanine,
   proline, methionine and tryptophan). The full original figure is kept, since the extra structures
   are part of what the question gives the candidate.

5. **`q3b.png` retains the "Catalytic sites" and "Allosteric sites" annotations.** They are printed on
   the original RI figure, so they stay. Worth knowing that they hand over part of a "describe the
   structure of PFK" answer.
