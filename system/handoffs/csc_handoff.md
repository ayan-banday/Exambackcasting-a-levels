**How CSC is studied — the declarative 5-step method (NOT procedural clusters).** Examiners reward matching
their topic sentences and repeated key points, not originality. So we study straight off the model answers:

1. **Pre-study → Layer 1** (10–20 min): the main arguments of the chapter. Don't skim.
2. **ONE bare-bones Layer-2 cluster** (~20 min, ~20 pages): the sub-arguments under each main argument.
   End state = I'd score 10–20% and think "I could bullshit a rough answer," not "I can answer this well."
3. **Pull the highest-leverage questions** for the chapter — widest coverage for fewest questions.
4. **I attempt each on Wispr Flow (voice)** saying my reasoning, no looking up — then you **hypercorrect**
   against the model answers (their exact examples, words, topic sentences, and WHY each earns marks).
5. **Encode** by understanding why each point matters until I'm 80–90% confident, then next question.
   Shortcut: if I already half-know a topic, we skip straight to step 3 — don't restart.
