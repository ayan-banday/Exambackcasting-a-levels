1Domain, range, and the one-one test
Definitions and notation
\(D_f\) is the set of inputs, \(R_f\) the set of outputs. A function must give exactly one output per input.

\(f^{-1}\) exists \(\iff\) \(f\) is one-one \(\iff\) every horizontal line \(y=k\) cuts the graph at most once. That sentence, with the words “horizontal line” and “at most once”, is what earns the mark.

To find a range: sketch the graph over the stated domain and read off the \(y\)-values. Do not guess it from the formula.
Example
\(f(x)=\ln\!\big((x+1)^2\big)+2\) for \(x\ge 0\). Show that \(f^{-1}\) exists.

For \(x\ge 0\), \(x+1\ge 1>0\), so \((x+1)^2\) is strictly increasing on this domain, and \(\ln\) is strictly increasing, so \(f\) is strictly increasing.
A strictly increasing function is one-one, so any horizontal line meets \(y=f(x)\) at most once. Hence \(f^{-1}\) exists.

(Without the restriction \(x\ge0\), \((x+1)^2\) is symmetric about \(x=-1\) and \(f\) would not be one-one.)
Trap Writing “\(f\) is one-one because it passes the vertical line test”. The vertical line test only says it is a function at all. The horizontal line test is the one-one test.
Practice — do this before revealing
The function \(f\) is defined by \(f:x\mapsto \dfrac{ax-3}{5x-4}\) for \(x\in\mathbb{R}\), \(x\ne\dfrac45\), where \(a\in\mathbb{R}\). Find \(f^{-1}(x)\) and state its domain, and find the value of \(a\) for which \(f\) is self-inverse.
Built on HCI 2025 Prelim Paper 1 Q8
Let \(y=\dfrac{ax-3}{5x-4}\). Then \(y(5x-4)=ax-3\Rightarrow 5xy-ax=4y-3\Rightarrow x(5y-a)=4y-3\).
\(x=\dfrac{4y-3}{5y-a}\), so \(\boxed{f^{-1}(x)=\dfrac{4x-3}{5x-a}}\).

Domain of \(f^{-1}=R_f\). As \(x\to\pm\infty\), \(f(x)\to\dfrac{a}{5}\), and \(y=\dfrac a5\) is a horizontal asymptote never attained, so \(R_f=\mathbb{R}\setminus\left\{\dfrac a5\right\}\). Hence \(D_{f^{-1}}=\mathbb{R},\ x\ne\dfrac a5\).

Self-inverse means \(f=f^{-1}\), i.e. \(\dfrac{ax-3}{5x-4}=\dfrac{4x-3}{5x-a}\) for all valid \(x\). Comparing, \(a=4\).
Check: with \(a=4\), \(f(x)=\dfrac{4x-3}{5x-4}\) and \(f^{-1}(x)=\dfrac{4x-3}{5x-4}\). Identical, so \(a=4\).
2Finding the inverse — and its domain and range
The four-step procedure
1. Set \(y=f(x)\) and make \(x\) the subject.
2. Swap the letters to write \(f^{-1}(x)\).
3. \(D_{f^{-1}}=R_f\) — always. This is the step people drop, and it is usually its own mark.
4. \(R_{f^{-1}}=D_f\).

If step 1 gives a \(\pm\), the original domain tells you which sign to keep.
Domain restriction to create an inverse
If \(f\) is not one-one, restrict the domain to the largest interval on which it is. For a parabola with vertex at \(x=h\), take \(x\ge h\) (or \(x\le h\)) — and say why: on that interval \(f\) is strictly increasing (or decreasing), so it is one-one.
Example
\(f(x)=e^{2x}-4\), \(x\in\mathbb{R}\). Find \(f^{-1}\) and its domain.

\(y=e^{2x}-4\Rightarrow e^{2x}=y+4\Rightarrow 2x=\ln(y+4)\Rightarrow x=\tfrac12\ln(y+4)\).
So \(f^{-1}(x)=\tfrac12\ln(x+4)\).
\(R_f\): \(e^{2x}>0\) for all real \(x\), so \(f(x)>-4\), giving \(R_f=(-4,\infty)\).
Therefore \(D_{f^{-1}}=(-4,\infty)\).
Trap Giving \(f^{-1}\) without its domain. It is a separate mark on nearly every paper, and \(D_{f^{-1}}=R_f\) requires you to have actually found \(R_f\) — which usually means sketching \(f\).
Practice — do this before revealing
The function \(f\) is defined by \(f:x\mapsto \dfrac{1}{x-2}\), \(x\in\mathbb{R}\), \(x\ne 2\). Find \(f^{-1}\) in a similar form, and state the value of \(x\) for which \(f(x)=f^{-1}(x)\).
Built on HCI 2021 Prelim Paper 1 Q8
\(y=\dfrac{1}{x-2}\Rightarrow x-2=\dfrac1y\Rightarrow x=\dfrac1y+2\).
\(\boxed{f^{-1}:x\mapsto \dfrac1x+2,\ x\in\mathbb{R},\ x\ne 0}\) — the exclusion is \(x\ne0\) because \(R_f=\mathbb{R}\setminus\{0\}\).

Where \(f=f^{-1}\): \(\dfrac{1}{x-2}=\dfrac1x+2=\dfrac{1+2x}{x}\).
Cross-multiplying: \(x=(1+2x)(x-2)=2x^2-3x-2\Rightarrow 2x^2-4x-2=0\Rightarrow x^2-2x-1=0\).
\(x=1\pm\sqrt2\). Both are valid (neither is \(0\) or \(2\)).

Shortcut worth knowing: solutions of \(f(x)=f^{-1}(x)\) that lie on \(y=x\) can be found from \(f(x)=x\) instead, which is usually far quicker. Here \(\dfrac{1}{x-2}=x\) gives the same quadratic.
3Composite functions
Existence and construction
\(fg\) means “do \(g\) first, then \(f\)”.

\(fg\) exists \(\iff R_g\subseteq D_f\). Learn it in that order — the range of the inner must fit inside the domain of the outer.

If it exists: \(D_{fg}=D_g\), and to get \(R_{fg}\), push the domain through in two stages: \(D_g\to R_g\to R_{fg}\), reading each range off a sketch.

To show \(fg\) does not exist, state \(R_g\), state \(D_f\), and name one element of \(R_g\) outside \(D_f\).
Iterated functions
\(f^2=ff\), \(f^3=fff\). If \(f^2=x\) then \(f\) is self-inverse and the pattern has period 2: \(f^{\text{even}}(x)=x\), \(f^{\text{odd}}=f\).
If \(f^3=x\), the period is 3 — reduce the exponent mod 3. Exam questions like \(f^{2030}\) are always solved this way, never by brute force.
Example
\(f:x\mapsto\dfrac{1}{x-3}\), \(x\ne3\); \(g:x\mapsto x^2\), \(x\in\mathbb{R}\). Only one of \(fg\), \(gf\) exists. Which, and why?

\(R_g=[0,\infty)\) and \(D_f=\mathbb{R}\setminus\{3\}\). Since \(3\in R_g\) but \(3\notin D_f\), \(R_g\not\subseteq D_f\), so \(fg\) does not exist.

\(R_f=\mathbb{R}\setminus\{0\}\) and \(D_g=\mathbb{R}\). Since \(R_f\subseteq D_g\), \(gf\) exists:
\(gf(x)=g\!\left(\dfrac{1}{x-3}\right)=\dfrac{1}{(x-3)^2}\), with \(D_{gf}=D_f=\mathbb{R}\setminus\{3\}\).
Trap Two things. Order: \(fg\) applies \(g\) first — reading left to right is wrong. Domain of the composite: it is \(D_g\), the domain of the inner function, not \(D_f\) and not the intersection.

Also note the syllabus excludes restricting a domain in order to make a composite exist — if a composite does not exist, say so and stop.
Practice — do this before revealing
The function \(f\) is defined by \(f(x)=\dfrac{1}{1-x}\) for \(x\in\mathbb{R}\), \(x\ne1\), \(x\ne0\). Show that \(f^2(x)=f^{-1}(x)\), and hence find \(f^{3}(x)\) and \(f^{2030}(x)\) in simplified form.
Iterated-function pattern; the same device HCI used in a 2025 prelim (\(f^{2030}\))
\(f^2\): \(f\!\left(\dfrac{1}{1-x}\right)=\dfrac{1}{1-\frac{1}{1-x}}=\dfrac{1-x}{(1-x)-1}=\dfrac{1-x}{-x}=\dfrac{x-1}{x}\).

\(f^{-1}\): \(y=\dfrac{1}{1-x}\Rightarrow 1-x=\dfrac1y\Rightarrow x=1-\dfrac1y=\dfrac{y-1}{y}\), so \(f^{-1}(x)=\dfrac{x-1}{x}\).
Rules match and both have domain \(\mathbb{R}\setminus\{0,1\}\), so \(f^2=f^{-1}\). Shown.

\(f^3\): \(f^3=f\!\circ\! f^2=f\circ f^{-1}=x\). So \(f^3(x)=x\) — the function has period 3.

\(f^{2030}\): \(2030=3(676)+2\), so \(f^{2030}=f^{2}\), giving \(\dfrac{x-1}{x}\).
4The graph of \(f^{-1}\), and where \(f\) meets \(f^{-1}\)
Reflection in y = x
The graph of \(y=f^{-1}(x)\) is the reflection of \(y=f(x)\) in the line \(y=x\). Everything swaps:
• a point \((a,b)\) on \(f\) becomes \((b,a)\) on \(f^{-1}\);
• a vertical asymptote \(x=k\) becomes a horizontal asymptote \(y=k\);
• the domain and range swap.

Intersections. If \(f\) is increasing, every solution of \(f(x)=f^{-1}(x)\) lies on \(y=x\), so solve the much easier \(f(x)=x\). If \(f\) is decreasing, there can be solutions off the line \(y=x\) as well — then you must solve \(f(x)=f^{-1}(x)\) directly.
Example
\(f(x)=\sqrt{x-1}\), \(x\ge1\). Sketch \(f\) and \(f^{-1}\) on the same axes and find where they meet.

\(f\) is increasing, so intersections lie on \(y=x\): solve \(\sqrt{x-1}=x\Rightarrow x-1=x^2\Rightarrow x^2-x+1=0\).
Discriminant \(=1-4=-3<0\), so there is no intersection at all — the two curves are reflections that never meet.
\(f^{-1}(x)=x^2+1\) with \(D_{f^{-1}}=R_f=[0,\infty)\).
Trap Assuming \(f\) and \(f^{-1}\) always intersect on \(y=x\), or always intersect at all. Check whether \(f\) is increasing before using the shortcut, and check the discriminant before claiming a solution exists.
