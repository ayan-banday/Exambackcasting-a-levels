What tripped you up last session — read once before you start:
  • "Why can you set z = 0?" A plane∩plane line is infinite. Fixing one coordinate (say \(z=0\)) just picks the single point where the line crosses the \(z=0\) plane. Any consistent choice gives a valid point on the same line — you only need one. (If the line happens to be parallel to \(z=0\), that choice fails and you pick a different variable to fix.)
  • Foot of perpendicular — line vs plane are different. To a plane: \(F = P + t\mathbf n\), sub \(F\) into the plane, solve \(t\). To a line: \(F = \mathbf a + \lambda\mathbf d\), impose \(\overrightarrow{PF}\cdot\mathbf d = 0\), solve \(\lambda\).
  • Plane normal from 3 points: use two vectors from the same point — \(\mathbf n = \overrightarrow{AB}\times\overrightarrow{AC}\) (not \(\overrightarrow{AB}\times\overrightarrow{BC}\)). Check it by dotting with a plane direction — should be 0.

Question 1

Question
The points \(A(2,0,1)\) and \(B(-1,3,4)\) are given.
(a) The point \(P\) divides \(AB\) such that \(AP:PB = 1:2\). Find \(\overrightarrow{OP}\). [2]
(b) The plane \(p\) passes through \(P\) and is perpendicular to \(AB\). Find its Cartesian equation. [3]
(c) Find the exact distance from \(A\) to \(p\), and explain why it equals \(|AP|\). [3]
Solution
(a) Ratio theorem
\(AP:PB = \lambda:\mu = 1:2\); the weight goes with the OPPOSITE endpoint, so \(\overrightarrow{OP} = \dfrac{\mu\mathbf a + \lambda\mathbf b}{\lambda+\mu} = \dfrac{2\mathbf a + \mathbf b}{3}\). M1 A1
\[ \overrightarrow{OP} = \tfrac{1}{3}\!\left(2\begin{pmatrix}2\\0\\1\end{pmatrix}+\begin{pmatrix}-1\\3\\4\end{pmatrix}\right) = \begin{pmatrix}1\\1\\2\end{pmatrix} \]
(b) Plane through P, normal = AB
Perpendicular to \(AB\) means the plane's normal is \(\overrightarrow{AB} = \mathbf b - \mathbf a = (-3,3,3) \parallel (1,-1,-1)\). Fit \(d = \mathbf n\cdot\overrightarrow{OP}\). M1 normal, M1 d, A1
\( d = (1)(1)+(-1)(1)+(-1)(2) = -2 \Rightarrow \) plane \( x - y - z = -2 \).
(c) Distance A → plane
Formula \(\dfrac{|\mathbf a\cdot\mathbf n - d|}{|\mathbf n|}\): \(\mathbf a = A(2,0,1)\); \(\mathbf n=(1,-1,-1)\); \(d=-2\); \(|\mathbf n|=\sqrt3\). M1 A1
\( \dfrac{|(2)(1)+(0)(-1)+(1)(-1)-(-2)|}{\sqrt3} = \dfrac{|2-1+2|}{\sqrt3} = \dfrac{3}{\sqrt3} = \sqrt3 \).
It equals \(|AP|\) because \(AB \perp p\) and \(P\in p\), so the foot of the perpendicular from \(A\) to \(p\) is \(P\); the distance is just \(|AP| = |\overrightarrow{OP}-\mathbf a| = |(-1,1,1)| = \sqrt3\). A1
Fused: ratio theorem (C1) → plane from a point + normal (C2) → point-plane distance (C2), tied together by the geometry that a perpendicular plane makes \(P\) the foot.

Question 2

Question
The points \(A(1,1,0)\), \(B(3,1,2)\), \(C(2,0,1)\) are given.
(a) Find the exact area of triangle \(ABC\). [3]
(b) Find a unit vector normal to the plane \(ABC\). [2]
(c) Find the Cartesian equation of plane \(ABC\), and hence the point where the line \(\mathbf r = \begin{pmatrix}2\\0\\0\end{pmatrix}+t\begin{pmatrix}0\\1\\1\end{pmatrix}\) meets it. [4]
Solution
(a) Area via the cross product
\(\overrightarrow{AB}=(2,0,2)\), \(\overrightarrow{AC}=(1,-1,1)\); area \(=\tfrac12|\overrightarrow{AB}\times\overrightarrow{AC}|\). M1 cross, M1, A1
\( \overrightarrow{AB}\times\overrightarrow{AC} = (2,0,-2) \Rightarrow \text{area} = \tfrac12\sqrt{4+0+4} = \tfrac12\cdot 2\sqrt2 = \sqrt2 \).
(b) Unit normal
The cross product is normal to the plane; divide by its magnitude. M1 A1
\( \hat{\mathbf n} = \dfrac{(2,0,-2)}{2\sqrt2} = \dfrac{1}{\sqrt2}(1,0,-1) \).
(c) Plane, then line ∩ plane
Use \(\mathbf n=(1,0,-1)\) through \(A(1,1,0)\): \(d = 1-0 = 1\), so \(x - z = 1\). Sub the line \((2, t, t)\). M1 plane, M1 sub, A1 t, A1 point
\( (2) - (t) = 1 \Rightarrow t = 1 \Rightarrow \) point \((2,1,1)\).
Fused: cross-product area + unit normal (C1) → plane equation → line∩plane (C2). The same cross product gives the area AND the plane's normal.

Question 3

Question
Lines \(l_1:\ \mathbf r = \begin{pmatrix}1\\0\\0\end{pmatrix}+\lambda\begin{pmatrix}1\\1\\0\end{pmatrix}\) and \(l_2:\ \mathbf r = \begin{pmatrix}2\\0\\1\end{pmatrix}+\mu\begin{pmatrix}0\\1\\1\end{pmatrix}\).
(a) Show that \(l_1\) and \(l_2\) are skew. [4]
(b) Find the acute angle between them. [2]
(c) Find the exact shortest distance between them. [4]
Solution
(a) Not parallel, then no intersection
Directions \((1,1,0)\), \((0,1,1)\) not proportional → not parallel. Equate components. B1, M1, M1, A1
\(x:\ 1+\lambda = 2 \Rightarrow \lambda = 1\); \(z:\ 0 = 1+\mu \Rightarrow \mu = -1\); \(y:\ \lambda = \mu\) needs \(1 = -1\) — false → inconsistent → no common point → skew.
(b) Angle between lines (cos, directions)
\(\mathbf d_1\cdot\mathbf d_2 = 0+1+0 = 1\); \(|\mathbf d_1| = |\mathbf d_2| = \sqrt2\). M1 A1
\( \cos\theta = \dfrac{1}{2} \Rightarrow \theta = 60^\circ \).
(c) Shortest distance (cross product)
\(\mathbf d_1\times\mathbf d_2 = (1,-1,1)\), \(|\cdot|=\sqrt3\); \(\mathbf a_2-\mathbf a_1 = (1,0,1)\). M1 M1 A1
\( d = \dfrac{|(1)(1)+(0)(-1)+(1)(1)|}{\sqrt3} = \dfrac{2}{\sqrt3} = \dfrac{2\sqrt3}{3} \). A1
Watch: the angle uses \(\cos\) with the directions; the shortest distance uses the cross product \(\mathbf d_1\times\mathbf d_2\). Different tools on the same pair of lines.

Question 4

Question
The point \(P(3,2,1)\) and the plane \(p:\ 2x - y + 2z = 4\).
(a) Find the foot of the perpendicular \(F\) from \(P\) to \(p\). [4]
(b) Find the exact shortest distance from \(P\) to \(p\). [2]
(c) Find the reflection of \(P\) in \(p\). [2]
Solution
(a) Foot — walk from P along the normal
Plane method: \(F = P + t\mathbf n\), then sub into the plane. \(\mathbf n = (2,-1,2)\). M1 M1 M1 A1
\(F = (3+2t,\,2-t,\,1+2t)\). Sub: \(2(3+2t)-(2-t)+2(1+2t) = 6+9t = 4 \Rightarrow t = -\tfrac29\).
\( F = \tfrac19(23,\,20,\,5) \).
(b) Distance
\(|PF| = |t|\,|\mathbf n| = \tfrac29\cdot 3\). M1 A1
\( = \tfrac{6}{9} = \tfrac23 \).
(c) Reflection
\(P' = 2F - P\), since \(F\) is the midpoint of \(PP'\). M1 A1
\( P' = 2\cdot\tfrac19(23,20,5) - (3,2,1) = \tfrac19(46,40,10) - \tfrac19(27,18,9) = \tfrac19(19,\,22,\,1) \).
This is the PLANE foot method (sub \(F\) into the plane). Contrast with Question 5, which is the LINE foot method (dot with the direction). Keep them straight.

Question 5

Question
The line \(l:\ \mathbf r = \begin{pmatrix}1\\2\\3\end{pmatrix}+\lambda\begin{pmatrix}2\\-1\\2\end{pmatrix}\) and the point \(P(1,0,1)\).
(a) Find the foot of the perpendicular \(F\) from \(P\) to \(l\). [4]
(b) Find the exact shortest distance from \(P\) to \(l\). [2]
(c) Find the reflection of \(P\) in the line \(l\). [2]
Solution
(a) Foot — general point on the line
Line method: \(F = \mathbf a + \lambda\mathbf d\) on the line, then impose \(\overrightarrow{PF}\cdot\mathbf d = 0\) (NOT sub into anything). M1 M1 M1 A1
\(F=(1+2\lambda,\,2-\lambda,\,3+2\lambda)\), \(\overrightarrow{PF}=(2\lambda,\,2-\lambda,\,2+2\lambda)\).
\(\overrightarrow{PF}\cdot\mathbf d = 2(2\lambda)-(2-\lambda)+2(2+2\lambda) = 9\lambda+2 = 0 \Rightarrow \lambda = -\tfrac29\).
\( F = \tfrac19(5,\,20,\,23) \).
(b) Distance
\(|PF| = |\overrightarrow{PF}|\), with \(\overrightarrow{PF} = \tfrac19(-4,20,14)\). M1 A1
\( |PF| = \tfrac19\sqrt{16+400+196} = \tfrac19\sqrt{612} = \tfrac{6\sqrt{17}}{9} = \dfrac{2\sqrt{17}}{3} \).
(c) Reflection
\(P' = 2F - P\), same rule as reflecting in a plane. M1 A1
\( P' = 2\cdot\tfrac19(5,20,23) - (1,0,1) = \tfrac19(1,\,40,\,37) \).
Line foot vs plane foot: here you impose \(\overrightarrow{PF}\cdot\mathbf d = 0\) (the point is ON the line, perpendicular to its direction). In Q4 you substituted \(F\) into the plane equation. That is the whole distinction.

Question 6

Question
The planes \(p_1:\ x + 2y - z = 3\) and \(p_2:\ 2x - y + z = 1\).
(a) Find a vector equation of their line of intersection \(l\). [4]
(b) Find the acute angle between \(p_1\) and \(p_2\). [3]
(c) Find the point where \(l\) meets the plane \(y = 0\). [2]
Solution
(a) Direction, then ONE point
Line lies in both planes, so direction \(= \mathbf n_1\times\mathbf n_2\). For a point, fix one coordinate — set \(z=0\) (this picks the point where \(l\) crosses the \(z=0\) plane) and solve the pair. M1 A1 direction, M1 point, A1
\( \mathbf n_1\times\mathbf n_2 = (1,2,-1)\times(2,-1,1) = (1,\,-3,\,-5) \).
Set \(z=0\): \(x+2y=3,\ 2x-y=1 \Rightarrow x=1,\ y=1\). Point \((1,1,0)\).
\( l:\ \mathbf r = \begin{pmatrix}1\\1\\0\end{pmatrix} + t\begin{pmatrix}1\\-3\\-5\end{pmatrix} \).
(b) Angle between planes (normals, cos)
\(\mathbf n_1\cdot\mathbf n_2 = 2-2-1 = -1\); \(|\mathbf n_1| = |\mathbf n_2| = \sqrt6\). M1 A1
\( \cos\theta = \dfrac{|-1|}{6} = \dfrac16 \Rightarrow \theta = 80.4^\circ \). A1
(c) Where l meets y = 0
The \(y\)-coordinate of \(l\) is \(1-3t\); set it to 0. M1 A1
\( 1-3t = 0 \Rightarrow t = \tfrac13 \Rightarrow \mathbf r = \left(\tfrac43,\,0,\,-\tfrac53\right) \).
The z=0 point: you're not "assuming z=0 everywhere" — you're choosing the one point of the infinite line that sits on the \(z=0\) plane. Any valid choice gives a point on the same line; you only need one to anchor it.
