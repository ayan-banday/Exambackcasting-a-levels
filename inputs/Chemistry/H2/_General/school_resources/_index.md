## Headline calibration rules (top 5)

1. **Lock paper structure (9729):** P1 (30 MCQ × 1m × 1h), P2 (5 Qs × 75m × 2h), P3 (Sec A 3 × ~20m + Sec B 1-of-2 × 20m = 80m × 2h), P4 (55m × 2.5h). NEVER use 9647 format (40 MCQ, 4-of-5 P3 choice, standalone Planning Q in P2).

2. **P3 Section A architecture is locked:** Q1 = Physical integrated industrial (gas + thermo + kinetics), Q2 = Equilibrium + Transition Element, Q3 = Organic synthesis + structure elucidation. Section B = Inorganic-heavy deduction OR Organic compound deduction puzzle (1-of-2 choice).

3. **Reagent/condition specificity is non-negotiable:** Cambridge expects exact wording — "LiAlH₄ in dry ether," "K₂Cr₂O₇/H₂SO₄, heat under reflux," "Sn + conc. HCl, then NaOH(aq)," "NaBH₄ in methanol." Never use generic "reducing agent." The 28-row reagent/condition table in the master reference is the canonical list.

4. **Mark allocations are formula-driven:** 1 mark per curly arrow, "state and explain" = 2m, energy cycle = 3-5m, structure elucidation = 5-7m, mechanism 4-6m, calculation 2-4m (working + answer). 3 sig figs + units mandatory.

5. **Topic mix is fixed per paper:** P1 = ~12 Physical + ~6 Inorganic + ~12 Organic. 6-8 multi-statement (I-IV) traps per P1. Data Booklet referenced 5-7 times per paper. All 3 super-clusters always touched.
