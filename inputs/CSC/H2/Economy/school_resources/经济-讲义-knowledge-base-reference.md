### 2. 梁: 第1课题第1讲 从出口导向到扩大内需 (J2 复习版) — the master document
- **Teacher / Source:** 梁勇
- **Lecture position:** J2 第1讲 复习讲义 (25 pages, dense text — single most useful PDF for 课题一)
- **Sub-topic:** 出口导向型经济 + 扩大内需 (双循环) — combines J1 L2 + new 内需 framing
- **Key concepts defined:**
  - **出口导向型经济**: 外向型经济 with international market as orientation, 比较优势 driven, labour-intensive
  - **内需**: 内部需求总量 = 居民/企业/政府的消费 + 投资需求
  - **三驾马车**: 投资 + 消费 + 出口 (the 3 demand-side pillars of GDP)
  - **双循环**: "国内大循环为主体、国内国际双循环相互促进" (2020-05-14, 中共首次提出)
  - **中等技术陷阱**: 已脱低端但向高端突破困难, 锁定在全球价值链中端 (微笑曲线中段)
- **Core mechanism:** 全球化红利递减 + 中美博弈 + 人口红利消失 → 出口导向不可持续 → 扩大内需成为必然. 内需扩大 = 提升消费 (居民) + 有效投资 ("两新一重") + 城镇化. 政策本质 = "短期靠投资托底, 长期靠收入与制度改革提升消费"
- **Specific data/cases:**
  - 1978 中国出口总额 97.5亿美元 → 2025 出口 3.77万亿美元
  - 1978 GDP 1495亿美元 (世界排名 11位, 占世界经济总量 1.7%) → 2025 GDP 19.63万亿美元 (占全球比重 20%, 第二大经济体)
  - 中国占世界经济增长贡献率 ~30%
  - 制造业增加值: 2010 首次超越美国 → 连续 16 年世界第一 (2025 年 = 美+日+德三国总和)
  - "新三样" = 新能源汽车 + 锂离子电池 + 光伏产品 (出口结构升级标志)
  - 城镇化率 1978: ~17.9% → 2025: 67.89%
  - 改革开放后 ~2.9亿农村劳动力转移到珠三角/长三角
  - 2008年 "四万亿投资计划" (铁公基)
  - "两新一重" = 新型基础设施 + 新型城镇化 + 交通水利重大工程
  - 中产阶级已超 4 亿人, 是扩大消费的主力军
  - 2026 年 4月 7-8日 中国召开首次全国服务业大会
  - 2025 年服务业增加值突破 80 万亿元, 占 GDP 57.7%, 对增长贡献率超 60%
  - 2025 年三驾马车贡献率: 消费 52.0% / 投资 15.3% / 出口 32.7%
  - 2024 年中国 60+ 人口 3.1 亿 (22%), 65+ 占 15.6% (中度老龄化)
  - 城镇化率每提高 1 个百分点 → 拉动最终消费增长约 1.6%, 居民消费总额 + 1200 亿元
  - 城镇化每递增 1%, GDP 增长 1.5%, 可替代出口 10 万亿元
  - 城市居民人均能源消费量 ~ 农村的 3.5-4 倍
  - 环境损失 GDP 高达 6% (健康损失贡献 1/4)
- **Cross-课题 connections:** 中美贸易战 (外交), 城镇化→户籍改革 (社会), 中产阶级 (社会), 央地关系 (政治-投资驱动地方GDP锦标赛)
- **Maps to 集锦 questions:** Q2 三驾马车, Q3 出口依赖, Q4 扩大内需, Q5 区域不平衡 (city-village gap), foundational for Q11 绿色发展 (内需→产业升级)
- **High-leverage vocabulary:** 三驾马车 / 双循环 / 压舱石 / 没钱花·不敢花·有钱无处花 / 雷声大雨点小 / 收入分配"一次分配不公平, 二次分配不到位" / 微笑曲线 / "卡脖子" / 三高一低 (高投入·高消耗·高排放·低效益) / 内卷 / 边际效益递减 / 韧性优先 / BANI时代 (脆弱·焦虑·非线性·难以理解)

### 5. 梁: 第1课题第2讲 国企改革 (J2 复习版) + J1 第4讲
- **Teacher / Source:** 梁勇
- **Lecture position:** J2 复习 第2讲 (26 pages, fully read) + J1 第4讲 (slide companion)
- **Sub-topic:** 国企改革
- **Key concepts:**
  - **国有企业**: 国家出资+控股的企业, 国有资产占 GDP ~60%, 国企总营收占 GDP ~70%
  - **国企双重性**: "企业性" (营利) + "公益性" (公共服务) → 三大职能 = 增进经济效益 / 社会效益 / 维护国家安全
  - **预算软约束**: 国企亏损时政府输血 (追加投资/减税/财政补贴/银行贷款)
  - **政策性负担**: 战略性 (重工业偏好) + 社会性 (冗员/福利) — 林毅夫框架
  - **混合所有制**: 国资+民资+外资交叉持股
  - **国进民退 / 国退民进 / 国民共进**
- **Core mechanism (历程):**
  1. 1978-1992 放权让利 (两权分离) — 引入市场机制但承包制有短期化弊端
  2. 1993-2003 朱镕基 攻坚脱困 — 建现代企业制度+抓大放小+下岗潮
  3. 2003-2012 胡温 国资委体制 (2003 成立) — "管资产+管人+管事" 三结合, 央企从 196 家减到 117 家. 2008 四万亿大部分流向国企 → 国进民退
  4. 2013- 习近平: 混改 + 党的领导 + 防国资流失. 提"两个一以贯之"+"三个有利于". 2015《关于深化国企改革的指导意见》分类改革 (商业类/公益类/功能类). 2024 二十届三中全会"完善管理监督体制机制"
- **Specific data:** 2018 国企营收/利润年均增长 11.9%/10.3%; 2018 国资总额是 1978 年的 247.1 倍; 2025 国企营收 ~84.89 万亿元, 利润 4.038 万亿. 央企资产突破 95 万亿. 央企在 "一带一路" 沿线项目超 3400 个. 中国国资总权益 36198 亿美元 (远超法德英意美等), 占 GDP 44.0%. 2018 财富 500 强中国上榜超 20%, 央企国企占 8 成. 国资委监管体系演进: 十八届三中(2013)→十九大(2017)→十九届五中(2020)→2022 中央经济工作会议→2024 二十届三中.
- **Cases/examples (国企垄断五类行业):** 全国性自然垄断 (电信/电力/民航/邮政/铁路/石油); 区域性公用事业 (供水/热力/燃气/公共交通/港口/垃圾处理); 行政垄断转事业单位 (有线电视/医院); 行政垄断竞争行业 (机车制造/核工业/航空工业); 特种行业 (造币/烟草/食盐/医药/能源/资源)
- **Cross-课题 connections:** 法治 (产权制度改革), 党管企业 (政治), 一带一路 (外交), 央地关系 (地方GDP锦标赛 1994)
- **Maps to 集锦:** Q9 国企改革
- **Vocabulary:** 共和国的长子, 大而不强, 抓大放小, 简政放权, 政企分开, 现代企业制度, "做强做优做大", "管资本为主", 铁饭碗·铁交椅·铁工资

### 6. 梁: 第1课题第3讲 复习讲义 扩大科技开放 (J2) + J1 第5讲 科技开放与可持续发展
- **Teacher / Source:** 梁勇
- **Lecture position:** J2 第3讲 复习 (27 pages, fully read) + J1 第5讲 (slide deck, intro samples read)
- **Sub-topic:** 扩大科技开放
- **Key concepts:**
  - **中国四大优势** (集中力量办大事+超大规模市场+完整产业体系+丰富人才资源)
  - **传统产业 / 新兴产业 / 未来产业** — 三层产业结构
  - **实体经济三维升级**: 高端化 (向价值链高端迈进) + 智能化 (数字经济与实体融合) + 绿色化 (双碳)
  - **创新** (熊彼特 Schumpeter "生产要素的重新组合"): 增量/邻近/破坏性/激进4类型
  - **全要素生产率 (TFP)** 提高的两路径: 技术创新 + 改善要素配置效率
  - **新质生产力**: 科技创新主导, 高科技+高效能+高质量
  - **科技开放 / 自主创新 / 技术溢出效应**
  - **引进来 vs 走出去**: 双轮驱动 (前者解决"有没有", 后者解决"强不强")
  - **国家创新体系** + **创新全球化** + **小院高墙**
- **Core mechanism:** 改革开放→以"市场换技术"→"引进-消化-吸收-再创新"→自主创新. 中国正从全球价值链中低端向"中国智造"高端攀升. 美国"小院高墙"+技术封锁→倒逼自主创新, 但要避免闭门造车.
- **Specific data:**
  - 2022 R&D 经费投入 3.09 万亿元 (世界第二, 全球创新指数从 2012 年第 34 名升至 2022 年第 11 名)
  - "78 计划" 1978 年 78 亿美元成套技术引进 ("洋跃进")
  - 1984 年上海大众 (中德首家合资) — 最早通过消化吸收先进技术取得竞争优势
  - 1985《关于科学技术体制改革的决定》"经济建设必须依靠科学技术, 科学技术工作必须面向经济建设" (面向·依靠)
  - 1995 年 科教兴国战略
  - 2006 自主创新战略+建设创新型国家
  - 2008 千人计划; 1994 百人计划; 1998 长江学者+985计划; 2012 海外高层次人才引进
  - 2014 习近平"加快建设健全国家创新体系"
  - 2016《国家技术转移体系建设方案》(2017 国务院发布)
  - 2017《国家技术转移体系建设方案》
  - 2021 习近平"设立面向全球的科学研究基金"
  - 中国与 160+ 国家和地区建科技合作关系, 加入 200+ 多边机制

- **Specific data:**
  - 2008 联合国环境署绿色经济和绿色新政倡议
