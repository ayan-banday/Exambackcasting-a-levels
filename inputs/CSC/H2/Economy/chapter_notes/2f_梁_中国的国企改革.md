- HO/LV (银行债务 + 国企改革）
    1. 在防范系统性金融风险的过程中，银行不良债务治理与国企改革哪个更具决定性作用？如果只改革其中一方，中国经济能否实现长期稳定？
        1. 银行不良债务
            1. 去杠杆 （供给侧改革）- 不让地方政府利用大笔贷款建基础设施 （刺激经济）
            2. 提高监管
                1. 6+4+2万亿地方化债 （暗债 - 明债）
                2. 一行一局一会
        2. 国企改革
            1. 抓大放小 （战略性企业 - 新基建；军事；绿发展）
                1. 政府将资金投入战略性企业 
            2. 混合所有制 （产权）
    2. 国企“软预算约束”往往加剧银行不良贷款积累。相比通过银行加强风险管理与通过深化国企产权改革，哪一种更能有效切断债务恶性循环？
        1. 监管 （6+4+2/一行一局一会） → 结构性失衡下降 → 银行领导人不会再包庇政府/地方人员 → 隐性担保下降 → 不会轻易借给国企/地方政府 →信贷不会锁定在这些部门 =  资源错配下降 →  银行不良贷款下降 →银行资产负债压力减轻 - 更多资金借给高回报的企业 → 风险-收益逻辑被强化，道德风险削弱 - 除掉银行向国企借钱而积累债务的风险 →有效切断债务恶性循环
            1. 短期方法 
        2. 混合所有制改革 → 民营企业/外资产权 → 政府不再一股独大- 隐性担保逐渐消失 - 预算软约束僵化 - - 无法依赖政府兜底 - 迫使僵尸企业下台 - 整体国企效率上升 - 必须与民营企业竞争 - 逼出创新 - 动力创新/提高效率 - 全要素生产率提高 - 借的钱能还回来 - 形成良性循环 
            1. 长期方法 
    3. 在推动高质量发展中，国有银行对大型国企的支持与民营企业融资难的缓解，哪一个更关键？若偏向一方，经济效率与社会公平会受到怎样的影响？
        1. 大型国企 （战略性领域） → 低成本 → 扩大在能源，军事等关键领域投资 → 战略性基础设施上升 → 产业集群效应 → 上下游产业链更加顽强 （加上公民社会兴起） → 科技研发速度上升 → 创造更多绿色/5g产品 → 推动产业升级 （高端技术） → 高附加值 →  实现高质量发展
            1. 国有垄断 - 不公平 - 社会主义核心价值 （社会层面）-公正/法治 - 意识形态合法性。正当性 - 政权合法性
            2. 国有垄断 - 国企隐形担保 - 
        2. 民营企业 （非关键领域） → 信贷放松 （信贷不再锁定到僵尸企业当中）- 投资高回报企业 - 风险 - 收益逻辑上升 - 更愿意借给民营企业 - 加大研发投入 / 服务外包更加完善 + 中间投入效应 - 引进更多外来技术 - 技术溢出效应 + 市场换技术 - 引进-吸收消化再创新 - 高质量产品 - 推动产业升级 - 投资驱动 到 创新驱动 - 高质量发展
            1. 刘鹤 5，6，7，8，9
    4. 面对地方政府债务风险与国企政策性负担，若必须优先解决其中之一，哪一项更能增强中国经济的可持续性？这将如何改变中央与地方的财政关系？
        1. 地方政府晋升锦标赛 →更多经济资源，组织资源，文化资源 （人往高处走）→ gdp主义 → 利用隐性担保 （银行高层人员与地方政府互相包庇）→ 借取大量贷款 → 投资到制造业，基础设施，房地产 → 百项工程 （边际效应递减） → 三高一低 → 中国利用1/6gdp来处理环境污染 + 需依赖优先天然资源 + 遭到国外压制批评 （中国癌症村） → 损害中国可持续发展
        2. 预算软约束 → 政府兜底 + 补贴 （输血）→ 向银行借大笔贷款保留僵尸企业 → 僵尸企业非常低效率/没有竞争性 → 无法及时交贷款 → 银行资金断裂 → 信贷收缩 → 民营企业融资难 → 倒闭 / 无法创新 → 外资严重下降 → 没有市场换技术/技术溢出效应 → 无法制造高端产品 → 停留在微笑曲线中部 （加工）→ 依赖出口导向型经济维持经济发展 + 加大投资 → 外商依存度过高 → 中国经济不可持续 （科技瓶颈）
