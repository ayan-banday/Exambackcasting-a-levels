- 司法 + 公共服务 （ho/lv)
    1. 在推动国家治理现代化过程中，法治建设（如依法治国、司法独立）与公共服务完善（如教育、医疗、社保均等化）哪个更能有效增强政治稳定？如果缺失其中之一，会对社会稳定产生怎样的影响？
        1. 公共服务 
            1. 均衡性
                1. 社保 - 全面覆盖 + 低保制度
                2. 医疗 - 医保并轨 + 新农合 
                3. 住房 - 廉租房 + 经济适用房 → 城镇化 → 马斯洛需求层次理论 
            2. 均等化
                1. 教育 
                    1. 两集工程 （基本普及九年义务教育 + 基本扫除青壮年文盲） 
            3. 可及性
        - 生理 + 安全需求 → 提高生育率 / 民众三感
    2. 如果司法改革止步不前，但公共服务显著改善，能否弥补合法性不足？
        1. 公共服务改善 = 均等化；均衡性；可及性
        2. 官僚主义 → 政府缺位 （信息孤岛 +  各管一摊）
        3. 行政化 + 地方化 → 供给不匹配 + 支出失衡 
        4. 不透明 （腐败） 
        5. 党权凌驾于法律
    3. 比较“党导法治”（强调党的领导）与“服务型政府”（强调以人民为中心），哪一种更能回应社会矛盾、缓解治理风险？如果二者产生冲突，应当优先保障哪一方？
    4. 在构建善治秩序时，依靠法律制度（如宪法、法律救济、程序正义）和依靠公共服务供给（如社保、教育、医疗）哪个对缩小社会差距的作用更大？如果减少公共服务投入，而强化法律约束，社会公平能否真正实现？
    5. 信息化发展带来了“智慧法治”（如数字司法、裁判文书公开）与“数字公共服务”（如互联网+政务、智慧医疗）。你认为哪一方面的数字化改革更能推动国家治理现代化？若两者发展不均衡，会造成怎样的制度性风险？
