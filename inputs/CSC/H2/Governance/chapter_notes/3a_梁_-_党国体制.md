    1. 在维持中国政治稳定的过程中，党国体制的集中化领导与基层群众自治的分权机制，哪一个更能有效化解社会矛盾？如果必须削弱其中之一，中国的治理效果会受到怎样的影响？
        1. 党国体制 （党领导一切）
            1. 效率高 （宏观调控能力）- 集中力量办大事
            2. 贯彻行高 - 一张蓝图绘到底
        2. 基层群众自治
            1. 贴近民生 - 立刻解决矛盾 - 减压阀 ； 扫描仪
                1. 地方主义威胁
                2. 能力不足
    2. 从政绩合法性与意识形态合法性的角度比较：如果经济增长放缓，政府应优先依靠公共服务改善（政绩合法性）还是民族共同体叙事与意识形态宣传（意识形态合法性）来稳固执政基础？哪一种更能在危机中起“最后防线”的作用？
        1. 经济增常放缓 = 高投资高出口效益下降 = 需依赖内需主导型经济 = 养老金消耗殆尽，社保不完善导致民众不愿消费
        2. 公共服务改善 = 均衡性/均等性增加 （两集工程 + 廉租房 + 医保并轨）= 民生改善 = 新中产三感提高 = 认同正当性
            1. 但 - 政绩困局 - 太好 = 民众要求太高 （全球化/信息化 - 能看到其他国家如何办事 / 民主化） - 个性化服务 - 中国当今还无能力
            2. 民族共同体叙事与意识形态 = 民族共同体意识 （中国梦）= 提高
                1. 国家发展 = 我的幸福
                2. 具像化 （ 社会主义核心价值 - 国家层 （富强）+ 社会层 （法治+公正）-促进创新 - 国家层 （文明） -促进绿色发展）
                3. 增加评价维度
    3. 官方机制（如人大、政协、多党协商）在合法性建设上主要依赖形式化程序，而公民网络参与则更具即时性与多元化。两者相比，哪一个更能增强政治效能感？若削弱网络空间的政治表达，官方机制能否独立维持社会认同？
    4. 政治异议在中国既被视为风险，也可能成为改革动力。相比“全面压制异议”与“有限包容、协商吸纳”，哪一种更能长期维护执政合法性？如果中国放宽异议空间，会如何改变政府与社会之间的互动？
    5. 在监督与制约机制中，社会信用体系与网络实名制强化了国家控制，而传统的党内监督（如中纪委、监察委）则强调自上而下的约束。两者相比，哪一种更能真正防止权力滥用？若必须优先改革其中之一，哪一个更关键？
