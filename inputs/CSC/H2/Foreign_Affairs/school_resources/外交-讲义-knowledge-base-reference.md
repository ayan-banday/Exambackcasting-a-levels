### 梁：第4课题第1讲：影响中国外交的核心因素：主权与领土完整
- **Source:** 梁
- **Lecture position:** 第1讲
- **Cluster (1-6 above):** Cluster 1 — 影响中国外交政策的因素 (主权)
- **Specific sub-topic:** 主权 + 领土完整 as drivers of Chinese foreign policy

- **Key concepts (definitions):**
  - **外交:** 主权国家以国际法/国际惯例为基础，通过正式代表本国的最高领导和外交部门处理国际关系的行动和过程；功能 = 沟通互动、谈判、情报搜集、冲突管理。
  - **外交政策:** 国家决策者为实现国家利益所规定的特定目标制定的对外战略和行动方针；分为目标 / 制约因素 / 制定过程三层面。
  - **国家利益:** 物质层面（安全、发展）+ 精神层面（国际承认与尊重）的总和；外交一切行动的出发点和归宿点。
  - **核心利益:** 国家利益结构中次序优先、关系全局、不容挑战、面临威胁的利益；2011 国新办白皮书列出"六大核心利益"。
  - **主权:** 一国独立自主处理内外事务的最高权力（对内最高、对外独立），含管辖权、独立权、自卫权、平等权。
  - **主权让渡:** 全球化下国家自愿将部分主权权能转让国际组织行使，具有双向性、互动性、独立自主性；是行使主权的方式而非丧失主权。
  - **领土完整:** 整个领土范围的完整性 + 不可侵犯性，包括领域和资源两方面。

- **Core argument:** 主权与领土完整是中国外交的最高底线。中国奉行独立自主的和平外交政策，宗旨是"维护世界和平、促进共同发展"。习近平的"两个决不能"+"两个不要指望"明确将主权置于一切之上："决不能放弃正当权益，决不能牺牲国家核心利益。" 但全球化时代主权同时面临新挑战——超国家组织、跨国公司、互联网、强权政治不断挤压主权空间。

- **Specific data / cases / years:**
  - 1648《威斯特伐利亚和约》→ 现代主权体系
  - 2011-09-06 国新办《中国的和平发展》白皮书首次列出六大核心利益
  - 中国14个陆上邻国 + 6个海上邻国

  - 南海"五国六方"（中、越、菲、文莱、马、台）对南沙群岛主权诉求
  - 1996 上合组织成立，解决中俄哈吉塔边界
  - 1980s 邓小平提"搁置争议，共同开发"
  - 1995 中菲美济礁事件
  - 2002.11 金边《南海各方行为宣言》(DOC)
  - 2010 美国"重返亚洲"
  - 2012 中菲黄岩岛事件 / 设立三沙市
  - 2013 菲律宾单方面提交南海仲裁；中国启动 COC 磋商；填岛作业开始
  - 2014 习近平提"双轨思路"
  - 2016 中菲南海仲裁案最终裁决
  - 2017 特朗普"航行自由"行动频繁化

- **Cross-课题 connections:**
  - 政治：意识形态合法性、民族认同、新疆/西藏/香港/台湾治理 → 主权安全
  - 经济：经济发展是"打铁还要自身硬"基础；高质量发展削弱分裂主义
  - 社会：民族认同张力（新疆、西藏 vs 国家认同；香港殖民记忆；台湾"去中国化"）

- **Maps to 集锦 question(s):** Q33 (经济考量是否最关键), Q35–Q42 主权论证支撑

- **High-leverage vocabulary:**
  - 一中原则 / 韬光养晦 → 奋发有为 / 新型大国关系 / 双轨思路 / 一带一路 / 人类命运共同体 / 和平共处五项原则 / 战狼外交 / 三股势力 / 弱国无外交，大国未必有大外交 / 轻声说重话 / BANI（脆弱、焦虑、非线性、不可理解）/ 强权政治 / 丛林法则 / 大国博弈 / 主权让渡

- **中国外交政策演变 timeline (核心):**
  - 毛时代 1949-78：生存外交（一边倒、另起炉灶、打扫干净屋子再请客）→ 革命外交（三个世界）→ 中美改善

### 梁：第4课题第2讲：影响中国外交的核心因素：国家安全
- **Source:** 梁
- **Lecture position:** 第2讲
- **Cluster (1-6 above):** Cluster 1 — 影响中国外交政策的因素 (国家安全)
- **Specific sub-topic:** 国家安全 → 安全外交 → 总体国家安全观

- **Key concepts (definitions):**
  - **风险:** 特定环境/时间内危险或灾难发生的可能性。两类典型：
    - **黑天鹅:** 难以预料、小概率发生但影响重大、引发连锁负面反应的事件。
    - **灰犀牛:** 习以为常的高概率风险因未受重视而爆发，可预测但被忽视。
  - **国家安全:** 一国免受各种干扰、侵蚀、威胁和颠覆的状态和能力。涵盖军事、政治、国土、经济、文化、社会、信息等领域。
  - **国家安全观:** 执政者/参政者对国家安全的认识、观点和理论体系。
  - **安全外交:** 国家以和平手段为确保具有免受干扰、侵蚀、威胁和颠覆的状态和能力而开展的外交活动。中国安全外交=维护国家核心安全利益+塑造国际规则+反对霸权对抗+深化多边与周边合作。
  - **安全困境（Security Dilemma）:** 无政府状态下国家间互不信任，各国为安全增加军费导致军备竞赛，没人获得绝对安全。破解：构筑安全共同体或合作安全。
  - **崛起困境:** 崛起大国既要将物质实力转化为体系影响力，同时要缓解他国制衡，两难局面。
  - **国家安全泛化:** 公权力滥用总体国家安全观概念，突破国家安全"定义域"，组织利益最大化驱动；副作用包括统筹失衡、资源浪费、效率降低、边际递减。

- **Core argument:** 国家安全是外交的"底盘"和不可妥协的红线。"没有永远的朋友，也没有永远的敌人，只有永远的利益"——安全利益是双边战略关系的首要基础，经济利益第二位，紧密的经济关系并不必然加强双边战略关系。习近平的总体国家安全观（2014）将安全外交从"防御"上升为系统的战略框架。

- **Specific data / cases / years:**
  - 1943 Walter Lippmann《美国外交政策》首提"国家安全"
  - 1947 美国《国家安全法》并设立国家安全委员会（NSC）→ 40多个国家效仿
  - 1976 日本《70年代前期经济计划》首提"经济安全"
  - 1980 日本《国家综合安全报告》正式将经济安全纳入国家安全
  - 1992 中国成立国家安全部
  - 2000.9 中央成立"中央国家安全领导小组"，与"中央外事工作领导小组"合署办公（两块牌子一套机构）
  - 2003.10 中国加入《东南亚友好合作条约》(TAC)
  - 2013 十八届三中全会提议设立国安委
  - 2014.1 中共中央决定成立中央国家安全委员会，4月正式运转
  - 2014 习近平提出"总体国家安全观"
  - 2014 全国人大设立国家安全教育日（每年4月15日）
  - 2014 全国人大确定9月3日抗战胜利纪念日、12月13日南京大屠杀公祭日
  - 2018 地方各级党委设立国安委（办）
  - 2022.9 美国NSA对西北工业大学网络长时间入侵攻击
  - 2024.2 美国商会《中国商务环境调查报告》：私营和外资企业对中国《反间谍法》普遍担忧
  - 2023 军事实力排名：美、俄、中前三

- **国家安全观演变（毛→邓→江→胡→习 5 段式）:**
  - 毛 1949–78：传统安全为核心，时代主题战争与革命，积极防御战略+革命外交+输出革命
  - 邓 1979–89：综合安全观，时代主题和平与发展；百万大裁军；外交为经济服务
  - 江 1990–2002：新安全观（互信、互利、平等、协作）；安全多样化、合作性、共赢性
  - 胡 2003–2012：和平崛起→和平发展→和谐世界；首次对外宣布国家安全核心利益
  - 习 2013–：总体国家安全观，"以人民安全为宗旨,以政治安全为根本,以经济安全为基础,以军事/文化/社会安全为保障,以促进国际安全为依托"——10大统筹

- **总体安全观 5 大保障 + 16 大领域:** 政治、经济、军事、文化、社会、科技、信息、生态、资源、核、海外利益、太空、深海、极地、生物、人工智能等。

- **中国安全外交 7 大手段:**
  1. 清晰界定并坚守核心利益（红线/底线）
  2. 以大国关系为关键，稳定战略环境（推动相互尊重、和平共处、合作共赢；管控分歧）
  3. 以周边安全为重点（"亲、诚、惠、容"；双多边机制处理领土/海洋分歧；反对外部介入）
  4. 多边安全合作（联合国维和、亚丁湾护航、东盟地区论坛 ARF、上合 SCO、亚信会议 CICA、香格里拉对话 SLD、北京香山论坛、东盟防长扩大会议 ADMM+）
  5. 形塑全球规则、提升话语权（GSI 全球安全倡议-共同/综合/合作/可持续安全；六方会谈）
  6. 安全对话、管控分歧（防务对话、热线机制、TAC、《南海各方行为宣言》DOC 2002.11）
  7. 提高军事透明度（《中国的国防》白皮书、定期通报演训）

- **安全外交挑战:**
  - 中美战略矛盾、修昔底德陷阱风险加剧；美国 2017 起将中国界定为"战略竞争对手"
  - 美国对华遏制 5 大平台：双边同盟（美日韩菲）+ AUKUS + Quad（美日印澳）+ FVEY 五眼联盟 + 构筑"C型包围圈"

  - 网络信息安全、社交媒体武器化
  - 国家安全泛化陷阱（《反间谍法》打击招商引资）
  - 五个统筹（国际/国内 + 发展/安全 + 人民/政治 + 传统/非传统 + 国家安全/社会治理）

### 梁：第4课题第3讲：影响中国外交政策的核心因素：经济考量
- **Source:** 梁
- **Lecture position:** 第3讲
- **Cluster (1-6 above):** Cluster 1 — 影响中国外交政策的因素 (经济考量)
- **Specific sub-topic:** 经济外交 + 海外利益保护 + 国家经济安全

- **Key concepts (definitions):**
  - **经济外交:** 一国中央政府及职能部门围绕经济事务，针对他国政府/国际组织/跨国公司开展的官方交往。双重目的=（1）双多边经济合作；（2）通过经济相关外交活动实现非经济目的（安全、稳定）。
  - **援助型 / 合作型 / 制裁型经济外交:** 三种性质分类。
  - **国家经济安全:** 一国经济整体上的安全性，含可靠政治主权 + 抵御内外风险能力 + 经济主权不受侵犯 + 经济持续高速健康发展。
  - **海外国家利益:** 存在于中国主权管辖范围以外的中国利益；广义=境外协议合约+尊严形象，狭义=境外公民/财产/活动安全。涵盖政治、经济、军事利益。
  - **能源安全:** 一国可获得能源资源、保障经济需要、参与国际竞争和可持续发展。3 维度：投资境外石油、建立石油战略储备、控制能源运输安全。
  - **经济安全困境:** 一国追求经济发展和技术进步时引发他国安全担忧 → 反制 → 网络效应 → 经济相互依存被武器化（"全景监视战略"+"阻塞战略"）。

- **Core argument:** "经济是外交的压舱石"。中国 1978 改革开放以来，经济外交从"以发展为中心"逐步迈向"发展与安全并重"。经济外交呈现 4 阶段演变：接触性（1978–91）→ 融入性（1992–2000）→ 参与性（2001–12）→ 引领性（2013–）。当前面对中美贸易战、"小院高墙"、"脱钩断链"，中国必须将经济影响力转化为务实的外交影响力。

- **Specific data / cases / years:**
  - 1944 布雷顿森林会议
  - 1957 日本《外交蓝皮书》首次出现"经济外交"概念
  - 1971 第26届联大恢复中国合法席位（亚非拉23国联合提案）
  - 1980 中国恢复 IMF 和世行席位
  - 1981 中国开始向世行借款
  - 1983 中美商贸联合委员会成立
  - 1986 中国加入亚洲开发银行；正式申请"复关"GATT
  - 1989 六四后中国遭国际经济制裁
  - 1991 中国加入 APEC
  - 1993 APEC 首届峰会；克林顿政府将经济安全列为美外交三大支柱之一
  - 1997 "10+3"机制（东盟+中日韩）
  - 2000 朱镕基首提中国-东盟自贸区构想
  - 2001.11 中国正式加入 WTO
  - 2008 全球金融危机；中国推动 G20 升格首脑会议
  - 2008 底 中国海军根据联合国安理会1846号决议开始亚丁湾常态化护航
  - 2010 中国-东盟自贸区正式建成；中国 GDP 超日本居世界第二
  - 2013 中国超美国成为世界第一大贸易国；提出"一带一路"倡议；提出"中国制造 2025"（2015）
  - 2018-23 中国与一带一路共建国货物贸易从 1.9 万亿→2.8 万亿美元（年均 +8.1%）；中国对共建国直接投资累计超 1800 亿美元（年均 +5.9%）；当地创造 42.1 万就业岗位
  - 自 2013：21 个自贸试验区 + 海南自贸港；中国与 26 国/地区签署 19 个自贸协定；自贸伙伴贸易额占外贸总额约 35%

- **经济外交 4 阶段演变（关键论述结构）:**
  1. 接触性（1978-1991）：打破孤立，谷牧西欧考察，恢复 IMF/世行席位

### 梁：第4课题第4讲：意识形态与中国外交
- **Source:** 梁
- **Lecture position:** 第4讲
- **Cluster (1-6 above):** Cluster 1 — 影响中国外交政策的因素 (意识形态)
- **Specific sub-topic:** 意识形态在外交中的演变（毛 → 邓 → 江/胡 → 习）

- **Key concepts (definitions):**
  - **意识形态:** 特定社会阶级/集团基于自身利益对现存或构想的社会制度的解释、辩护、批判或改造的理论体系。3 部分：认知体系+价值体系+信仰体系。功能：表达交流、感染操纵、认同、合法化、动员、团结组织。
  - **文化霸权:** 一个社会阶层通过文化工具操纵社会文化，支配多元社会。冷战后美国凭借文化普及性建立全球"文化霸权"。美国对外政策的意识形态四要素：天定命运、利他主义、自由主义、反共主义。
  - **意识形态安全:** 一定时空中意识形态不受威胁的状态。包括（1）价值正当性合法性；（2）外在制度实践可行性；（3）理论逻辑与制度安排契合性。
  - **韬光养晦:** "韬"意识形态的"光"+"养"经济发展的"晦"——不在意识形态上论证社会主义优越性，而是用 1/5 世界人口的实践说话。

- **Core argument:** 意识形态在中国外交中经历了 3 阶段："放第一位"（1949-78 毛）→ "淡化"（1972-2012 邓江胡）→ "重新拾起、走到外交前台"（2013- 习）。但即使习时代，意识形态也是工具而非发动机——外交"第一性原理"是国家利益，不是价值输出。

- **Specific data / cases / years:**
  - 1948 中苏意识形态结盟
  - 1972.2.21 尼克松访华，2.28《中美联合公报》—放弃以意识形态划线
  - 1978 十一届三中全会
  - 1982 中共十二大正式吸取意识形态划线教训
  - 1986 政府工作报告"不以社会制度和意识形态的异同来决定亲疏好恶"
  - 1989 六四 → 邓"韬光养晦"提出
  - 2003 玫瑰革命（格鲁吉亚）
  - 2004-05 橙色革命（乌克兰）
  - 2010-11 茉莉花革命（突尼斯→阿拉伯之春）
  - 2008 北京奥运会火炬传递受阻 → 中国民族主义崛起
  - 2018.7 美 CIA 副助理主任 Michael Collins："中国对美发动冷战"
  - 2020.7.23 美国务卿蓬佩奥尼克松总统图书馆演讲，被视作"新铁幕演讲"
  - 北京共识 vs 华盛顿共识：北京共识=独裁现代化+合法化威权；华盛顿共识=私有化、自由化、稳定化
  - 习近平政府"七不讲"高校禁令；"党媒姓党"；官媒批宪政；4 个自信（道路/理论/制度/文化）

- **意识形态在中国外交中 3 段演变（必背）:**
  1. **革命外交（1949-78 毛）**：意识形态第一位，"一边倒"（1949-50s）→ 中苏决裂后"一条线战略"（70s）→ 1972 中美和解开始放弃以意识形态划线
  2. **淡化（1972-2012 邓江胡）**：邓"不去计较社会制度和意识形态的差别"+"不以社会制度和意识形态划线"+"不输出意识形态"+"不干涉内政"；改革本身成为新意识形态；"韬光养晦"
  3. **回归外交前台（2013- 习）**：习"意识形态工作是党的极端重要工作，事关党前途命运、国家长治久安、民族凝聚力"；4 个自信；制度性竞争；防"颜色革命"；从防御转向竞争；推动"人类命运共同体""全球治理中国方案"

- **冷战后美国对华接触政策 4 大目标:**
  1. 使中国融入美国主导的自由主义国际秩序
  2. 使中国遵守既有规则规范
  3. 避免发展为正面对抗
  4. 通过接触使中国走向自由化民主化
  - 克林顿"建设性战略伙伴"→小布什"负责任利益攸关方"→奥巴马"相互战略保证"

- **意识形态在当代中国外交 3 大功能:**
  1. 对国内：合法性功能（政策叙事框架）
  2. 对发达国家：对抗西方话语霸权（防御性、反霸权、主权导向，目的不是输出而是降低外部干预成本）
  3. 对发展中国家：有限动员（南南合作、发展权、制度多样性、反单边主义）

- **影响当今中国外交的关键因素优先级:**
  - 国家安全（风险控制+战略克制，避免新冷战）> 经济（外向型经济可持续依赖全球体系）> 全球治理（规则博弈而非阵营对抗） > 意识形态（包装层而非决策起点）

- **Cross-课题 connections:**
  - 政治：合法性来源、党的执政安全、改革本身成为新意识形态
  - 经济：经济发展是邓时代意识形态核心，发展才是硬道理
  - 安全：反"颜色革命"、防"和平演变"

- **High-leverage vocabulary:**
  - 一边倒 / 一条线战略 / 韬光养晦→奋发有为 / 北京共识 vs 华盛顿共识 / 颜色革命（玫瑰/橙色/茉莉花）/ 历史的终结 / 文明的冲突 / 4 个自信 / 7 不讲 / 党媒姓党 / 不输出意识形态 / 不干涉内政 / 人类命运共同体 / 全球治理中国方案 / 制度性竞争 / 文化霸权 / 天定命运 / 利他主义 / 第一性原理

### 梁：第4课题第5讲：中国与国际经济组织
- **Source:** 梁
- **Lecture position:** 第5讲
- **Cluster (1-6 above):** Cluster 5 — 参与全球治理（经济）
- **Specific sub-topic:** 中国融入 IMF / 世界银行 / WTO / 创建 AIIB / BRICS / 一带一路 / 推动改革

- **Key concepts:**
  - **全球经济秩序 / 治理:** 制度规则 + 权力结构 + 运行机制；目的是维持合理有序的国际经济秩序+促进世界经济持续增长。核心=规则治理。
  - **布雷顿森林体系（1944）:** "一个主导（美）+ 两个体系（货币金融+贸易）+ 三大组织（IMF/WB/GATT）"，美元-黄金本位制（1盎司=$35）。
  - **特里芬悖论（Triffin Dilemma）:** 美元作为世界本位货币既要维系币值稳定（要求美国国际收支顺差），又要满足全球美元供给（要求美国持续逆差），自相矛盾。最终 1971.12 尼克松《史密森协定》撕毁布雷顿森林体系。
  - **后布雷顿森林体系:** 一币（美元）+ 三制（浮动汇率/资本自由流动/新自由主义"华盛顿共识"）+ 四权（货币铸币权、金融定价权、规则制定权、制裁与金融武器化权 SWIFT）。
  - **石油美元（Petrodollar）:** 1976 美沙《不可动摇协议》，沙特石油以美元计价 → 全球70%石油资源置于美国掌控。
  - **金砖国家（BRICS）:** Jim O'Neill 2001 提出（巴西/俄/印/中），2011 南非加入。2014 NBD（新开发银行）规模 $2500 亿。
  - **意大利面条碗现象:** 不同 FTA 复杂的原产地规则交织，导致商业和行政成本上升。

- **Core argument:** 中国从国际经济秩序的"局外者/旁观者"→ 接触性（1978-91）→ 融入性（1992-2000）→ 参与性（2001-12）→ 引领性（2013-）。当下中国是"规则接受者+规则博弈者+规则塑造者"三位一体；中国的策略是"代表性修复+规则公平化+公共品补位+发展型叙事"，"压舱石≠另起炉灶"——稳定规则/预期/经济底盘/全球公共产品。

- **Specific data / cases / years:**
  - 1944.7 布雷顿森林会议（44 国）
  - 1945.12.27 IMF 成立；1946.6 WB 营业
  - 1947.10.30 GATT 23 个缔约方在日内瓦签订（中国是创始缔约国之一）
  - 1948 GATT 生效
  - 1971.12 尼克松《史密森协定》撕毁布雷顿森林体系
  - 1976 美沙《不可动摇协议》
  - 1980.4.17 IMF 恢复中国合法席位；1980.5.15 WB 恢复中国合法席位（份额从 5.5 亿→12 亿 SDR）
  - 1983 中美商贸联合委员会成立
  - 1986.7 中国正式申请"复关"GATT；中国加入亚开行
  - 1991.11 中国、台北、香港加入 APEC
  - 1995.1.1 WTO 取代 GATT
  - 1996.4.26 上海五国成立；1997 江提"引进来+走出去"
  - 1999 G20 成立
  - 2001.11.10 中美第 25 轮谈判达成协议；2001.11 朱镕基首提中国-东盟自贸区
  - 2001.12.11 中国正式加入 WTO
  - 2002.6 上海合作组织宪章签署（"上海精神"=互信、互利、平等、协商、尊重多样文明、谋求共同发展）
  - 2006 金砖国家外长首次会晤
  - 2008 G20 升格首脑会议（华盛顿）
  - 2010.1.1 中国-东盟自贸区正式建成；中国 GDP 超日本居二
  - 2011 BRICS 加南非
  - 2013.6 中国超美国成最大贸易国；提出一带一路
  - 2014 BRICS 新开发银行（NBD）成立 $2500 亿；亚投行（AIIB）筹建
  - 2019 屈冬玉当选 FAO 总干事
  - 2020 中欧 CAI 完成谈判
  - 2021.9 中国正式申请加入 CPTPP
  - 2022.1.1 RCEP 生效

### 梁：第4课题第6讲：中国与多边贸易协定
- **Source:** 梁
- **Lecture position:** 第6讲
- **Cluster (1-6 above):** Cluster 5 — 参与全球治理（经济）+ Cluster 4 partial（中国-亚细安）
- **Specific sub-topic:** WTO / 多边贸易体系 / CAFTA / RCEP / CPTPP / TPP / IPEF

- **Key concepts:**
  - **国际贸易类型:** 出口/进口/服务贸易；双边/多边
  - **贸易安排梯度:** 特惠关税区 < 自由贸易区（FTA）< 关税同盟 < 共同市场 < 经济联盟 < 完全经济一体化
  - **新贸易保护主义:** 在全球化和多边规则背景下，使用"隐蔽、制度化、技术化"手段（碳边境税、出口管制、反倾销反补贴）保护本国产业
  - **多边贸易协定:** 3 个+ 国家在同一框架下达成的共同遵守的贸易规则
  - **碎片化全球化:** 全球市场/规则/生产网络被政治、地缘、安全因素切割成分区化、阵营化、集团化板块
  - **CAFTA（中国-东盟自贸协定）:** 中国第一个 FTA、发展中国家间最大 FTA；2002 框架协议→2005 货物→2010 全面建成（1.0）→2019 升级（2.0）→2025.5 完成 3.0 谈判（覆盖数字、绿色、供应链等 9 领域）
  - **RCEP（区域全面经济伙伴关系协定）:** 东盟 10 + 中日韩澳新；2012 启动→2020 签署→2022.1.1 生效。覆盖全球 29.7% 人口、28.9% GDP、约 30% 贸易总额；十年内取消 90%+ 关税。
  - **TPP（跨太平洋伙伴关系协定）:** 奥巴马"规则同盟+亚太再平衡"，特朗普 2017 退出
  - **CPTPP:** 11 国保留 TPP 规则升级版；2018.3 圣地亚哥签字；2021.9 中国正式申请加入
  - **IPEF（印太经济框架）:** 拜登/特朗普版本，4 大支柱（供应链/数字经济/清洁能源/反腐），刻意避开市场准入和关税减让；本质是"低成本、高灵活、好甩锅"对付中国

- **Core argument:** WTO 是"经济联合国"+多边贸易体制"压舱石"；中国是多边贸易体系最大受益方+重要贡献者。RCEP/CPTPP/IPEF 三者：RCEP 现实红利最大（外贸压舱石）、CPTPP 是国内深层改革"压力测试"、IPEF 短期影响有限但是长期规则博弈工具。中国应"深度参与全球规则体系，成为多边主义稳定器；用 RCEP 压舱石对冲不确定性；把发展中国家身份转化为制度性优势"。

- **Specific data / cases / years (中国 FTA 进程):**
  - 2003.11.24 CEPA（中国-港澳）
  - 2005 中智 FTA；中巴 FTA
  - 2008 中新加坡 FTA；中新西兰 FTA（首个发达国家 FTA）；中秘鲁 FTA
  - 2009.8.15 中国-东盟自贸区《投资协议》
  - 2010.4 中国-哥斯达黎加 FTA；中国-冰岛 FTA（首个欧洲 FTA）
  - 2013.7 中瑞士 FTA
  - 2015.6.1 中韩 FTA；2015.6.17 中澳 FTA
  - 2017 中格鲁吉亚 FTA；中马尔代夫 FTA
  - 2019.10 中毛里求斯 FTA；中柬埔寨 FTA
  - 2020.11.15 RCEP 签署
  - 2023.5 中厄瓜多尔 FTA；2023.10 中塞尔维亚 FTA

- **CAFTA 关键数据:**
  - 90%+ 商品零关税；7000 种产品取消关税
  - 中国连续 14 年（2009-）东盟最大贸易伙伴；东盟 2020 起成为中国最大贸易伙伴
  - "早期收获计划（EHP）" — 农产品率先降税让东盟受益

- **CAFTA 演变3 阶段:**
  1. 2010 1.0 — 货物贸易关税大幅削减
  2. 2019 2.0 — 服务/投资/便利化/原产地
  3. 2025.5 3.0 — 数字经济、绿色经济、供应链互联互通、标准、SPS、海关、竞争与消费者、中小企业、经济技术合作 9 领域

- **CAFTA 朱镕基提出的 4 大动机:**
  ① 加入 WTO 后向周边释放确定性信号
  ② 亚洲金融危机后重建区域信任（"政治信任→经济制度合作"）
  ③ 改革开放第二外循环支点
  ④ 以"南南合作"塑造中国国际制度形象（不搞高标准压人；不对称、渐进式开放——"非霸权式规则输出"）

- **东盟为何愿意签 CAFTA 4 大原因:**
  ① 不愿被排除中国市场之外
  ② 中国给东盟让利（更长过渡期、EHP）
  ③ 对冲大国博弈风险（金融危机后对单一大国心存警惕）
  ④ CAFTA 规则友好（不强劳工/环境/制度敏感区）

- **RCEP 中国主推 3 大动机:**
  ① 应对全球不确定性（外贸压舱石）
  ② 巩固"区域经济中心位势"（把碎片化双边 FTA 整合）
  ③ 倒逼中国产业升级（"加工装配→关键零部件、核心技术、系统集成"）

- **RCEP 对中国 4 大积极影响:**
  - 外贸更稳（区域压舱石）
  - 产业链更强（"枢纽地位"强化）
  - 制度更开放（数字贸易、跨境数据、服务贸易倒逼改革）
  - 区域发展更协调（原产地累积规则使内陆地区"主动嵌链"）

- **中美博弈下美国 TPP→IPEF 战略转型:**
  - TPP（奥巴马"重返亚太"经济支柱+规则同盟）→ 2017 特朗普退出（"工作外包工具"标签）→ CPTPP 由日本牵头继续 → IPEF 转向"去贸易化"规则联盟

- **WTO 当下 4 大挑战:**
  - 单边主义削弱权威
  - 争端裁判机制失灵（上诉机构停摆）
  - 规则滞后（数字贸易/AI/绿色规则）
  - 成员利益协调困难+地位下降（"安全化、政治化"冲击）

- **中国为完善 WTO 4 大努力:**
  - 维护以 WTO 为核心的多边贸易体制
  - 推动争端解决机制改革（参与 MPIA 多方临时上诉仲裁）
  - 推动 WTO 规则与新经济议题对接（联合声明倡议 JSI）
  - 强调发展中国家利益与包容性改革

- **Cross-课题 connections:**
  - 经济：出口导向经济（贸易战、技术封锁）；产业升级；外向型经济
  - 政治：东盟"亚洲悖论"（经济靠中国、安全靠美国）

- **Maps to 集锦 question(s):** Q34, Q35, Q40, Q41（思考题"参与多边贸易协定能否维护中国核心利益"= 2025 A-Level 真题）

### 梁：第4课题第7讲：全球安全治理 — 中国与联合国
- **Source:** 梁

- **Specific sub-topic:** 联合国体系 / 维和 / 裁军 / 核不扩散

- **Key concepts:**
  - **集体安全（Collective Security）:** 一种保障所有国家生存与国际和平的制度——侵略一国即视为侵犯所有国。1920 国际联盟；1945 联合国是最大代表。
  - **国际安全治理 4 特征:** 议题扩展（人类安全）+ 合作性（集体而非单边）+ 制度化（国际法）+ 多边主义（联合国/区域组织）。
  - **联合国 6 大主要机构:** 联大、安理会、经社理事会、托管理事会（1994 停止运作）、国际法院、秘书处。
  - **联合国体系全球安全治理 3 大支柱:**
    ① 集体安全机制（安理会）
    ② 多边安全规范（条约体系）
    ③ 实践性安全行动（维和、人道援助、制裁、反恐）
  - **维和 3 原则:** 当事国同意 + 中立 + 非自卫不使用武力
  - **GSI（全球安全倡议 Global Security Initiative）:** 习近平 2022 博鳌论坛提出，"共同/综合/合作/可持续"安全观；反对冷战思维与阵营对抗。

- **Core argument:** 中国与联合国关系经历 4 阶段：批判性参与（1950-60s "美帝工具论"）→ 谨慎参与（1971 重返联合国后）→ 积极融入（1980s 改革开放后；1989 首派维和；"三不政策"破除）→ 从参与者到建设者再到引领者（2013- 提出 GSI、人类命运共同体；中国-联合国和平与发展基金）。中国参与联合国安全治理的战略逻辑=维护自身安全环境+提供国际公共产品+塑造多边主义秩序。

  - 1996 第 51 届联大《全面禁止核试验条约》通过；中国签

  - 权力结构：安理会结构性矛盾、议题政治化

### YCK（杨振光老师）第4-2讲：中美关系——经贸合作与博弈
- **Source:** 杨振光老师 (YCK)
- **Lecture position:** 第4-2讲
- **Cluster:** Cluster 3 — 中美经贸博弈
- **Specific sub-topic:** 贸易逆差 / 贸易摩擦四阶段 / 特里芬难题 / "一带一路"应对机制

- **Key concepts:**
  - **特里芬难题（Triffin Dilemma）:** 1944布雷顿森林体系的内在矛盾——美元作为国际储备货币需持续供应（必然造成贸易逆差），但美元稳定又要求收支平衡。两者互相矛盾，是无法克服的悖论。
  - **"压舱石":** 中美经贸关系即使政治摩擦巨大仍能维系，因为双边贸易规模庞大、依存度深，是关系稳定的物质基础。
  - **"小院高墙"（decoupling framing）:** 美国科技脱钩核心策略——在关键领域（芯片、AI）设高墙，其余领域维持贸易。

- **中美双边贸易四大特征:**
  1. **规模巨大:** 2024货物贸易5820亿美元+服务769亿美元=6589亿美元总计；2021高位7557亿美元，2022年7584亿美元后回落。
  2. **互补性强:** 2001–2016年中美形成经典分工——中国制造+美国设计/品牌/金融服务；2018后"去风险化"压低低端制造互补，高科技管制加强，但互补格局并未完全消失。
  3. **相互依赖深:** 2020年10个主要行业中5个以中国为主要供给方，10个以中国为主要市场；星巴克华门店4100家，苹果在华收入超400亿美元，通用汽车在华每年生产300万辆。
  4. **贸易不平衡（逆差持续）:** 美对华货物贸易逆差从2020年-310.3亿→2022年峰值-382.9亿→2024年-295.5亿→2025年逐步缩窄至-175.4亿美元（反映关税冲击效果）。

- **中美贸易摩擦三阶段:**
  1. **初期（约2006–2016）:** 高频"双反"（反倾销+反补贴），WTO框架内救济为主。
  2. **激化（2017–2020）:** 301/232调查关税；华为等入实体清单；CHIPS法案前期部署。
  3. **重塑（2021至今）:** 高科技围堵+供应链脱钩：CHIPS and Science Act；CFIUS投资审查加强；截至2026年初数百家中国科技企业入各类黑名单（实体清单+1260H清单）。

- **中国反制机制（2025年关税升级序列）:**
  - 2025年4月10日起：加征34% → 84% → 2025年4月12日125%（"在目前关税水平下，美国输华商品已无市场接受可能性"）
  - 2025年5月14日：降回10%，90天内暂停24%加征

  - 2026年1月：公布退出66个国际组织总统备忘录（含31个联合国机构+35个非联合国组织）
  - 2026年1月22日：正式退出世界卫生组织

- **"一带一路"应对美国"脱钩断链"的机制:**
  - 中巴经济走廊 / 中亚天然气管道 / 泛亚铁路（东南亚高铁）/ 数字丝绸之路 / 人民币跨境结算 / 亚洲基础设施投资银行（AIIB）/ 金砖国家合作机制

  - 2012年9月3日：日本政府与岛主达成协议，以20.5亿日元签订购买合约
  - 2025年：中国海警船钓鱼岛巡航357天（历年新高），日本官员私下建议渔民远离以避免冲突
  - 2026年1月23日：石垣市议会通过新条例，对尖阁诸岛加强管理

- **中日立场对比（结构性差异）:**
  - 中国：钓鱼岛是中国固有领土（依据明清文件）；日本"窃取"钓鱼岛；"购岛"是"唱双簧"的"闹剧"
  - 日本：尖阁是日本固有领土，历史上和国际法上都很明确；日本现在有效控制；"国有化"是从日本公民手中转移所有权，非新侵占
  - 均强调：历史依据、战略与资源价值（渔业、石油天然气）、国家主权问题

- **对"唱双簧"说法的反驳（重要分析）:**
  - 野田佳彦（民主党，中间偏左）vs 石原慎太郎（自民党，中间偏右）：政治对手，非同一阵营
  - 野田执政属"弱势政府"（国会扭曲/ねじれ国会、执政党内部分裂、频繁换相、2011年大地震后社会危机），国有化是为"维持现状"而非挑衅
  - 中国单一制思维vs日本联邦式地方自治：东京都知事由选民直选，具自主权；中国无此参考框架

- **欧美对钓鱼岛立场:**
  - 欧盟："原则性中立"——不在主权上选边站；倡导UNCLOS+和平解决；反对单方面改变现状（2021日欧峰会联合声明第21段）
  - 美国：主权归属中立，但《美日安保条约》Article V明确适用于钓鱼岛——奥巴马（2014年首次公开确认）、特朗普、拜登均重申；奥斯汀："美国反对任何试图改变现状的单方面行动"

- **Cross-课题 connections:**
  - 主权（梁第1讲）：领土完整最高底线
