# 1. 考试结构 Exam Structure

*Corrected from Official 2023 Syllabus*

## Paper 1: 案例分析 (Case Study Analysis)

- **Duration**: 2 hours 45 minutes (165 minutes total)
- **Total**: 60 marks, 40% of grade
- **Assessment Objectives**: AO1 + AO2 + AO3

| Section | Marks | Description |
|---------|-------|-------------|
| Section A (A组) | 35 marks | 4 sub-questions based on 5 sources. Focus: interpreting, analyzing, evaluating sources |
| Section B (B组) | 25 marks | 1 question based on 4 sources. Focus: analyzing, evaluating topics, proposing solutions |

- Each case study centers on one of the 4 core topics
- Sources include text and non-text materials (maps, photos, charts, data, cartoons, posters)

## Paper 2: 问答题 (Essay Questions)

- **Duration**: 2 hours 30 minutes
- **Total**: 90 marks (3 questions x 30 marks each), 60% of grade
- **Assessment Objectives**: AO1 + AO2

| Section | Description |
|---------|-------------|
| Section A (A组) | 1 compulsory question |
| Section B (B组) | Choose 2 from 3 questions |

## 评价目标 Assessment Objectives (AO)

| AO | Chinese | Description |
|----|---------|-------------|
| AO1 | 对知识的理解与应用 | Understand and apply knowledge of contemporary China's economy, politics, society, and international relations |
| AO2 | 对课题的分析与评价 | Explore topics and trends; analyze, evaluate and synthesize different perspectives; construct coherent arguments; cite powerful evidence |
| AO3 | 对资料的诠释与评价 | Interpret, analyze, evaluate sources; analyze perspectives from different sources; evaluate sources to make judgments; propose effective recommendations |

> **Note**: AO1 is part of both AO2 and AO3 assessment.

# 4. 案例分析题型 Case Study Question Types

## 4.1 - 1(a) 解释题 (Explanation) - 6 marks

**What's tested**: Explain concepts, phenomena, trends, characteristics, or relationships.

### Steps

1. **Describe** the phenomenon/characteristic from the source (是什么)
2. **Explain** background/reasons using source + own knowledge (为什么)

### Scoring Tiers

| Tier | Marks | Description |
|------|-------|-------------|
| Tier 3 | 5-6 | Explain 2+ factors/issues |
| Tier 2 | 3-4 | Explain 1 factor/issue |
| Tier 1 | 1-2 | Describe 1+ factors/issues |
| 0 | 0 | No merit |

### Key Rules

- **MUST** use the specified source
- **MUST** combine own knowledge; can use other sources to supplement
- To reach highest tier: at minimum (2 characteristics + 1 reason) OR (1 characteristic + 2 reasons)
- Best approach: 2 sets of (1 characteristic + 1 reason) in separate paragraphs, one-to-one correspondence
- If source has 2-3 charts/data sets, must combine ALL charts/information

### Past Questions

| Source | Question |
|--------|----------|
| SEAB Sample | 试根据资料A关于中国软实力的相关数据，解释中国软实力的特征。|
| 2024 A-Level | 根据资料A，解释中国推动全球治理体系改革的原因。|
| 2024 HCI Prelim | 试根据资料A关于中国经济结构转型的相关数据，解释中国经济结构转型的特征。|
| 2024 EJC Prelim | 试根据资料A，解释中国司法改革的特征。|
| 2024 DHS Prelim | 试根据资料A的相关数据，解释中国与亚细安经贸关系的特征。|

## 4.2 - 1(b) 观点对比题 (Compare Viewpoints) - 9 marks

**What's tested**: Describe, explain, and compare similarities/differences between 2 sources.

### Steps

1. **Identify & analyze similarities** (using sources + own knowledge)
   - Approach angles: overall stance, partial viewpoints, methods/means, causes, results/effectiveness, impact, trends/expected goals
2. **Identify & analyze differences** (same approach angles)
3. **Compare** similarities vs differences, reach clear conclusion: 同>异 or 同<异

### Scoring Tiers

| Tier | Marks | Description |
|------|-------|-------------|
| Tier 3 | 7-9 | Analyze similarities AND differences using source content and own knowledge |
| Tier 2 | 4-6 | Explain similarities OR/AND differences using source content and/or own knowledge |
| Tier 1 | 1-3 | Describe, explain or directly copy sources without comparison |
| 0 | 0 | No merit |

### Key Rules

- **MUST** use both specified sources + own knowledge
- **MUST** analyze BOTH similarities AND differences
- Source origin (domestic/foreign, official/civilian) is supplementary, not primary analysis - focus on the viewpoints themselves
- Clearly distinguish overall stance (整体立场) vs partial viewpoints (局部观点) - never confuse the two
- If your conclusion is "differences > similarities", do NOT say they have the "same overall stance" (and vice versa)

### Past Questions

| Source | Question |
|--------|----------|
| SEAB Sample | 试比较资料B和D关于中国提升软实力的观点。|
| 2024 A-Level | 比较资料B和D关于中国在推动全球治理体系改革的角色。|
| 2024 HCI Prelim | 试比较资料B和D关于中国经济结构转型的观点。|
| 2024 EJC Prelim | 试比较资料B和D关于中国司法改革问题的观点。|
| 2024 DHS Prelim | 试比较资料B和D关于中国与亚细安关系的观点。|
| 2024 RVHS Prelim | 试比较资料B和D关于中国银行业债务风险的观点。|

## 4.3 - 1(c) 评价资料适用度 (Evaluate Source Usefulness) - 8 marks

**What's tested**: Evaluate how useful a source is for explaining a specific claim.

### Steps

**Step 1**: Brief summary of source (1-2 sentences)

**Step 2**: Evaluate 2 strengths/valid points (有效性/优点)
- Template: "若要说明......面对的挑战，资料C的优点如下。"
- [Evidence from source C that supports the claim] + own knowledge or other sources to explain how this evidence effectively supports the claim

**Step 3**: Evaluate 2 limitations/weaknesses (局限性/缺点)
- Template: "但是，美中不足的是，资料在说明......面对的挑战上也存在如下局限/缺点。"
- Limitation angles:
  - Lacks key data/direct evidence (需要其他更重要的信息或更有力的论据，资料无法直接说明问题)
  - No longitudinal comparison - only individual year data, cannot observe trends (缺乏纵向比较)
  - Covers only partial aspects (只能局部地反映问题/现象，无法整体上涵盖)
  - Small/unrepresentative sample (受访者人数不多或没有给出受访者的背景，缺乏广泛代表性)
  - Contains predictions - cannot confirm future outcomes (带有预测成分，现阶段还无法依据对未来的预测来决定某个还未兑现的结果)

**Step 4**: Compare strengths vs limitations, give clear judgment
- If usefulness is HIGH: point out the source's strongest advantage
- If usefulness is LOW: point out the source's most fatal weakness
- Template: "因此，资料在较大程度上适用/不适用；资料在说明......面对的挑战上适用度较大/较小。"

### How to Judge Overall Usefulness

- If source **LACKS** key information/powerful evidence for the claim, or data relevance is weak -> **适用度较小**
- If source **HAS** key information/powerful evidence, or data directly addresses the claim -> **适用度较大**

### Scoring Tiers

| Tier | Marks | Description |
|------|-------|-------------|
| Tier 3 | 6-8 | Comprehensively evaluate BOTH effectiveness AND limitations using own knowledge and/or other sources |
| Tier 2 | 3-5 | Evaluate effectiveness AND/OR limitations using source content and origin |
| Tier 1 | 1-2 | Describe source content only |
| 0 | 0 | No merit |

### Key Rules

- Use source information as primary evidence when arguing strengths/limitations; own knowledge and other sources as supplementary
- Question asks "Is the source useful?" NOT "Do you agree with the source?" - do NOT evaluate whether the source's viewpoint is correct
- Directly compare the claim with the source to find key strengths and weaknesses
- **MUST** have clear big/small usefulness judgment - CANNOT say "moderate usefulness" or "to a certain extent useful"
- Do NOT contradict yourself - don't say "useful" for strengths then "not useful" for limitations

### Past Questions

| Source | Question |
|--------|----------|
| SEAB Sample | 若要解释中国提升软实力面对挑战，试评价资料C的适用度。|
| 2024 A-Level | 若要解释中国推动全球经济治理体系改革面对的挑战，试评价资料C的适用度。|
| 2024 HCI Prelim | 若要解释中国推动经济结构转型面对挑战，试评价资料C的适用度。|
| 2024 EJC Prelim | 若要解释中国司法改革面临挑战，试评价资料C的适用度。|
| 2024 DHS Prelim | 若要解释中国与亚细安关系面对的挑战，试评价资料C的适用度。|

## 4.4 - 1(d) 资料是否支持论点 (Do Sources Support the Claim?) - 12 marks

**What's tested**: Evaluate whether 3 sources support a given statement about government efforts.

### Two Answering Methods

#### Method 1

1. **Positive argument**: Analyze how all 3 sources CAN demonstrate the claim
   - Identify content supporting the claim + use own knowledge to analyze from logic/evidence perspective
2. **Negative argument**: Analyze how all 3 sources CANNOT/insufficiently demonstrate the claim
   - Entry points: (a) Source content lacks relevance, doesn't directly demonstrate government efforts/results; (b) Source mentions government efforts' insufficiency/limitations/challenges, indirectly showing efforts are ineffective
3. **Comparative analysis**: Compare what CAN and CANNOT be demonstrated, give clear judgment (较大/较小程度上能说明)
   - Compare from: 针对性 (relevance - does source provide key information directly?), 有效性 (effectiveness - do government actions/results support the claim?)

#### Method 2

1. Analyze each source individually from both positive and negative sides:
   - Source C (can/cannot demonstrate)
   - Source D (can/cannot demonstrate)
   - Source E (can/cannot demonstrate)
   - Note: Do NOT make degree judgments at this stage
2. Comparative analysis (same as Method 1 Step 3)

### Scoring Tiers

| Tier | Marks | Description |
|------|-------|-------------|
| Tier 3 | 9-12 | Evaluate sources + use own knowledge to make reasonable judgment about degree of support. Weaker answers in this tier are less comprehensive |
| Tier 2 | 5-8 | Evaluate relevant parts of sources, can use own knowledge, but evaluation quality is mediocre |
| Tier 1 | 1-4 | Describe relevant content from sources |
| 0 | 0 | No merit |

### Key Rules

- Analyze whether sources CAN DEMONSTRATE efforts, not whether you agree with the efforts
- Suggested phrasing:
  - [Positive] "资料C、D、E在说明中国政府在......的努力上，其优点如下..."
  - [Negative] "资料C、D、E在说明中国政府在......的努力上，其局限如下..."

### Past Questions

| Source | Question |
|--------|----------|
| SEAB Sample | 资料C，D和E在多大程度上说明中国政府在提升软实力方面所做出的努力？试加以分析。|
| 2024 A-Level | 资料C、D和E在多大程度上说明中国政府在推动全球治理体系改革所作出的努力？试加以分析。|

## 4.5 - Section B: 评价努力+建议题 (Evaluate Efforts + Propose Suggestions) - 25 marks

> **IMPORTANT**: This question type appeared since 2017. From 2017-2023 it was worth 15 marks. From 2024 onwards it is worth 25 marks.

### Steps (Repeat TWICE for 2 complete sets)

**Step 1: 指出政府的努力** (Identify government effort)
- MUST come from sources (specify which source)
- Entry points: 顶层设计 (national strategic planning), 制度建设/优化 (institutional building), 政策颁布及实施 (policy implementation)

**Step 2: 解释政府的努力** (Explain government effort)
- Explain reason/purpose/background using sources and/or own knowledge
- Keep brief - focus weight on evaluation and suggestions

**Step 3: 评价政府的努力 + 提出建议** (Evaluate + Propose suggestions)

① **Affirm achievements** (积极效应或成绩, must have evidence)

② **Identify shortcomings** - Entry points:
- 资源分配不均
- 政策制定或执行力不足
- 制度建设缺失或滞后
- 管理监管不力
- 权责边界不清/分工模糊
- 应急反应迟缓
- 公众参与不足

Useful vocabulary: 治标不治本, "上有政策，下有对策", "头痛医头，脚痛医脚", 缺乏长效机制, 政策失灵, 效果不彰, 实施效能不尽人意/低于预期, 产生副作用

③ **Propose specific suggestion** targeting the shortcoming
- Must be: specific, targeted, suited to China's national conditions
- Must be ORIGINAL (not copied from sources; if referencing source suggestions, must creatively transform them)
- Category-specific suggestion guidance:
  - **Economic**: 理清政府与市场边界 (efficiency), "提质增效升级" (productivity)
  - **Political**: 权力分配 (财权/事权) and 权力运行 (问责/监督)
  - **Policy**: 决策、执行、监督
  - **Governance**: 赋权社会, 创建制度化/非制度的利益表达机制/政治参与机制 (connect to 知情权、表达权、参与权、监督权 and 获得感、幸福感、安全感)
  - **Diplomatic**: "创造利益交汇点/扩大共同利益", "通过外交斡旋/第三方调节来管控分歧"

**Step 4: 分析建议落实 + 评价建议** (Analyze implementation + Evaluate suggestion)

① How to implement (分步骤, 分层面, 分领域, 分责任主体)

② How it solves the problem / how effective

③ Critical analysis:
- **可行性** (Feasibility): 实施方式, 实施渠道, 利益主体, 各类资源的支持度
- **有效性** (Effectiveness): 针对性, 作用力 (治标/治本), 时效 (长短期效应), 成功案例
- **局限性** (Limitations): 建议本身副作用/不够全面, 不利条件/挑战 (制度因素, 人为因素)

④ **获得成功的可能性**: Overall judgment combining feasibility, effectiveness, limitations
- Template conclusion: "综上所述，建议获得成功的可能性还是较大的。短期来说，可能无法立竿见影/一蹴而就/标本兼治...但能获得阶段性成果。长期而言，随着建议的深入实施，改革红利/制度红利/政策红利释放，建议的长期效应会愈趋显著。因此，我对建议的成功抱有谨慎的乐观。"

### Scoring Tiers

| Tier | Marks | Description |
|------|-------|-------------|
| Tier 5 | 21-25 | Comprehensive evaluation using ALL sources + own knowledge, provide suggestions, explain effectiveness from both reasoning and measures. Better: detailed evaluation of success probability. Weaker: lack clear connection between suggestions and topic evaluation |
| Tier 4 | 16-20 | Evaluate topic + provide suggestions using sources and own knowledge. Better: comprehensive and well-reasoned. Weaker: low quality evaluation, insufficient elaboration |
| Tier 3 | 11-15 | Limited evaluation using sources and own knowledge. Better: provide general suggestions. Weaker: no suggestions |
| Tier 2 | 6-10 | Explain the topic using sources and own knowledge |
| Tier 1 | 1-5 | Describe the topic using sources and own knowledge |
| 0 | 0 | No merit |

### Key Rules

- "评价政府努力+建议" is ONE complete set - must do **2 sets** total
- "评价努力" and "建议" carry **EQUAL weight**
- Government efforts **MUST** come from sources
- Suggestions must be **ORIGINAL**
- Suggestions and government efforts must be logically connected - suggestions target the shortcomings identified
- Common student mistakes:
  1. Government effort not from sources
  2. Use "中国政府应该" instead of "我建议"
  3. Suggestion drifts from the question's target

# 5. 问答题题型 Essay Question Types

*30 marks each*

## Universal Structure: 正-反-合 (Thesis - Antithesis - Synthesis)

1. **界定关键词 + 表明立场** (Define key terms + State position)
2. **立场分析 [正]** (Thesis: support your position)
3. **平衡分析 [反]** (Antithesis: counterpoints - use "有人认为"/"有不同学者表示" to introduce)
4. **比较分析/程度判断 [合]** (Synthesis: Compare, refute counterpoints, reaffirm position - recommend refuting each counterpoint individually)
5. **批判性总结** (Critical conclusion)

---

## Sub-Type 1: 是非题 (Yes/No Judgment)

**Keywords**: 是/能(够)/有助于/威胁了/已经/将/势必/应该/可以(难以)/正在/在很大程度上(作用)

### If AGREE with statement:
- **立场分析**: Argue the thesis (same direction as your position)
- **平衡分析**: Find direct opposite (self-refutation based on topic keywords, no external factors needed)
  - "是" -> "不是"; "可以" -> "不可以"; "有助于" -> "无助于/不利于"; "威胁了" -> "没有威胁"; "将/势必/已经" -> "不会/没有"
- **比较分析**: Compare both sides, determine which has greater influence, result must align with your position

### If DISAGREE:
Simply swap 立场分析 and 平衡分析

## Sub-Type 2: 最字题 (Superlative/Most Important Factor)

**Keywords**: 最大/最重要/最根本/最关键/最严峻

> **IMPORTANT: Agree and Disagree have DIFFERENT structures**

### If AGREE (the factor IS the most important):
- **立场分析**: Analyze the topic factor
- **平衡分析**: Introduce 2 OTHER factors and analyze them
- **比较分析**: Compare topic factor with the 2 other factors, highlight why topic factor is the most critical

### If DISAGREE (the factor is NOT the most important):
- **立场分析**: ① Point out why topic factor is NOT the key factor (limitations); ② Introduce 1 factor you believe is MORE important than the topic factor (don't need to claim it's THE most important - just argue it's more important than the topic factor)
- **平衡分析**: Analyze the topic factor (its merits)
- **比较分析**: Compare your proposed factor with the topic factor, explain why the topic factor is not the most critical

## Sub-Type 3: 因素是非题 / 关键题 (Key Factor)

**Keywords**: 关键/根源/罪魁祸首/重中之重/至关重要/动力源/主要是...造成的

> Answer primarily as 是非题, but can bring in 1 external factor when refuting. Self-refutation is primary; external factors are supplementary.

### If AGREE:
- **立场分析**: Analyze why topic factor IS the root/key cause
- **平衡分析**: (Self-refutation primary, external factor supplementary) ① Topic factor is NOT the root/key (重点); ② Introduce 1 other factor (辅助, not required)
- **比较分析**: ① Compare factor's effects vs limitations -> effects > limitations; ② Compare topic factor vs other factor -> topic factor > other factor

### If DISAGREE:
- **立场分析**: ① Argue topic factor is NOT the root/key (重点, show limitations); ② Introduce 1 factor you consider more important (辅助, not required)
- **平衡分析**: Argue topic factor IS the root/key
- **比较分析**: ① limitations > effects; ② other factor > topic factor

## Sub-Type 4: 程度题 (Degree/Extent)

**Keywords**: 在多大程度上（推动/提升/阻碍/加剧/影响）

### Two Sub-Variants

**Variant 1: A在多大程度上(作用了)B？**
- 较大程度: 立场=A's positive effect on B; 平衡=A's limitations on B
- 较小程度: 立场=A's limitations on B; 平衡=A's positive effect on B
- 比较: Compare positive effects vs limitations, determine degree

**Variant 2: A在多大程度上影响了B？**
- First determine: single-direction impact or dual-direction impact

*Single-direction:*
- 立场: Analyze the single-direction impact (usually negative)
- 平衡: Find counter-balancing factors
- 比较: Compare impact vs counter-factors

*Dual-direction:*
- 立场: Analyze both positive AND negative impacts
- 平衡: Acknowledge impact isn't absolute, analyze limitations and counter-factors
- 比较: ① Compare positive vs negative impacts; ② Compare overall impact vs limitations

## Sub-Type 5: 条件题 (Prerequisite/Condition)

### 必要条件题 (Necessary Condition)

**Keywords**: 必须...才能/只有...才能/要...就必须/唯有/如果不...就无法

**If AGREE (it IS a necessary condition):**
- **立场分析**: Argue the importance/indispensability of the condition
- **平衡分析**: ① "即使没有(condition)...也能(achieve result)" - remove the condition, argue with historical/current facts; ② "即使有(condition)...也不足以(achieve result)" - condition has limitations + other paths exist
- **比较分析**: Emphasize the condition's irreplaceable role by comparing its role vs limitations and comparing with other factors

**If DISAGREE:**
- **立场分析**: ① Even without the condition, result can be achieved (客观事实); ② Even with the condition, it's insufficient (局限+其他因素)
- **平衡分析**: Argue the condition's positive effects toward the result
- **比较分析**: ① Limitations > effects; ② Other factors more significant

### 充分条件题 (Sufficient Condition)

**Keywords**: 只要...就能

Usually DISAGREE (single condition rarely sufficient):
- **立场分析**: ① Explain limitations of the condition; ② Explain other important factors needed
- **平衡分析**: Acknowledge the condition's value/positive role
- **比较分析**: ① Compare effects vs limitations (emphasize insufficiency); ② Highlight other factors' importance

# 6. 问答题评分标准 Essay Scoring Criteria

| Dimension | Tier 5 (25-30) | Tier 4 (19-24) | Tier 3 (13-18) | Tier 2 (7-12) | Tier 1 (0-6) |
|-----------|----------------|----------------|----------------|---------------|--------------|
| 切题 (Relevance) | Fully on-topic | Mostly on-topic | On-topic but unclear | Off-topic | Irrelevant |
| 结构 (Structure) | Rigorous | Complete, coherent | Could be better organized | Incomplete, contradictory | Scattered |
| 深度 (Depth) | Deep + cross-topic | Deep + comprehensive | Lacks depth | One-sided | No understanding |
| 论证 (Argumentation) | Analysis-driven | Balanced | More description than analysis | Off-topic | Irrelevant |
| 论据 (Evidence) | Accurate + powerful | Appropriate | Mostly appropriate | Has evidence but off-topic | No evidence |

### Critical Scoring Caps

- No 平衡分析 = **max Tier 3 (18)**
- No 跨课题 = **max Tier 3 (18)**
- No 平衡分析 AND no 跨课题 = **max Tier 3 (15)**

# 8. 概念说明 Key Concept Definitions

*From Syllabus*

## Economic Concepts

**经济发展**: A process where a country/region's economy grows, improving people's economic and social living conditions. Involves GDP growth plus various social development indicators.

**经济增长**: Process of sustained increase in production value and income due to improved productive capacity.

**经济可持续发展**: Long-term strategy that pursues development while minimizing harm to natural resources, environment, and future generations' welfare.

**经济自由化**: Process of government reducing regulations on economic activities - includes free trade, deregulation, privatization. China uses "经济市场化" instead.

## Political Concepts

**政治稳定**: State where people's political behavior is constrained by the ruling party's system and they don't seek to overthrow/replace the government. CPC views perfecting the party-state system and maintaining territorial unity as strategies for political stability.

**国家治理**: Process of government managing society through national/local administrative, constitutional, and judicial organs.

**政权合法性**: Government's authority to manage and regulate a defined territory. Sources include ideology, history, national identity, and performance. CPC's legitimacy has two sources: performance and ideology.

**意识形态**: A set of values/concepts for understanding the world. China's ideology: Chinese socialism + national nationalism. Both the CPC's worldview and basis for domestic/foreign policy.

## Social Concepts

**社会转型**: Deep changes in social structure and cultural forms. Social structure = relationships between different groups; cultural forms = shared life experiences including values, beliefs, social norms.

**社会稳定**: State where all members' basic needs are met with no systemic social unrest. Chinese government views social stability as the cornerstone of economic development.

**社会治理**: Government management of social issues to maintain social stability.

**公民社会**: Private organizations/associations organized by people for common goals, not part of government. Since 1978, many NGOs emerged as government withdrew from public services.

## International Relations Concepts

**主权**: A sovereign state's jurisdiction over its territory, free from interference. Core interest for China - expressed in border sovereignty defense and "non-interference" principle.

**安全**: State where national territory and sovereignty are free from internal/external threats. Military modernization is key for China's maritime territorial security.

**冲突**: Opposing state resulting from different goals or competition between 2+ countries. Can manifest as war, economic competition, or diplomatic conflict.

**合作**: Policy coordination between countries to achieve common interests. Despite firm stance on core interests, cooperation and multilateralism remain China's foreign policy fundamentals.

### Essay 1: "依赖投资驱动的增长策略不利于中国经济的可持续发展。"试加以讨论。

- **Question type**: 是非题
- **Topics covered**: 课题一 (投资驱动, 经济结构), cross-topic: 课题二 (央地关系), 课题三 (少数民族管理)

---

投资驱动型经济增长策略主要指的是一个国家或一个经济体的经济发展主要依靠资本的投资项目获得增长，而其他如消费则在经济增长中比例小。中国在2008年世界金融危机爆发之后，主要通过扩大投资与扩大生产规模，以保证产品成本的优势，保持本国企业在国际舞台上所有的竞争力。资本对中国的总体GDP增长的贡献率长期保持在20%-30%左右。

可持续发展是一种注重长远发展的经济增长模式，其目的是为了实现在社会、生态、经济等方面共同协调发展，既要满足当代人的需求，又不要对后代人满足其自身需求的能力构成危害的发展。自1979年中国改革开放以来，中国凭借着巨大的出口红利和强有力的投资拉动，推动中国于2010年成为世界第二大经济体。虽然当下中国经济增长已经放缓，但投资驱动策略给中国经济带来的稳定性、以及在推动产业结构优化、提升人民的生活水平所发挥的作用则是有目共睹。

笔者认为依赖投资驱动的增长策略不利于中国经济的可持续发展。

首先，中国在通过投资驱动来实现缩小城乡差距与提升国民的生活水平的过程中，由于基础建设投资过大，回收期较长，而导致地方政府债务上升，银行风险增大。为了提升公共服务的效率与国民的生活水平，中国各地政府纷纷通过加大基础设施和产业的投资，发展各个领域，例如交通运输、信息产业、能源产业与房地产等。从2003年到2008年的6年间，全国基础产业和基础设施建设投资总额246770亿元，年均增长24.5%，比同期国民经济年均增长速度高8个百分点。但是，由于1994年分税制后中央与地方政府"分灶吃饭"，地方的经济建设和公共产品的支出主要来自地方政府的财政收入，但目前地方政府大多财力不足，"囊中羞涩"，其投资主要依靠银行信贷支持的，而投资效率过低意味着贷款银行信贷支撑的增长，而投资不能收回，意味着银行贷款还不了，导致金融系统风险的积累。再加上，由于中央政府运用政绩来考核地方政府，而地方政府为了GDP的增长，于是拼命加大投资，包括一些低效的有污染的投资，导致政府的财务赤字不断上升，既加剧了中央与地方之间的博弈，更不利于中国经济的可持续发展。【跨课题：政治：央地关系】

其次，目前中国投资结构仍然不合理，具体表现在"一产投资少，二产投资热，三产投资结构不平衡"。长期以来政府的投资大部分在第二产业中，而且是中长期的投资，中国吸引的外商直接投资约70%集中于制造业。许多地区的投资依旧集中在重化工业和房地产中，使得中国产业结构出现了"低度化"和"同构化"现象，无法促进产业升级。除了第二产业以外，第一产业因无法得到足够资金而造成发展缓慢，无法有效地把农业融入整体产业链。同时，第三产业投资虽有增加但内部不均衡问题也为突出，金融业、科技研发等生产性服务业以及批发零售等生活性服务业投资不足，公共服务、社会保障方面的投资更是不增反减。由此可见，由于中国投资结构不合理，使得产业结构从低水平状态向高水平状态升级速度缓慢和在低水平上徘徊的趋势，无法促进中国经济朝高质量方向发展。【跨课题：政治：央地关系】

再次，除了投资结构不平衡，中国的投资流向也加剧了区域发展不平衡，贫富差距显著，不利于中国经济可持续发展。由于各地区资源的丰富程度和组合不同，各地的产业结构和经营管理水平也不同，因此各地经济增长潜力不同，从而引起了投资环境的不同，资金和人才等往往会被吸引到区域条件好的地方，因为在那些地区的发展潜力大，资金投入的回报率高。这就形成了"马太效应"，使得富的更富，穷的更穷。虽然近年中央政府开始关注如何缩小区域差距，尝试通过"西部大开发"的研发主导，但实际上如今经济资产仍然偏向于东部沿海发达地区。内陆民族地区仍然存在着资金、技术、与人才等严重不足的问题，由于收入存在着很大的差距，这容易造成落后地区尤其是部分少数民族地区的人们的心理不平衡，产生妒忌和不满等情绪，在"三股势力"的鼓动下，引发"7.5事件"等民族分裂等群体事件，为社会安定带来危害。【跨课题：政治：少数民族管理】由此可见投资驱动策略无法确保中国社会的稳定和经济可持续发展。

然而，有人认为中国运用投资驱动增长策略有利于固定资产投资持续增长，对经济可持续发展起到了稳定器的作用，为满足民众日益增长的美好生活提供坚实的支撑与保障。改革开放以后，中国利用投资，使得固定资产呈现高速增长的态势，全社会固定资产投资年均增长21.1%以上。在2019年，投资对中国GDP的贡献达成31.2%，投资增长有效拓展了经济社会的发展空间，目前中国已成为拥有全部工业门类、200多种工业品产量居世界首位的制造业大国，交通、通信等基础设施实现从瓶颈制约成为中国的优势支撑和国际名片，继续引来外商投资。可见，投资驱动有能力保持经济平稳的增长，也不断扩展生产能力，带动城乡居民的消费，满足人民的需求。

另外，还有些人认为，投资驱动有利于改善城乡居民的居住条件，从而缩小城乡差距。随着新型城镇化的发展，更多农村居民开始流城市工作，而最终决定在城市居住。随着户籍制度的改革，城市居民的住房需求也在增加，尤其流动人口与城市中下层民众。他们既要买得到房子、又要买得起房间，故对与住房保障工程的投入加大，有利于多层次住房保障体系的形成。2020年，房地产开发投资比上年增长7.0%，其中住宅投资增长7.6%，说明商品住宅建设的快速发展，促进了现代城市的发展，有利于提高居民的生活水平，也确保城市居民能够拥有宜居的居住环境。

尽管如此，笔者依然认为依赖投资驱动的增长策略不利于中国经济的可持续发展。

不可否认，投资驱动型策略的确有利于巩固基本经济发展，但是长期来看，投资驱动结构不合理的问题给经济与环境带来危害，实际上弊大于利。由于长期以来中国主要依赖生产要素投入，重是"粗放型"经济增长规模，不仅商品的附加值低，而且产生大量的大气污染，加剧已存在的环境问题，给人们身体健康带来危害，也抵消了经济发展带来的成果由此可见，投资驱动策略发展至今所带来的利益已经逐渐减少，相反它所产生负面影响却无法实现社会、生态、经济"三位一体"等方面的共同协调发展。

此外，虽然投资驱动型策略确实有利于改善城乡居民的居住条件，但随着各个层级城市房价上涨的趋势，社会底层的民众并不一定能够买得起房子，无法享受投资驱动所带来的利益。2022年中国人均GDP按平均市场汇率来算12741美元，虽说整体恩格尔系数下降，但由于城乡二元化结构的限制、导致很多民众只能把大部分的收入花在基本的消费支出上，无法买得起不断高涨的房价。此外，即使社会中产阶级能够买得起房子，但是由于社会保障体系的不完善，人民因为为基本保险而担忧，抑制了他们的消费倾向。由此可见，投资驱动所带来的压力的确无法真正实现经济可持续发展。

因此，总的来说，中国长期以来实施的投资驱动型经济增长模式的确促进了国家的经济发展。但随着国家快速发展，中国政府必须确保本国拥有足够与良好的基本设施承担投资驱动所带来的其他影响，例如如何调整投资结构本身的不均衡与区域发展的不协调。所以，笔者认为投资驱动策略在未来社会、环境与经济方面无法确保给中国带来整体的可持续发展，中国需要改变经济增长的策略，从出口、投资到消费驱动，朝消费型社会迈进。

### Essay 2: "国有企业改革不力是中国经济发展面临的最大挑战。"试评价上述观点。

- **Question type**: 最字题
- **Topics covered**: 课题一 (国有企业改革), cross-topic: 课题二 (贪腐, 党国体制), 课题四 (中美关系)

---

国有企业改革包括完善现代企业制度、"抓大放小"、国有资产管理体制、混合所有制改革等。国企改革身为经济改革的中心环节，通过实现公有制与市场经济的有效结合，使国企形成适应市场经济要求的管理体制和经营机制，提高国有企业的竞争力和效率，增强国有经济的活力、控制力、影响力、抗风险能力等，从而建立和完善社会主义市场经济体制，推动中国经济的发展。然而，虽然目前国企改革的确取得了一定进展，但国企改革在推进过程中仍遇到瓶颈，对其改革效益构成阻力，限制了中国经济的发展，因此我认为国企改革不力是中国经济发展面临的最大挑战。

首先，国企改革改革不力，导致了国企对要素市场的高度垄断，降低了民营企业的市场竞争力。国有企业是政府干预经济的重要手段，在关系国家安全、经济命脉等国计民生的重要行业和关键领域，例如中国电力、石油、通讯、金融等，被国企主导甚至垄断。但国企虽然获取巨额垄断利润，失去创新动力，大而不强，效率和竞争力不足。国企垄断不利于多元市场主体在市场中公平和诚实地进行竞争，而公平竞争是市场经济的基本特征，但中国国企改革不力所导致的在某些关键领域的高度垄断，无法确保市场优胜劣汰的公平竞争，阻碍了中国市场经济的构建，难以促进中国经济健康发展。

其次，国企改革的中的混合所有制改革，面临"不愿混、不敢混、不真混"的挑战，不利于中国经济健康发展。因过去国企处于高位垄断、受到政府的照顾，因此在混改过程有些国企只想着"一股独大"，"绝对控股"，导致民企"不愿混"的问题。另外，因国企和民企等在管理、制度、监管约束等方面存在差异，导致双方都有顾虑而"不敢混"问题。而同时因在法律意义上，混改还没有真正的市场定位和独立定位，管理上往往照搬国企的办法，既没有机制上的互补，又存在着管理上的冲突，企业活力发挥不出来，导致"不真混"问题。鉴于这些种种矛盾与挑战，使得许多企业对混合所有制改革不积极、不利于各种所有制资本取长补短、相互促进、共同发展，最终导致国企无法更广泛地吸纳非国有的社会资本，难以扩大国有经济的辐射范围，不利于国有资本放大功能、保值增值、提高竞争力，限制了经济发展。

最后，国有企业改革过程中仍存在监管不力的问题，央企腐败案件频发，因此对中国的经济发展构成阻力。当前国有企业监督制度形成了多元监督主体并存、多种监督机制同时发挥作用、监督效果评价标准多样化的多元监督体系，虽然在某种程度上克服了单纯一元监督制度的缺陷，但从实践监督效果来看却差强人意，国有企业依旧未能摆脱"一管就死，一放就乱"的顽症。多元监督主体互动过程中、多元监督机制协同中以及多元监督目标整合中没有能够实现"无缝连接"的有效监督，甚至出现"多头监督"的局面，并没有真正能够让多元监督协同发力和达到多元监督所形成的强大合力监督力量。例如，中央巡视组就指出央企存在着大量问题，任人唯亲、领导寻租、用人腐败、流失国有资产等，种种都表明现行的国有企业监督管理体制仍然有很大的漏洞，十分不利于中国经济的健康发展。【跨课题：政治：贪腐】

但也有人认为国企改革已取得相当的成效，不是中国经济发展的最大挑战。相反的，他们认为区域发展不平衡才是中国经济发展的最大挑战。中国城乡之间和区域之间发展不平衡仍然明显，使得中国经济增长内生动力不足，从而制约经济发展。据中国国家统计局数据显示：2020年，上海成为首个居民人均可支配收入超过7万元（人民币，下同）的城市，而排在最后的甘肃只有2万元，中国在同年的人均可支配收入为32189元，然而只有9个省份超过全国平均线，中西部无一省份入列，即使这个平均收入数仍远低于发达国家人均可支配收入的5万元的水平。中国社会的两极分化不利于统一经济市场的建构和消费市场的发展，阻碍了中国高质量的经济发展。另外，区域和城乡之间收入的差距也会导致民众心理的不平衡，进而可能引发"仇富、仇官"等现象从而影响社会稳定。而社会的稳定与和谐是经济发展的基础，因此区域发展不平衡才是最大挑战。

另外，也有人认为能源问题才是中国经济发展最大挑战。2020年，中国原油对外依存度近70%，超过50%的国际警戒线，天然气对外依存度也超过40%。但是，一方面中国能源供应过于集中，多在中东等地缘政治不稳定区域，供应安全风险很大。另一方面，中国石油海上运输航线大部分都需经过由美国控制的马六甲海峡。由于中美在未来发展主导权和亚太地域安全控制权上的博弈日益加剧，中国能源运输安全风险增大。【跨课题：外交：中美关系】而能源是中国经济运行和发展的最基本要素，因此能源供应上的不稳定会直接影响经济的发展，导致中国的经济发展难以为继。

然而比较而言，我还是认为国企改革不力是中国经济发展面临的最大挑战。就解决难度而言，区域发展不平衡和能源问题已得到政府的关注，并取得了巨大进步，对中国经济发展而言不再是棘手问题。而国企改革遭遇结构性挑战，难度远超前二者。

为解决区域发展不平衡问题，2000年中共做出西部大开发战略决策、后来又陆续推出振兴东北老工业基地、中部崛起等战略，促进区域协调发展，卓有成效。如1999年西部地区生产总值为15354亿元，到2019年西部地区生产总值跃升为为205185亿元，提升了13倍。就基础设施而言，一系列重大基础设施如青藏铁路、西气东输、西电东送的建成，"一带一路"等大大增强了中西部地区的长远发展潜力，也强化了与东中部的联系。

中国政府也通过能源国际合作和能源科技创新，有效缓解了能源问题挑战。一方面，中国通过能源合作，油气进口越来越多元化，从中东地区扩展到俄罗斯、东非、中亚等地区，同时通过科技创新，大力发展风能、太阳能等清洁能源，再生能源以及其他能源的占比则从2000年的7.3%提升至2019年的15.3%。另一方面大力推动绿色发展战略，中共在"十三五"规划明确提出了"绿色发展"理念，建设资源节约型以及环境友好型的社会。因此，通过能源科技创新和能源国际合作，缓解能源压力，确保了能源安全。

与之相对应，国企改革的难度远超区域发展不平衡和能源问题。从经济学角度来看，区域发展不平衡和能源问题是技术性问题，通过加大投入就能有效缓解。但国企改革是结构性问题，其解决难度大。其中最大的结构性障碍是国企与政府的定位不清。政府对国企兼具"出资人"身份和"监管者"的双重身份，国企也具"公益性"与"企业性"双重属性，"企业"属性要求其注重经济效益，以获取利润为其本职工作；"国有"属性则要求其生产或提供公共产品，发挥其"公益性"特质。政府的双重身份、国有企业的双重属性，使得政府在面对国有企业改革时，在"放权"与"收权"间摇摆不定，政府与企业的边界不清，产权不明确，责权利不清晰。尤其是在当下"东西南北中，党是领导一切的"政治语境下，党的领导被视为国有企业的"根"和"魂"，政企不分，国企的现代企业制度改革举步维艰陷入停滞。【跨课题：政治：党国体制】另外，虽然中国政府在解决区域发展不平衡和能源问题过程中不无挑战，但这些改革是增量改革，改善能源问题和发展不均对大家来说都是有利的，因此反对力量不大。但是，国企改革是减量改革，要建立公平竞争的市场机制势必将消解国企的垄断地位，这无疑触犯了既得利益集团的利益，他们出来阻碍政府改革的努力，导致国企改革阻力重重，大大削弱其对中国经济发展的促进作用。

因此，我仍认为国企改革不利是中国经济发展的最大挑战。

### Essay 3: "政企不分是国企改革不力的症结。"你同意这个观点吗？

- **Question type**: 是非题
- **Topics covered**: 课题一 (国有企业改革), cross-topic: 课题二 (党国体制), 课题四 (经济外交)

---

国企改革指的是中国政府为了增强国企活力、提高国企经济效益和市场竞争力以及推动国企可持续发展的一系列改革，包括现代企业制度改革、抓大放小、国有资本管理改革和发展混合所有制经济，使国企能良好适应现代市场经济。然而，国企与政府不分家在很大程度上制约了国企改革的效益。

我认为，政企不分是国企改革不力的症结。

首先，政企不分导致国企无法在公平竞争的市场环境中开发出企业效率和创新精神，造成其内生动力不足，因此成为国企改革不力的症结。国有企业是计划经济的产物，被喻为中共的钱袋子和共和国长子。国企的国有属性导致政企不分，央企的一把手都由中共中央组织部任命，其运营、投资和管理由政府主导。由于当下中国的政治语境是"东西南北中，党是领导一切的"，使政府的介入严重干预了以法治为核心的市场公平竞争机制，国企可以依靠政府获取市场项目，赚取垄断利润，即使亏损也都由政府兜底，使市场无法发挥资源配置的角色，国企不思进取，大而不强，甚至沦为僵尸企业。如武汉钢铁集团就是体量庞大的"僵尸国企"，2015年亏损75亿元，被业内称为央企中的"亏损王"。国企被束缚在温室中，不能在市场的残酷竞争中磨练，难以开出企业积极性和创新精神，不利于国企实现创新驱动并将其企业竞争力有效释放。【跨课题：政治：党国体制】

其次，政企不分造成了国有企业定位模糊，不能成为真正的市场主体，因而构成国企改革不力的症结。政府对国企的控制和指挥导致国企承担过多的战略性政策负担，阻碍了其盈利能力，不利于国企经济效益的改革。一党专政作为中国的政治体制，其一项优势便是能帮助中国进行可持续的顶层设计和超前的战略部署，而将其付诸实践的过程中，国企扮演了举足轻重的角色。政府为国家整体利益的考量指导国企投资不具备比较优势的资本密集型产业，这类领域（如基础建设、军工研发）投资大且回报慢，对其的投资往往意在于长远服务中国的国家利益，而非在短期赚取回报。战略负担导致了国企与企业追求盈利的理念背道而驰，沦为政府政策的代言人，国企的投资难以在短期内收获回报，不利于其经济效益的改革。因此，政企不分使国企的定位游离于政府附属部门和商业化的企业间，两头不讨好，最终导致两头空。

再者，政企不分严重阻碍了商业类国企的混合所有制改革，成为国企改革不力的症结。国企改革中的重要项目便是让民营企业参股国企，通过民间资本的引入形成外界股东监督，确保国企在经营上以利润最大化为目标，推动其成为市场主体。然而，政企不分下，政府利用公权力指导国企软硬兼施大规模吞并民企，不但没能将国企真正市场化，还引发大量民间资本担心被并入国企从而选择"润"出国，据统计2022年有1万名民营企业家将从中国带出480亿美元资金，中国是仅次于俄罗斯的第二大财富和人口外流国家。而这进一步恶化国企垄断地位，造成国进民退。政企不分下，混改的失败及其带来反噬使国企在市场上缺乏竞争对手、在经营上缺乏外界监督，同时政府通过行政手段的干预进一步遏制了市场上的公平竞争，令国企难以真正发挥商业价值和创新动力，限制了其竞争力的上限。因此，政企不分是国企改革不力的症结。

然而，有学者指出，正是因为政企不分才使国企得以汇集资源、提高国企的经济效益，并没有阻碍国企改革。国企掌控了关系到中国国家安全的关键产业，央企80%的资产都集中在国防、能源以及通信等领域，成为中国的经济命脉。正因如此，政府为保障国家经济命脉的稳定会持续支持国企、为其撑腰，在增强国企抗风险能力的同时不断让其做大。例如，2008年金融危机中，中国的四万亿救市计划中大量资金都流入国企，帮助国企抵御难关；而高铁、基建等重大项目也是国企优先。目前世界500强企业中20%的企业为中国企业，而其中八成又是政府控制的国企。全球前十大银行中，中国就拥有5席。因此，政企不分使资源通过政府配置向国企倾斜，帮助国企做大，让国企有资本在全球化的市场中与外敌竞争，实际上有利了国企的经济效益和市场竞争力，并没有阻碍国企改革。

也有观点认为，在中国一带一路对外输出影响力的战略下，政企不分使国企为满足政府战略目标，能牵头政府主导的重大外交项目，提升其国际化水平和国际竞争力，在一定程度上促进了国企改革。例如，在一带一路中，国企是主力军和领头羊，参与沿线项目超过3400个，有力带动中国装备、服务以及技术标准"走出去"，从而提升国企的国际化水平和国际竞争力。央企境外单位超过1.1万户，分布在全球185个国家和地区，2019年境外资产总额为7.6万亿元，利润1318.9亿元。正是因为政企不分，中国才能要求国企参与一带一路的境外项目，倒逼国企走向开放的世界，成为中国推进"一带一路"经济外交的主力军，在国际风浪中积累宝贵"走出去"的经验，提质增效，提升市场竞争力。因此，政企不分不是国企改革不力的症结。【跨课题：外交：经济外交】

相比之下，我还是认为政企不分是国企改革不力的症结。

首先，虽然政企不分下国企被认为能通过政府支援"做大"，但国企始终"大而不强"。即便政企不分使国企能在短期内收获巨额利润，并为国企撑腰提供其在市场上竞争的资本，但从长远来看，政企不分却始终无法将国企"做强"。政企不分下，国企永远是温室中的花朵，靠着政府的支持攻城略地，最终只会形成"内斗内行，外斗外行"的局面。国企缺乏自力更生的能力，一旦失去了政府的扶持，在市场上将无立足之地。

其次，虽然政府能帮助国企在国际上获取项目，但由于国企资本缺乏外界资本监督、花公家钱无所忌讳，同时预算软约束，投资时往往风险评估不足，导致大量工程烂尾，使其最终无法收获投资回报。同时，国企在获取机遇的同时也要承担巨大的风险，小国无力偿还贷款、他国政局动荡等不确定因素都给国企海外项目带来了巨大的阻碍。马来西亚政权更替导致的中马高铁合作风波很好体现了外部不确定因素对项目建设带来的巨大风险。因此外部风险给国企的盈利能力和经济效益带来重大挑战，也使国企为完成政府战略考量必须作出投资回报上的牺牲，终究难以获得独立自主的市场地位，改革遥遥无期。

综上所述，政企不分下，国企难以真正走向市场化发挥企业价值，还承担过多战略负担或垄断红利，市场竞争力难以真正被发掘。因此，政企不分是国企改革不力的症结。

### Essay 4: "中国要实现高质量的经济发展，唯有推动绿色发展。"试讨论之。

- **Question type**: 必要条件题
- **Topics covered**: 课题一 (绿色发展, 能源), cross-topic: 课题三 (中产阶级), 课题四 (中国威胁论)

---

绿色发展指资源节约型、环境友好型的"以人为本"的可持续发展，具体实践方式包括循环经济、低碳经济和绿色经济。

高质量经济发展指强调创新、社会进步和生态建设协调的高附加值、可持续的经济增长。

我认为推动绿色发展是中国实现高质量经济发展的必要条件。

首先，推动绿色发展将解决中国的环境与资源瓶颈问题，建立宜居的生态文明，让中国在实现经济增长的同时不牺牲人民的生活质量。目前，中国靠大量生产要素投入来推动经济增长的要素驱动发展模式已经导致能源结构失衡和落后产能过剩，引发大量环境污染，让环境承载和自我修复能力不胜负荷。数据显示，中国每年治理环境污染的费用高达10%的GDP损失，这将增加环境治理成本，减少经济效益，加剧中国经济新常态的下行压力。以上的制约因素说明中国这种要素驱动的发展模式正在面临边际报酬递减效应，已经变得不可持续。推动绿色发展将推动中国从粗放型到集约型的经济发展方式改变，促进传统产业与绿色科技的深度融合，优化落后产能和盘活存量。例如，习近平在十三五时期提出了五大发展理念："绿色"便是其中之一。随着全国更加注重绿色发展，这将能够促进产业的全面绿色化推进低碳发展，达到节能减排的作用。这有助维护生态平衡，在实现经济的高质量发展的同时，不以人民的生活质量和健康水平为代价。

其次，推动绿色发展将促进经济结构调整，创造新的经济增长点，由此带动中国的高质量发展。在"三期叠加"迫使经济面临下行压力的背景下，中国必须将生产方式从劳动密集型转为技术密集型，并将产业结构从第二产业为主转为第三产业为主。在供给端，推动绿色发展将发展以减量化、再利用和再循环为核心的循环经济，提升资源使用效率和全要素生产率，培育高附加值的节约型绿色产业链。例如，根据《中国环保产业发展状况报告（2018）》，2017年中国环保产业营收1.35万亿，比2016年高17.4%。在需求端，推动绿色发展能普及绿色意识，让绿色服务业得以应运而生，由此推动"电子交易+绿色物流"的线上绿色交易模式和"生态旅游+养老+医疗"的产业融合，带动中国的绿色消费。可见，推动绿色发展有助于中国在供给端和需求端发掘新的经济增长点。

不过，有学者认为，即使没有推动绿色发展，中国也能实现高质量的经济发展。目前，中国的中产阶级规模在绝对数字上在世界排名第一（2017年中国中产阶级的规模为2.46亿）。【跨课题：社会：中产阶级】这将形成庞大的消费市场，促进第三产业服务业的发展，推动中国从出口和投资导向的外向型经济到内需拉动的内向型经济的转型，促进经济的健康发展。此外，数据也显示，中国GDP总量为世界第二。相对于其他发展中国家，中国的GDP年均增长也相当可观，保持在4.5-6.5%的稳定水平。可见，中国自身的有利条件已足以实现高质量的经济发展，无须快马加鞭地推动绿色发展。

也有学者认为，中国即使推动绿色发展，也未必能实现高质量的经济发展，原因有二。首先，中国的绿色发展面临技术和市场瓶颈，使得进程举步维艰，无法有效推动中国的高质量经济增长。目前，中国缺乏支撑绿色发展的核心技术，面临低碳技术开发与储备严重不足，与发达国家相比产业体系较薄弱。这将提升中国绿色经济的对外依存度，导致回报周期长和金融风险高，使得投资者望而却步，不利于绿色产业的推动。例如，中国的煤炭产业通过价格优势垄断能源市场，挤压中国的光伏、风电等清洁能源的需求，导致"弃光弃风"现象在2017年分别达12%和6%。长远来看，这将降低绿色发展对推动中国高质量经济增长的效益。其次，推动绿色发展无法为中国实现高质量经济增长创造良好的外部环境，毕竟"中国威胁论"甚嚣尘上，绿色发展作为经济结构调整的宏观政策将难以改变国际社会对中国的刻板印象。【跨课题：外交：中国威胁论】其他国家可能因为对中国的成见和信任赤字而不愿与中国分享关键的绿色技术。例如，美国因为知识产权问题，禁止核心芯片对中国新能源汽车比亚迪的出口。无疑，这会导致中国绿色发展难以突破技术瓶颈。

比较来看，我还是认为中国唯有推动绿色发展才能实现高质量的经济发展。高质量经济增长是建立在社会稳定的基础上。然而，中国目前所面临的环境和资源瓶颈已经引发了诸多环境抗争事件，使得绿色发展的推进迫在眉睫，否则中国的可持续发展将无以为继。再加上，当前中国推进绿色发展是最好的时机，应该善加把握。根据马斯洛需求，随着中国的教育和生活水平不断提高，人民的消费意愿也将从物质消费转向精神消费。这意味着绿色消费的蔚然成风将成为中国市场的必然趋势。近年来，中国政府也已经开始改革官员考核指标。例如，中国长江经济带的核心目标不含GDP，反而包括缓解生态环境问题的考核。这将开出官员对绿色发展的积极性，为绿色发展的推进提供庞大的政策红利。最后，推动绿色发展也能化解"环境威胁论"，维护中国的"负责任大国"形象，为中国赢得国际声望，进一步扩大地缘空间，为高质量经济发展提供有利的外部环境。

总的来看，推动绿色发展虽然面对着一些现实挑战，但目前中国已经具备了克服这些挑战的有利条件。必须承认的是，推动绿色发展能为中国的经济增长创造有力的自身条件和外部环境，并在供给端和需求端带动中国高质量的经济增长。因此，推动绿色发展确实是中国实现高质量经济发展不可或缺的必要条件。

### Essay 5: "推动绿色发展是中国实现高质量发展的唯一选择。" 请加以讨论。

- **Question type**: 必要条件题
- **Topics covered**: 课题一 (绿色发展, 供给侧改革), cross-topic: 课题二 (央地博弈), 课题三 (中产阶级, 社会保障制度)

---

绿色发展是倡导资源节约型、环境友好型的可持续发展模式，以循环、低碳和绿色经济为核心，以推动产业转型和生态建设。习近平倡导"绿水青山就是金山银山"，核心就是绿色发展。

高质量发展不以损害环境为代价，通过产业结构升级、平衡供给端和需求端及提高全要素生产率实现集约型增长。

笔者认为推动绿色发展不是中国实现高质量增长的唯一选择，理由如下：

第一，中国即使不推动绿色发展，也能以其他途径实现高质量增长。首先，中国有4亿中产规模，中产收入较高且稳定，拥有中国32%的财富，人均财富值约为国家人均的三倍。中产消费能力和意愿强，家庭支出是农民的3.4倍，是产业、服务业工人的2.3倍，能担任"消费前卫"。中产消费重心已脱离基础性消费，对生活格调的追求使他们偏向发展型、个性化和享受性消费。这有利于开拓内需市场，缓解经济新常态下三驾马车失衡以及国际市场波动对出口导向型经济的冲击。此外中产对精神文化、旅游、时尚、奢侈品等方面的高需求推动服务业发展和消费结构升级，加速产业结构调整，实现高质量发展。【跨课题：社会：中产阶级】其次，中国积极推进供给侧改革，实现经济软着陆。"去产能、去库存"能解决供给端失衡，减少产能过剩及资源浪费，提高市场经济效率；"去杠杆"的核心是金融改革，减少债务和泡沫经济风险，控制大型金融机构和房地产开发商（例如恒大）构成的"灰犀牛风险"；"降成本、补短板"可减轻中小型企业税负，降低运营成本，释放市场活力，以创新驱动的发展模式提升全要素生产率，实现经济的提质增效。以云南金融供给侧改革为例，生物医药、运输设备制造等新型制造业的长期贷款实现快速增长，2019年末，上述制造业长期贷款余额比年初分别新增9.1亿和6.7亿元，这对制造业升级及解决供给失灵至关重要。因此中国经济能凭借中产优势和其他宏观经济调控实现高质量增长，不必单靠推动绿色发展。

第二，中国推动绿色发展过程中面临技术和制度短板，无法有效实现高质量增长。在技术领域，中国低碳技术自主研发、储备滞后，占全球高附加值低碳专利的6%，科研基础性产业体系薄弱，严重依赖专利转让。随着中美科技博弈升级，美国对华实施技术封锁导致中国绿色发展的核心技术被掐脖，但低碳、新能源科技的自主创新需要时间，因此脱钩会阻碍政府通过绿色发展解决环境问题。制度层面，国家治理现代化滞后反映在环保机关条块分割，导致执法权模糊、法规不完善的结构性矛盾。此外地方政府因"GDP锦标赛"的政绩考核压力选择不严格监管危害环境的工程，选择性、替换性、欺骗性执法，对中央环保指令阳奉阴违，形成央地博弈的局面，损害高质量、可持续的经济发展。【跨课题：政治：央地博弈】

然而，有学者认为环境问题已严重到反噬经济发展的地步，亟需以绿色发展保障可持续经济发展，因此绿色发展是实现高质量发展的唯一选择。中国快速工业化进程具"三高一低"的特征，粗放的加工制造、重工业加剧空气、土地、水资源污染。中国碳排放已超过发达国家总和，煤炭消费比重高加剧碳排放及空气污染，造成每年1.4万亿美金的经济损失。违规工业废物处理造成土壤污染，直接导致粮食产业减产100亿公斤，污染既破坏生态环境和第一产业生产工具，也使政府承担GDP6%的环境治理成本。污染危害国民健康，2013年重度空气污染造成6.5万居民因臭氧、PM2.5等致癌物质早逝，加重医疗体系的负荷。中国医疗社保体系供给总量不足，社保支出仅占GDP2%，是相同收入水平国家的一半，以致于"未富先老"的社会抗风险能力弱，污染引起的健康问题会增加民众承担医疗开销上涨的难度，提高中国陷入"中等收入陷阱"的风险，不利于可持续增长。【跨课题：社会：社会保障制度】相反绿色发展打造"减量化、再利用、再循环"的循环经济，引导投资从高能耗产业流向技术密集的生产部门，以传统与新兴产业的融合实现互补，提升资源利用效率和全要素生产率，这对中国从粗放到集约、劳动密集到技术密集型的经济结构调整至关重要，有助于打造高附加值的绿色产业，实现高质量增长。

也有学者认为能源供需的结构性矛盾侵蚀能源安全，增加外部环境波动对中国经济的冲击，必须以绿色低碳经济保障可持续经济发展，因此是高质量增长的唯一选择。能源利用效率低的重工业不断扩大能源缺口，恶化"富煤、贫油、少气"的不合理结构，加剧能源对外依存度，增加能源供应安全的不稳定。进口石油占中国石油消费的70%，高达80%的能源运输经马六甲海峡，"马六甲困境"使中国外向型经济因美国"掐脖"、黑天鹅事件引发的石油价格波动更不稳定，不利于可持续增长。绿色低碳经济的核心是能源结构"清洁化"，这需要中国从化石向可再生能源转型，通过三峡大坝、"人造太阳"核聚变研发等项目提升水电、太阳能、核能等新能源的发电量、装机容量，减少油气消费比重。中国也双管齐下实施"能耗双控"，将GDP能耗从2010年的2:1降至2018年的1.55:1，通过产业链"绿色化"降低工业化对环境能源的消耗，推动能源"开源节流"，实现高质量发展。

两相比较，笔者仍认为绿色发展不是中国实现高质量增长的唯一选择。据环境库兹涅兹曲线，发展中国家都须经历以生态环境为代价、发展经济的阶段。当中国经济成为发达工业化国家，环境问题会因政府严格监管、民众环保意识得到缓解，解决环境问题因此不是当务之急。相反中国庞大的中产规模能有效压缩库兹涅兹曲线的时间轴，中产不满意政府环保监管不利，但以厦门PX群体事件为例，中产熟悉政府运作，更愿意在法律规范内参与集体维权运动，表达利益诉求。鉴于自身力量有限，中产常通过非政府组织参与社会治理，完善社会协同治理，倒逼政府完善环保政策，加大污染治理力度。

能源领域内，中国能源"低碳化"滞后，以"富煤"为主要特征，煤炭占比达57%。执行力不足也阻碍结构调整，中国既推动绿色发展又同时建造燃煤发电厂，过度依赖高污染高碳排放的煤炭，不利于实现2030年"碳达峰"和2060年"碳中和"的环保目标，导致绿色发展受阻，经济发展不可持续。中国新能源研发也同样面临技术瓶颈，《十四五》规划的财政拨款缺位、低碳技术产业体系薄弱、对外依存度大等挑战都阻碍能源"低碳化"，以致于中国难以实现高质量发展。相比，推动供给侧改革比绿色发展能更直接实现高质量增长。能耗双控靠"拉闸限电"的粗暴手段限制用电量，欠缺产业和技术升级的扶持措施，未能有效提升能源使用效率，反而导致高能耗上游产业减产，削弱稳定的经济增速。相反供给侧改革不存在绿色发展面临的制度和技术瓶颈，能通过经济结构调整实现要素最优配置，带来房地产、"僵尸"企业等与环保无直接关联企业的提质增效、产能优化，从而更全面推动产业升级。供给侧改革不面临绿色发展执行能力不足的窘境，在中央支持下能稳就业、稳金融、稳外贸、稳投资、稳预期，工业产能利用率在2018年前三季度达76.6%，有效缓解产能过剩，彰显供给侧改革对稳定高质量增长的重要性。综上所述，仅推动绿色发展不足以支撑中国经济的高质量发展。

### Essay 6: "城镇化是推动中国经济发展的强大引擎。"你同意这个观点吗？

- **Question type**: 是非题
- **Topics covered**: 课题一 (城镇化, 内需, 产业升级), cross-topic: 课题三 (中产阶级, 流动人口, 社保制度)

---

城镇化指的是伴随工业化发展，第二、第三产业向城镇聚集，农村人口向城镇转移，城镇规模不断扩大，城镇数量不断增加的自然历史过程。其中，城镇化包含了两个前后相继的转变：一是伴随着非农业的发展，农业劳动者就业向非农业的转变；二是伴随着非农业向城市的集聚和集中，非农业人口（及其家庭成员）向城市居民的转变。由于城镇化是工业化的伴生物和推助器，是解决"三农"难题、协调推进工业化、信息化和农业现代化的关键，有助于推动作为经济结构调整，促进经济可持续发展。笔者认为城镇化是推动经济发展的强大引擎。

首先，在中国迫切需要从投资与出口驱动转为内需拉动的经济增长方式的当前，城镇化能够为此提供强大的助力。由于全球贸易保护主义抬头导致中国依靠外需的外向型经济面临严峻的挑战，中国的当务之急是扩大内需，而城镇化无疑是带动消费的强大引擎。在城镇化的过程中，大量农业劳动者因为城市与农村发展的差距而选择到城市里工作，承担非农业劳动的工作，其收入相较之前的将会提升。据新华网报道，城镇居民人均消费指出26112元，而农村居民人均消费支出12124元，这在很大程度上是因为其就业性质的不同。随着大量流动人口向城市聚集，到城市务工的农民工的可支配收入有所增加，而其生活需求也会进一步拉动消费。据调查，城市化每提高1%，就会拉动最终消费增长约1.6%。可见，城镇化可助中国解决经济发展的三驾马车失调的问题，是中国经济发展的新引擎。

其次，城镇化是工业化的伴生物以及推助器，其有助于中国进一步实现工业化的深化，提升中国在全球产业链结构中的位置，从生产低附加值的低端产业转为生产高附加值的高端产业，让中国从"制造业大国"晋升为"制造业强国"，为经济可持续发展提供强大助力。近年来，中国推进城镇化的手段之一包括建设特色小镇，也就是以某一新兴产业或者附加值较高的传统产业为基础，具有特色与文化氛围的现代化产业群落。据《国务院关于深入推进新型城镇化建设的若干意见》，这些特色小镇将发展信息产业、先进制造、民俗文化传承、科技教育等产业来创造新的经济增长点。为了达成这个目的，政府加大对高新技术产业的投资，从而帮助这些小镇实现工业升级，让中国制造业可以制造高附加值、高技术含量的产品。例如：2014年底风靡全国的杭州云栖小镇便与阿里巴巴公司合作，打造了一个以云生态为主的产业小镇。小镇围绕云计算的特点，运用大数据计算将简单数据变成生产要素，成功构建了"共生、共荣、共享"的生态体系。可见，城镇化能帮助中国进一步实现工业化的深化，让其制造业转型升级，开发出更多的新经济增长点。

值得一提的是，在中国政府为了让小镇实现工业升级而加大对高新技术产业投资的过程中，这些高新技术产业的发展在成为驱动经济增长生力军的同时，也创造了中高收入的就业机会，有利于培育城市中产阶级。由于城市中产阶级普遍享受更高且稳定的年收入，这组人群的消费能力以及消费意识较高，可以整体上带动中国的消费结构升级。城市中产阶级为了追求品味的生活，消费一般脱离基础性消费，其恩格系数（即食品支出总额占个人消费支出总额的比重）较低，注重享受型消费，因此其更愿意在文化、娱乐等方面消费，因而促进第三产业的发展，帮助中国摆脱对制造业的过度依赖，实现产业结构升级，为中国经济可持续发展提供新的增长点。【跨课题：社会：中产阶级】

但是，有人认为，中国的城镇化目前主要还是"土地城镇化"，还没有完成真正意义上的"人的城镇化"，这显然有别于西方所经历的城镇化进程。根据清华大学蔡继明教授对城镇化的定义，城镇化包括：一、农业劳动者就业向非农业的转变；二、非农业人口（及其家庭成员）向城市居民的转变。中国的城镇化虽然满足了农业劳动者向非农业劳动者的转变（农民工进城），但是却没有满足农民工的市民化。据《2017年全国农民工监测调查报告》，50岁以上的农民工养老保险参保率仅为16.7%。由于中国的户籍制度，农民工的户籍因为留在了农村，因此其虽然在城市里工作，也无法享受城里人的待遇。因此，中国即使继续推进"土地城镇化"而忽略"人的城镇化"，也无法在很大程度上提高国内的需求，因为庞大的农民工群体在没有社保补贴的情况下，在消费方面仍然会有诸多后顾之忧。【跨课题：社会：流动人口/社保制度】其为了确保自己在有需要的时候（生病、养老金等），有足够的资金支撑自己，储蓄率偏高，导致其大部分的工资都存起来了，真正消费的部分偏少。因此，这对拉动中国内需的影响有限。有鉴于此，有人便认为，城镇化不是中国经济增长的强大引擎。

也有人认为，以售卖土地促成城镇化的城镇化模式面临着过度依靠廉价的土地红利、人口红利的问题，因此是不可以持续的，无法有效地推动中国经济发展。中国现在的城镇化模式仍然以"土地城镇化"为主，意味着地方政府垄断土地市场，通过低价征用农民土地，出让土地，创办园区，希望借此实现农业人口向非农业人口的转型。虽然这在一定程度上快速地促进了中国的城镇化，但这也带来了"伪城镇化"的问题，即：白象工程、"鬼城"现象。况且，这种方式的城镇化无以为继，随着越来越多土地已经被地方政府购买实现"城镇化"，中国在未来能通过同样方式转换的土地资源将越来越少；毕竟土地资源不是无限的。土地红利的消失意味着城镇化趋势无法持续，因此有些人认为城镇化长期来说不可能是中国经济发展的强大引擎。

另外，还有些学者对于特色小镇的作用提出质疑的态度 - 他们认为，2017年全国特色小镇数量到达5000个左右，但全都千篇一律，都在照抄浙江的经验。况且，有些特色小镇得到地方政府的资助，但这也将加剧地方政府的债务问题。更是有很多特色小镇有强烈的房地产化倾向，表面上是特色小镇，但实质上是房地产项目。因此，特色小镇发展不是很成熟，难以在推动经济发展方面作出实质效果。

确实，中国城镇化进程的确面临诸多阻碍与问题。但是，近些年来中国提出了"新型城镇化"的概念来弥补不足。新型城镇化的核心是"人的城镇化"，其中最为重要的是农民工的市民化。随着农民工能通过属地化管理享受公共服务均等化的福利，其就无须担心今后缺乏社会保障而选择把大部分的收入放在银行中存起来。可支配收入的提升将刺激这群人的消费能力以及意愿，有助于中国经济转向内需拉动的经济增长模式，实现西方国家见证的由城镇化所带动的经济发展。短期来看，农民工虽然不太可能晋升成为消费能力庞大的中产阶级，但毕竟他们到城市务工所从事的是较此前收入更高的非农业劳动，所以客观来说他们的消费能力会有所提升。无可厚非的是，长期来看，中国发展新兴城镇化道路是正确的，在不远的未来，这个政策有望帮助庞大的底层人民实现社会阶层的流动，培育内需市场。诺贝尔经济学家斯蒂格利茨（Jospeh E. Stiglitz）便曾说：21世纪全球经济的"两大引擎"，就是中国的城镇化以及美国的科技创新。中国"以人为本"的城镇化也意味着地方政府不需要再依靠土地红利推动土地城镇化，因此土地红利的消失便不再是一个棘手的问题。而随着"人的城镇化"解放人民的消费潜力并拉动中国的内需，我相信城镇化会是推动中国经济发展的强大引擎。

此外，虽然中国面临土地红利、人口红利流失的困境，但随着其进一步推动新型工业化、信息化、城镇化、农业现代化这"四化同步"的政策，这将在很大程度上促进信息化与工业化的深度融合，实现经济发展的提质增效，摒弃之前的以投入要素为主的经济发展模式。当前，以信息化为支撑的新一轮科技革命和产业变革正在兴起，互联网、大数据、人工智能、数字经济、电子商务等新科技不断涌现。根据索洛增长模型，科技创新是推动经济长期增长的关键。因此，政府"四化同步"的政策有利于中国借助技术进步来更加有效地利用现有要素，从而实现经济持续发展。

最后，随着特色小镇概念的兴起，以及中国政府发展中小城市和就地城镇化的趋势，中国政府将开发中部地区的经济发展潜力，实现某些产业从东部沿海地区转移至中西部地区。这对于中国经济持续发展无异于是一剂强大的强心针：随着中国制造业将进一步更新换代，以及农业的现代化，中国尚未被开发的经济活力将被完全激活。特色小镇在其发展初期，不受政府规范，经历了野蛮生长的发展阶段。虽然不少特色小镇只是风光一时，但未必会继续落败。据笔者了解，中国国家发改委为了规范特色小镇的发展，已经印发《国家发展改革委关于实施2018年推进新型城镇化建设重点任务的通知》，并表示：对已公布的两批403个全国特色小城镇、96个全国运动休闲特色小镇，开展定期测评和优胜劣汰。这意味着接下来政府将规范特色小镇的发展，规避其发展的弊处。

因此，总的来说，城镇化在促进中国制造业转型升级、推动产业结构升级和消费结构升级等方面扮演了重要的角色，这些条件不但有效地培育了中产阶级和提高人民的整体收入，更是为拉动中国的内需市场提供了强大的助力。虽然中国的城镇化建设遇到了重重挑战，但笔者仍有信心其能成为中国经济持续发展的强大引擎。

### Essay 7: 扩大内需在多大程度上是推动中国经济增长的关键？

- **Question type**: 关键因素题
- **Topics covered**: 课题一 (内需, 经济增长), cross-topic: 课题三 (中产阶级, 人口老龄化), 课题四 (中美关系)

---

中国以往主要通过投资与出口拉动经济增长。目前，随着全球化红利和人口红利逐渐削弱，中国需要减少经济的对外依赖性。近年来，中国不断刺激国内消费、拉动内需市场。扩大内需主要是扩大国内的消费需求和投资需求以带动国民经济增长。在经济新常态的背景下，我认为扩大内需是推动中国经济增长的关键。

当前，中国国内已具备了一系列有利于扩大内需的条件，使其足以成为推动经济增长的关键。首先，中产阶级的不断扩大为扩大内需带来了新的契机【跨课题：社会：中产阶级】。2019年，瑞信研究院调查显示，占中国21%的中产阶级拥有全国32%的财富，其人均财富指约中国人均的3倍。长远来看，中产阶级将于2030年占中国总人口70%。消费能力强的中产阶级对于生活条件的要求不断提高，更倾向对非生活必需品和奢侈品的消费。由此可见，中产阶级对扩大中国内需蕴蓄着巨大潜力。其次，新型城镇化的推进也有利于拉动投资与消费需求。近年来，中国不断推动全国城镇化进程，城镇化率年均增长1.02百分点，由此带来了很多新的投资与消费需求。城镇化的推进带动了新兴服务产业、高新技术产业、基础设施等投资。而随着中国深化工业化进程，技术的进步和供给质量的提高会刺激消费者的需求，让消费者更加愿意购买中国制造的高附加值、高技术含量产品。此外，为了推进"以人为本"的新型城镇化，中国近年来着手对户籍制度进行全面改革，有利于农民工市民化，使他们在享有社会保障后逐渐解除消费方面的后顾之忧。据调查，城镇化率每增加1%，就会拉动最终消费增长约1.6%。以目前来看，消费对中国经济的贡献率已经高达60.5%，足以显示，内需市场有巨大的扩大潜力，且很大程度上能够推动经济增长。

此外，在内部挑战和外部挑战的压力之下，中国很难像过去一样继续依赖出口导向的外向型型经济，因此扩大内需成为了纠正三架马车失衡并推动经济增长的关键。从外部挑战来看，出口导向型经济增长模式近年来因为外需市场疲软和美国贸易保护主义的兴起而形势不容乐观。美国自2018年以来向华增税、加大壁垒，已经冲击了两国之间的贸易关系；2019年，中国向美的出口总值下降0.7%。外部环境的不稳定性随时能够冲击中国的经济增长。【跨课题：外交：中美关系】从内部挑战来看，中国自2012年劳动人口不断减少，已经遇刘易斯拐点，2018年，中国劳动人口首次下滑至9亿以下。中国社会老龄化使其适龄劳动人口减少，人口红利流失。劳动力成本不断增加使中国失去产品价格优势，中国以往的比较优势弱化直接冲击了中国出口导向型经济增长模式。【跨课题：社会：人口老龄化】结合内部与外部的挑战，中国的外向型经济无以为继，中国当下必须转向内需拉动的经济。以内需推动经济增长的模式，能够让中国不受国际市场波动的巨大影响，使中国的经济增长不会因为全球经济遇瓶颈而大幅度下降。

持有反对意见者提出，扩大内需不是推动中国经济增长的关键。他们认为扩大内需困难重重，无法有效推动中国经济增长。突出表现为①没钱花。消费不足主要是因为劳动报酬在国民收入分配中的比重较低，而较低的收入就会只有较低的消费。受中美贸易战及新冠疫情拖累，居民收入增长缓慢，消费价格上涨过快，2022年中国全年居民消费价格(CPI)比上年上涨2.0%。占人口绝大多数的中低收入阶层，只能把大部分收入用在解决食品需求等基本的消费支出上，用在旅游、文化、健身等方面的消费就很少，导致消费需求的降低和总需求不足。高收入者消费意愿不强烈，而低收入者有消费意愿却没有消费能力。大城市与发达地区房价长期过快上涨，居民消费预期不稳定，从而导致发达地区城镇居民边际消费倾向下降。②有钱不敢花。消费是扩大内需的基石，但由于中国养老、医疗和教育等社会保障体系尚未完善，虽然实现具有普惠性特征的社会保障全覆盖，但城乡、区域实行标准不一，社保制度碎片化，保障水平不高，保障功能有待提升，使得人们有后顾之忧不敢消费。【跨课题：社会：人口老龄化】③有钱花不掉。中国中产阶级不断壮大，对高端消费品和服务消费的需求明显增加。一方面消费结构升级加快，另一方面落后的产业结构导致高质量供给不足、高端消费供给不足、个性化消费供给不足，产品和服务的品种、品质和品牌尚不能很好满足居民日益升级的消费需求。没钱花、不敢花和花不掉的窘态，折射出中国扩大消费不力的深层次结构性问题，严重阻碍了其对中国经济增长的拉动作用。

也有人认为，产业转型才是推动中国经济增长的关键。中国需要推动产业转型，从以劳动密集型产业为主转变成以技术密集型产业为主，以节约人力资源和环保的方式制造出含更高附加值、更高技术含量的产品。而随着技术密集型产业占中国总产业的比重增加，中国的产业不但能够减少其所需要投入的人力成本和环境治理成本，也具备更好的条件来实现中国的创新驱动发展战略，从而推动中国经济增长。

对比而言，我仍认为扩大内需是推动中国经济增长的关键。

首先，虽然拉动内需面临困难，但在中国政府努力下困难正在被克服，拉动内需正有力促进中国经济增长。中国通过倡导新型城镇化和"两新一重"，一方面依此拉动投资需求，把大量投资引入发展数字经济、推动高新技术产业，扩大公共服务投资，为更多人提供就业机会，让人们有钱花。另一方面不断完善社会保障制度，提升养老保险、失业保险、城医疗保险等保障水平，给人们一颗定心丸，解决他们不敢消费的后顾之忧。同时，打造大众创业、万众创新"双引擎"，通过"互联网+"引领生产方式走向数字化、智能化、现代化，使产品走向个性化、定制化。由此可见，中国政府的努力正在卓有成效地中国实现高质量发展。

其次，产业转型要推动中国经济增长，也必须以扩大内需为依托。虽然产业转型也是推动中国经济增长的重要因素之一，但要让技术密集型产业成为中国产业的主要支柱，归根结底还是需要从需求端看起。唯有通过扩大内需市场，人民才会更有能力和意愿去消费技术密集型产业所生产的高附加值、高技术含量产品。因此，扩大内需是产业转型的前提，从需求端带动供给端的发展，才是经济增长的关键。

总体而言，扩大内需能够解决目前三驾马车失衡的问题，并且能够为中国经济增长作出巨大贡献。

### Essay 8: 中国有能力应对巨大的能源需求。试评价这个观点。

- **Question type**: 是非题
- **Topics covered**: 课题一 (能源), cross-topic: 课题四 (能源外交)

---

能源亦称能量资源或能源资源。为了满足工农业和人民生活水平的提高，传统能源可能会被人类使用殆尽。自90年代末，中国经济的增速发展带动多种能源的消费量的急剧上升。巨大的能源需求导致中国"富煤、贫油、少气、缺水"的能源储备面临能源安全及供给不足的挑战，影响其经济可持续发展。可是，鉴于中国在"开源节流"方面的不懈努力下取得了显著成果，笔者认为中国有能力应对巨大的能源需求。

首先，为了满足该需求的供给，中国已经积极寻找外部供给并通过国际合作机制来维持能源供应的可持续性，从而确保供应源的多元化和安全性。【跨课题：外交：能源外交】中国50%的石油从中东地区进口，且全部依靠海路运输，地区局势的变幻莫测威胁了中国的能源运输。因此，中国所倡导的能源外交让它与中东国家、俄罗斯及拉美同时签署能源合作备忘录，拓展能源多元化战略。例如在2012年，中国与沙特阿拉伯签署在沙特合资修建油矿的协议，每年处理2000万吨原油。中国也与俄罗斯签署《石油领域合作谅解备忘录》、《关于俄罗斯向中国出口天然气的框架协议》的合作协议。俄罗斯每年向中国供应4600万吨石油，成为中国能源供应的另一个渠道。多项跨国合作的机制可完善国际能源市场的监测和应急机制并提升海外能源供给的安全性。同时，为了进一步确保能源的安全供给，中国积极参与世界组织，以便强化中国与他国的沟通和政策协调，深化双方在能源领域的互利互信。例如，中国积极参与联合国及其下属机构如联合国环境署、联合国贸发会议等，为能源市场问题上开展密切合作制定具体规划。中国也利用国际法建立跨国能源合作的机制，确保能源供应的可持续性。在2010年，中国与海合会六个成员国签署《中华人民共和国和海湾阿拉伯国家合作委员会国关于战略对话的谅解备忘录》。双方重申尊重《联合国宪章》宗旨原则和国际法，促进和平、推动互利合作。在国际法的保障下，中国有能力避免地区动荡对能源供给的威胁，维护其能源安全。

其次，中国不断推动产业结构升级和能源消费结构升级，由此有效地提升了能源利用效率，从而有能力降低巨大的能源需求，应对此问题。为了扭转"高投入、高耗能、高污染、低效益"的粗放型经济发展方式，中国大力推动产业结构调整，积极加快产业结构的升级，发展能源消费强度低的第三产业，降低第二产业的总能耗。在2007年，中国第二产业总能耗在70%，现在已经降至60%。近年来，中国政府合理地调整产业结构布局，积极促进以工业为主导的产业结构向第三产业为主导的产业结构转化。由此，中国国内生产总值中的能源消耗由1980年的3.39吨标准煤下降到2006年的1.21吨标准煤，年均节能率3.9%。能源节约的明显效果证明中国有能力、有毅力推进产业结构升级，从源头遏制能源需求的上涨。不仅如此，产业结构升级也带动了能源消费结构的优化，在2018年天然气、水电、核电、风电等清洁能源消费总量的比重同比提高约1.3个百分点，煤炭消费所占比重下降1.4个百分点。后者的下降趋势预示着经济增长方式的转变，国民经济结构的节能化和部分轻型化有利于提高中国能源利用效率。这形成一个良性循环，让中国有能力应对巨大的能源需求的问题。

最后，中国通过科技创新，有效实施"开源节流"的措施确保能源的供应，应对巨大的能源需求。中国的石油天然气工业已经形成了比较完整的勘探开发技术体系，特别是复杂区块勘探开发、提高油田采收率等技术。在电力工业方面，先进发电技术和大容量高参数机组得到普遍应用。电网格局的建设也解决了原本运输问题 - 铁路运力不足。能源运输往往会因该问题而受阻，从而增加运输成本并影响能源的正常供应。加强输电网络的建设有效维护资源运输的安全性。中国政府也积极开发可再生能源，逐步改善现有的能源消费结构，降低石油的进口依存度。例如，截止2018年低，中国可再生能源量同比增长12%。预计到2030年，可再生能源在中国总能源结构中将占到30%以上。随着中国有了更充足、稳定且清洁的能源来源，国内便得以保障能源安全，降低对外依存度，有效应对巨大的能源需求。

不过，有人认为中国能源对外依存度依旧很高，在各国争夺国际能源的态势进一步加剧的背景下，中国无法避免海外能源博弈所带来两大风险：国际油价攀升和进口运输安全。【跨课题：外交：能源外交】这使得中国无法确保稳定的能源供应来应对巨大的能源需求。2012年，伊朗核危机将油价推至高点。由于各国担心西方同伊朗的对抗升级为武装冲突或战争，来自该地区的石油供应面临被中断的风险，国际油价上涨了5%以上。中国对伊朗的石油依存度为2750万吨，平均每天进口50桶；一旦来自伊朗的石油供应被中断迫使油价大幅上涨，中国会因此而付出巨大的经济代价。同时，霍尔木兹海峡和马六甲海峡不受中国管辖，外国势力的干扰随时有可能直接威胁中国的能源运输安全，切断中国的经济命脉。中国70%的原油进口都要经过霍尔木兹海峡，中国80%的原油进口必须经过马六甲海峡。马六甲海峡的通道狭小而且海盗猖獗，加上美军对该运输通道的军事威胁随时有可能阻断该商业航道的畅通及航运安全，使得中国陷入"马六甲困境"。以上两种风险将不断削弱中国应对巨大能源需求的能力。

相比之下，笔者还是认为中国依旧可以应对巨大的能源需求。

在全球化的背景下，维护能源外交多边组织合作的格局，确保能源外交的机制化才可以实现各国互利共赢的局面。各国在追逐与维护共同利益的基础上会避免零和博弈。中国的能源外交以及多边组织的合作制度给各国提供机会、平台完善国际能源市场的监督机制并促进能源开发以保障供应。这将降低世界能源博弈的可能性，让中国可以应对自己的能源需求。

同时，中国也在建设其他的运输航道，分散海上运输的风险。中国正在开辟克拉运河的运输路线。这条运河将横穿泰国南部，让中国船只绕开马六甲海峡，直接从印度洋的安达曼海进入太平洋的泰国湾。中国也在建设四大穿过东盟国家的国际航道，开辟新的运输途径，保障能源供给。

总而言之，笔者认为中国有能力以"开源节流"的方式应对巨大的能源需求。该国通过能源外交，确保能源供给源的多元化，深化区域合作维护运输通道的安全性。中国也通过科技创新改善产业结构和能源消费结构，降低巨大的能源需求，使该问题不足以阻碍中国的经济可持续发展。

### Essay 9: "快速工业化加剧了中国区域发展不平衡。" 试加以讨论。

- **Question type**: 是非题
- **Topics covered**: 课题一 (工业化, 区域发展不平衡), cross-topic: 课题二 (政治体制), 课题三 (流动人口)

---

工业化指的是工业或者第二产业的产值在国民生产总之当中比重不断上升的过程，以及工业就业人数在总就业人数中比重不断上升的过程。快速工业化作为中国的经济发展的策略之一，助推了中国经济的飞速发展，但同时也带来了一系列问题，其中包括区域发展的不平衡。随着工业化的进程不断推进，中国区域之间（尤其是东部沿海地区与中西部内陆地区之间）的经济和社会发展水平等方面所存在的差距不断扩大。因此，我认为快速工业化确实加剧了区域发展不平衡。

首先，快速工业化加剧了区域间经济发展的不平衡。中国的工业化是在国家实施"非均衡发展战略"的宏观背景下而启动的，因此它作为一个经济策略必须服务于国家实施的"第一个大局"（即让沿海地区优先发展）。东部沿海地区享有优越的地理位置，在对外贸易上存在着西部地区所没有的得天独厚的优势，因此为了快速地盘活中国经济，中国政府重点对沿海地区实行政策优惠和放权让利。由于中国是一党专政，政府掌握大量经济资源，而且强调地方服从中央，于是政府将经济资源和生产要素集中于东部地区，东部就此开始大力发展资本、技术密集型的高附加值产业，导致当地经济飞速发展、经济生产率如日中天。【跨课题：政治：政治体制】随着东部地区的经济社会水平开始提升，当地的资本回报率、就业机会以及薪酬等方面都存在着优于西部地区的条件，而大量的优质资本和劳动力等经济要素在市场机制的驱动下也会源源不断地继续流向东部。可见，起初的政策倾斜最终演变成了优势的积累和自我巩固，让东部地区愈发快速地推进科技创新，实现产业集聚与升级。比如：2017年，中国高新技术企业超过73.3%都集中在东部地区。相比之下，中西部内陆地区工业化不足，不仅面临着人口流失的问题，而且产业单一、分散、又落后，不利于经济的发展。这样的恶性循环使区域差距不断扩大，因此加剧了经济发展的不平衡。

其次，快速工业化也加剧了区域间社会发展的不平衡。由于工业化的成果都集中在东部沿海省份，中西部的许多剩余劳动者为了追求更好的生活，纷纷背井离乡涌入东部沿海地区寻求高薪的就业机会。可见，快速工业化支撑了城镇化的推进，而人口不断往东部地区的流动不断为东部城市的管理提出了更高的要求。【跨课题：社会：流动人口】一个最典型的例子便是北京：北京的市规划委虽然早在提出北京市的人口承载量最大只能达到1800万人，但是近年来人口的不断流动导致北京的常住人口早在2014年就已经达到2150万人，远远超出了市规划委的控制目标。人口的过度集聚导致公共设施不负重荷、当地资源严重短缺。无论是交通的严重堵塞、水资源的极度匮乏、抑或是环境质量的不断下降，"大城市病"的众多影响都给当地的城市管理造成了极大的挑战，迫使着当地政府加大对当地公共设施、社会领域等方面的财政投入。这样来看，快速工业化带来的人口流动倒逼了东部地区不断完善其城市的基础设施和城市管理体制，以更好地达到更高的人口承载量。同时，东部地区由工业化而实现的经济上的发达也意味着人民有着更高的劳动收入，而地方政府更高的财政收入也意味着东部地区有能力来促进城市建设和改善民生问题，由此使得该地区人民的生活质量明显比其他地区更胜一筹。事实上，东部与中西部地区之间的人均GDP的最高与最低的差距到了2017年已达到了4.5倍。人均GDP作为人民生活质量和社会发展的重要指标之一，显示出了区域之间社会发展的不平衡。总之，快速工业化加快了东部地区社会发展的步伐，东部地区无论从城市硬件还是软件都不断接近宜居城市的标准，而社会发展落后的西部地区则仍然十分凋敝。因此，快速工业化加剧了区域间社会发展的不平衡。

然而，有人认为快速工业化并没有显著加剧区域发展不平衡，因为政府采取的"区域协调发展战略"所释放的政策红利缓解了该问题。近年来，政府已经意识到区域发展不平衡的严峻性，并且逐步转变区域发展战略。无论是江泽民提出的"协调发展"（1996），或是胡锦涛提出的"科学发展观"（2003），中国政府显然已经开始加强对邓小平"第二个大局"的推进，把实现包容性增长、缩小地区差距摆上突出的位置。习近平的"区域协调发展战略"（2017）也通过多方面的措施试图缓解区域发展不平衡。第一，中国不断推进京津冀、长三角等城市群的发展，建立以中心城市引领周边城市、以城市群带动区域发展的新模式，推动区域板块之间融合互动发展。第二，政府也提出了"四大板块"和"六个支撑带"，形成了以"一带一路"、京津冀协同发展、长江经济带发展、粤港澳大湾区建设等战略为引领，统筹推进"西部开发、东北振兴、中部崛起和东部率先"这四大板块联动发展的区域发展总体格局。总之，中国政府的一系列措施一方面能通过倾斜政策对落后地区提供资金和项目扶持，支持产业结构的调整和升级，另一方面能继续鼓励发达地区率先发展，并通过"梯度转移"和"扩散效应"，在率先发展中带动和帮助中西部地区的发展。显然，政府致力于深化区域合作、推进区域良性互动发展、并充分发挥不同地区的比较优势，通过健全的合作、互助和扶持机制逐步扭转区域发展的差距，形成东中西相互促进、优势互补、共同发展的新格局。因此，政府的协调发展战略在一定程度上缓解了快速工业化对区域发展不平衡所产生的负面影响，快速工业化并没有加剧中国区域发展不平衡。

对比而言，我依然认为快速工业化在很大程度上加剧了中国区域发展的不平衡。虽然政府确实有意愿缩小地区差距，甚至已经将其提高到了国家战略的高度，但是政策的有效性低下，在实践层面上并没有完全释放出政策红利，无法有效地解决区域发展不平衡的问题。何况，区域协调发展战略不是万灵药，无法真正地根治问题的症结。在没有培育出新的比较优势之前，政府盲目的倾斜式的投资政策和补贴只会进一步扭曲市场配置资源的效率，并不能有效地帮助落后地区吸引优质的资本和人才及其他有利于发展的经济要素。事实也证明，中西部的就业增长依然缓慢、劳动参与率依然偏低，甚至支出大于所得。2017年，中国的劳动生产率最高的省份是最低省份的3.8倍（比起2008年的2.5倍明显增大）；同时，在全国新增企业数量当中，中西部的12个省份所占的比重依然少于20%，经济活力明显还是落后于东部地区。显然，政府政策所给予中西部地区的政策优势以及其本身所具备的资源优势都无法有效地转化为发展的红利。因此，政策的调整目前还无法有效地缓解快速工业化对区域发展不平衡的负面作用。快速工业化在很大程度上还是加剧了区域发展不平衡的问题。

放眼未来，中国的区域协调发展战略如果要更具针对性，政府不应以自身为投资主体仅仅加大对中西部地区的工业投资，而应该改变推动当地工业化的路径，一方面结合该地区的地理和资源优势来培育特色工业，一方面引入市场化机制来吸引企业、人才前往该地区，从而实现工业升级。近年来，贵州通过大力发展大数据产业来力图实现"弯道超车"，取得了显著的阶段性成果，或许能给中国政府带来不容小觑的启发。

### Q3: "阶层分化是中国社会转型所面临的最大挑战。"你在多大程度上同意这个观点？【30分】

- **Question type**: 最字题
- **Topics covered**: 课题三 (阶层分化, 社会转型)

#### Teacher Answer Framework

**一、关键词解释与申明立场**

阶层分化是指社会发展转型中，社会利益重新分配，不同社会阶层在分化、整合、重组、流动中形成许多新的社会利益群体，和社会阶层结构重构的动态变化过程。社会阶层分化本质是一个社会各阶层利益重新分配的过程。

社会转型指的是社会经济结构、文化形态、价值观念等发生深刻变化，是社会系统全面的、结构性的调整与转化。中国社会转型体现为：从传统社会转向现代社会；从农业社会转向工业社会；从乡村社会转向城镇社会；从封闭性社会转向开放性社会；从同质的单一性社会转向异质的多样性社会；从伦理型社会转向法理型社会。

我不同意题目的观点，认为阶层分化不是中国社会转型所面临的最大挑战

**二、立场分析**

首先，阶层分化是中国社会转型的必然结果，中国政府通过完善分配制度，使阶层分化对社会转型的冲击总体可控

中国从传统社会向现代社会转型伴是中国对内市场化改革、对外融入全球化的必然结果：

市场化改革 -> 资源配置从"按计划"转向"按市场" -> 不同地区、行业、群体的利益多元化 -> 社会流动促进阶层分化 ->
- ①中产阶级扩大（2001年4% -> 2024年42.3%）-> 消费的前卫，政治上的后卫但不缺位 -> 社会稳定器
- ②阶层分化本身是社会分工精细化 -> 不同群体在教育、技能、收入水平上差异化 -> 产生激励机制 -> 经济发展动力源
- ③阶层分化 <-> 完善分配机制（三次分配、财政转移支付、扶贫）-> 阶层固化下降，社会正常流动 -> 包容性社会促进社会多元创新

其次，人口老龄化才是中国社会转型的重大挑战

计划生育/全球化追求个人主义 -> 婚育观发生重大变化 -> 人口老龄化（2023年末60岁及以上老年人口超2.96亿，占中国人口的21.1%进入中度老龄化社会）
- ①劳动力供给减少 -> 人口红利下降 -> 劳动力密集型产业难以为继 -> 成本上升，企业竞争力下降 -> 不利于经济可持续发展
- ②社会保障与养老负担加重 -> 养老、医疗、社会福利支出迅速攀升 -> 政府公共服务压力增大 -> 对国家治理能力提出挑战

**三、平衡分析**

有人认为阶层分化是中国社会转型所面临的严峻挑战

首先，他们认为阶层分化造成贫富差距拉大，导致阶层固化，底层社会产生相对剥夺感，成为社会转型中的严峻挑战

阶层分化 <-> 收入差距扩大（基尼系数2008年为0.491，2024年0.47，高于0.4的国际警戒线）-> 社会流动渠道受限 -> 寒门再难出贵子 -> 阶层固化（富二代、官二代、农民工二代）-> 底层群体产生相对剥夺感 -> 社会矛盾上升 -> 官民信任下降 -> 塔西佗风险上升 -> 阻碍国家治理/社会稳定

其次，他们认为阶层分化导致利益诉求多元化，国家治理难度加大，成为社会转型中的严峻挑战

阶层分化加剧利益分化 -> 社会诉求的多样化（高收入者关注资产保值、教育资源优质化/中产关注社会流动、教育机会、住房和医保/低收入或弱势群体则更关注基本生活保障、就业机会、社会救助）-> 公共服务和政策体系需适应多元利益 -> 政策制定与协调难度上升 -> 若难以兼顾所有阶层就会出现矛盾冲突 -> 不利于国家治理

**四、比较分析**

①回应平衡质疑：阶层分化给中国社会转型带来的挑战正在被中国政府的政策所化解

针对阶层分化导致收入差距扩大以及利益诉求多元化问题，中国政府正通过"调节与发展并重"策略来解决阶层分化问题：一方面完善分配制度改革，通过税收等政策杠杆来优化财富分配，加大对低收入群体的补助和转移支付如精准扶贫与乡村振兴，实现共同富裕；另一方面通过完善公共服务均等化如教育、就业、社会保障等，如让教育资源下沉来提高低阶层子女教育水平，打破"阶层固化"推动区域协调发展，来提升低阶层机会，实现收入差距缩小、社会流动性增强、公共服务公平，取得了举世瞩目的成果。贫困地区农村居民人均可支配收入，从2013的6079元增长到2020年的12588元，年均增长11.6%。2020年11月中国所有国家级贫困县全部脱贫，联合国秘书长古特雷斯高度评价："精准扶贫方略是帮助贫困人口、实现2030年可持续发展议程设定的宏伟目标的唯一途径，中国的经验可以为其他发展中国家提供有益借鉴。"

②与外来因素进行比较：人口老龄化与阶层分化相比对中国社会转型带来的挑战更大。

对比平衡点：解决难度/影响程度

**五、总结**

综上所述，我认为阶层分化不是中国社会转型所面临的最大挑战。

#### Student Essay 1 (林昱源 25S69)

中国的城镇化指的是随着国家高度工业化，国家的第二、第三产业开始靠城市聚集，随着农业的缩小，农业工作者及其家属开始向城市里移动，以寻找、从事非农业就业，以及城市本身占用土地量规模的扩大的自然历史进程。这主要体现为"人的城镇化"、"土地城镇化"两方面。

可持续发展指的是一种在满足自身发展需求的同时，不影响后代为了满足其自身发展需求能力的一种经济发展模式，在中国主要体现为"绿色发展观"、循环经济、绿色经济

我认为城镇化在较大程度上推动了中国经济的可持续发展。

首先，城镇化，尤其是"人的城镇化"带来了有效的消费扩大，带动了中国的内需，推动了中国的服务业发展，促使了中国产业链从以低附加值的第二产业转型到高附加值的第三产业。随着城镇化的不断推进，"人的城镇化"带来了大量的流动人口，即从农业、乡村转进城市的农民工，进城寻找工作，提升了城市中的人口资本。随着更多农民工进城工作，由于城市中生产要素高，农民工能够得到更高的收入报酬，提升其可支配收入，而因为城市生活的不同需求，其消费意愿同消费能力一同增长，推进了中国的消费增长、从而拉动内需增长，平衡"三驾马车"结构问题。间接的，随着这群人士的可支配收入提高，其对于消费的意愿、消费结构也将提高，从生存型、温饱型消费转换为自我发展型、体验型、精神性等更深层次的体验性消费，他们因此也更有可能接受溢价来购买奢侈品等体验产品，有效提高了中国的消费。这将促使中国的第三产业做大强，由于城市中的消费强有力，吸引更多商家发展第三行业，同时倒逼政府机构为追求更有效、高速经济发展，逐步让具有"三高一低"、高排放、高污染、高投入、低效率的传统工业逐步退台，不再做中国经济增长的主力，从外向型转为内生型经济，促进"内循环"，逐步减少对于传统重工业的依赖。这将助于，从总的来算，减少中国经济发展对环境所带来的危害，因高度依赖"三高一低"制造业及第二产业来发展经济的因素，中国在2005年在"世界环境可持续指标"中，在144国家中排名倒数第十四。随着这类行业的不断发展，中国的土地要素、优质土壤资源以及水源资源被蚕食，要素的锐减严重影响这一发展模式的持续性，是对于后代的一种威胁，不符合中国的经济发展可持续性。因此，通过城镇化，第三产业可得以强力发展，减少对高污染发展模式的依赖，从而得到可持续发展。

其次，城镇化可以减少区域发展不平衡现象。通过城镇化，社会资源和资本可以更为集中，而同上面所说到的，除了可以提高消费结构，引发经济快速增长以外，中国的城镇化现象也可以在一定程度上造成中产阶级的扩大。中产阶级的扩大提高了其政治参与意愿，提高了其消费结构和层次，促使这一中产阶级更可能参与非政府组织，促进国家公民社会的发展，从而强化"第三次分配"，让自愿性资源分配能够成为协和治理的强有力的经济强心针。随着城镇化的进程，中产阶级得以更高教育程度，其政治参与意愿得以提高，更有可能以自己的提高的可支配收入来进行第三次分配，即公益性活动。而且，城镇化也为农民工提供了一个发展自我能力，从而回农村创业、有效拉动乡村经济水平的机遇。综合起来，这可有效缩小城乡差距，良好有效分配城市的优良资本，从而减少了地区之间不平衡。不同公民社会，因城市化的发展，能够协同政府动员大量社会资金，如帮助贵州贫困山区小孩的"希望小学"受收到的大量捐款。随着城镇化的进程，即每增加1%的城镇化率，就会对于中国经济带动1.6%的经济增长率，中国人民的平均社会地位提高，其可支配收入亦可提高，而大量的城市人民捐款有效的帮助政府进行了社会资源、资金的再分配，帮助缩小了区域差距不平等，减少了社会中的要素分配不平衡所造成的社会正义缺失、因社会发展不平衡所造成的民众情绪不满，甚至暴动，如7.5事件，因少数民族地方人民认为中国政府没能够正视地方民族人民需求而造成的暴动，从而推动了中国经济不因区域发展不平衡而需要政府调动大笔资金来减缓这社会矛盾以及不同地区的不均匀，以及减少了"三股势力"等极端现象的滋生，减少了政府在管理这一方面的成本，同对经济发展的成果不会成为分裂社会的一件事，在一定程度上促进了中国经济发展的可持续性。

然而，城镇化对于促进中国可持续发展却带有一定的局限性。首先，虽然中国近年来城镇化率高达67%，其中包括了2.95亿流动人口，其劳动对于中国改革开放以来经济贡献高达20-30%，中国政府的社保机制滞后于人口流动进程，以致"人的城镇化"高度受限，城镇化的进度仅仅为"土地城镇化"。随着农民工集体进城就业，由于户籍制度的限制，在城市工作的农民工"身户分离"，即在城市中就业，但不可享受到同城市人口一般的社会福利，如医疗保障，工伤保险等。缺乏了这一基本保障，为了应对突发状况，如疾病、残疾等状况，中国的农民工更倾向于过度存款，以防备这类突发现象，随着国家开放医疗体系，中国出现了"一场大病能干倒一个中产"现象，即医疗费、住院费用用高昂，农民工缺乏了社会保障、医疗保障等确保其能够拥有资金，有效应对这种情况的制度后，只能够大量存款，降低了其可支配收入以及消费意愿。这导致了城镇化不能很有效的拉动中国的第三产业，随着城市人民消费意愿低迷，第三产业、尤其是中国向内生型经济发展过程进展难以持续，第三产业行业服务无法以来内需而做大。故此，城镇化在一定程度上也是无法推动中国可持续发展的，目前对于"三高一低"产业的过度依赖格局依然会保留。

其次，有鉴于社会不稳定对于中国社会可持续发展的不可持续性，随着"人的城镇化"的失败，中国普遍出现农民工在城市中"经济上接纳、社会上排斥、工作上歧视"的现象，导致了高度的社会正义缺失，使农民工认为自身利益未被重视，引发社会不稳定情绪和现象，从而导致社会暴动等现象发生。这种暴动现象无疑是对于中国经济发展不可持续的，其影响了投资者的信心，可能会长期因为政治不稳定而避免进入中国市场，而有鉴于中国的比较优势之一就是其政治稳定，以及农民工所带来的廉价劳动力，农民工的社会不满情绪甚至是随之引发的社会暴动使高度负面影响中国经济可持续发展的。如湖北农民工惨遭冤枉在广州被警察殴打致死所引发的社会舆论和暴动，对于当地维稳以及公安系统造成了一定的成本以及资源损失，足以见得长期，大规模的暴动对于中国经济的可持续发展是没有好处的。

然而，我认为总体上而言，城镇化还是能够有效推动中国经济的可持续发展。中国近年来推进了"新型城镇化"，旨在大城市城镇化的同时，以乡镇为主体，通过引进独特产业、高科技新型产业、云计算等产业，实现乡村地区高速经济可持续发展，从而缩小地方经济发展不平衡，让中国经济从两个方面得以可持续发展，一就是第三产业、低污染、高附加价值产业的发展，而二者为减少因地区不平衡而滋生的不满心态。这既能够促进城乡之间社会保障机制资源分配的以平衡，通过资源的合理再分配，地方政府能够让村民乡民得以更高质量的社会保障，从而促进其消费意愿和可持续发展，如"云栖村"等运用云计算来成为新型城镇化中，城乡的特色产业，摆脱了传统的第二产业、高污染产业的束缚，增加了其居民的可支配收入，推动了中国的第三产业发展，使其更为可持续。从而达到了促进中国经济可持续发展的效果。

其次，如上所述，城镇化有效提高居民的教育水平以及中产阶级大发展扩大。随着公民教育程度提高，中国政府所提倡的"文明社会"可得以更深入的意识以及民众回响，即民众素质提高，有了基本文明意识，从而更加理性、包容的看待外来农民工，减少了社会冲突事件、社会歧视时间，让中国的经济发展模式在民间被更为认同，更为可持续。更大的中产也意味着更多第三次分配也可能会给予为这些农民工给予托底性保障提供资金，缓解上述不均衡问题的现象。

城镇化指的是农业劳动人口向非农业转换，以及非农业人口向城市居民转换的城市化过程，包含人的城镇化以及土地城镇化。改革开放后，中国经济腾飞，城镇化成为重要燃油。城镇化率每年增长1.02个百分点，为经济带来可观的增长。经济的可持续发展指的是中国的经济在推动生产力增长的过程中所采取的重大措施与决策具有可持续性，可以帮助中国经济持续发展。

笔者认为城镇化在很大程度上推动了中国经济的可持续发展。

首先，中国政府推动人的城镇化，让基数庞大的农村过剩劳动力流往城镇，解放劳动力，弥补城市的供给侧结构性不足，从而推动了经济的可持续发展。中国农村的资源配置效率低下，导致了大量剩余劳动力，需要推动产业升级。这些大量剩余农业劳动力在农村无法找到工作，抑制了生产力和消费力。城镇的拉力在于机会更多、劳动回报率更高。农村的"推力"，加上城镇的"拉力"，让基数庞大的农村过剩劳动力流往城镇，不再依赖于效率低下的小农经济，而是可以加入工厂、服务业等行业。流动人口规模约有4亿人，是中国总劳动人口的约五分之一。大量廉价劳动力弥补了城市的供给侧结构性不足，带来人口红利，有效降低了劳动成本并增加了企业利润，为中国打出"制造业强国"与产品价格竞争优势的王牌，提高国际竞争力。这有效推动了中国的市场经济产业结构从第二产业转向第三产业，带来可持续发展。

其次，城镇化解放资本，有效刺激了城镇的内需市场，从而带来可持续发展。在中美贸易战的不断升级的背景下，中国已难以继续依靠出口来带动经济的可持续增长。美国对中国增加关税，技术与科技"卡脖子"，带来黑天鹅风险。中国对美国的出口在2017年下降0.7%，是一个极其危险的信号。中国需要平衡三驾马车，转向内需驱动的经济增长模式。城镇化让大量农民流往城镇，拥有更高的收入。新华网报道，城市居民的人均收入约26000元，是农村人口的一倍更多。在完成农业劳动人口向非农业转换，以及非农业人口向城市居民转换的城市化过程中，农民工拥有了更高的可支配收入，因而有钱花，敢消费，带动城镇的消费市场。同时，他们的生活需求也会带动消费。调查显示，城镇化每提高百分之一，就会拉动最终消费增长1.6%。而中国政府也已在完善社保，加强社保的覆盖深度与广度，让更多流往城镇工作、居住的劳动人口也可以被社保覆盖，让他们不必为未来的不确定性进行额外储蓄，提高消费意愿。城镇化有效地扩大了中国经济的内需，拉动消费，缓解三驾马车失衡，从而推动中国经济的可持续发展。

同时，中国政府大力推动特色小镇的建设，促进科技创新与产业升级。中国的经济正处于经济转型的阵痛期，需要从要素驱动的经济增长转向创新驱动，成为"制造业强国"和发展"人才红利"。根据索罗发展模型，科技创新是经济发展的不可或缺因素。特色小镇是以新兴产业或高附加值的传统产业为群落，带来聚集效应，将经济增长的关键高质量要素，如人才、资金、项目等汇聚在一起，共同取长补短，激发创新与活力，协同发展。中国政府通过资源倾斜，大力促进特色小镇的建设与发展。例如云南的杭州云栖小镇以云生态为招牌，在全国范围内引起了巨大关注与讨论度。城镇化促进了中国经济的科技创新，带来产业转型升级与新的经济增长点，从而推动经济的可持续发展。

不过，也有学者认为城镇化无法有效推动中国经济的可持续发展。他们认为中国的城镇化依旧局限于土地城镇化，并没有"人的城镇化"。首先，他们认为基数庞大的劳动人口涌入城市，会为城市的公共基础设施带来极大的压力。许多城市的公共基础设施已在高负荷运转，而这些公共设施的建设速度滞后于人口涌入的速度。例如北京的原本城市人口承载量仅仅可以承担1千万左右的人口，但其实际承载人口早已超过了两千万。随着大量劳动人口流往城市工作、居住、安居乐业，资源的紧张短缺被加剧，如机会、就业、环境、治安等。大城市中的适龄劳动人口不断增加但工作岗位并未增加，于是每个岗位的竞争翻倍，带来"内卷"现象。而大量城市人口会产生大量生活与生产垃圾，为环境治理带来负担，加剧了地方政府的环境治理成本与财政支出。由于中国的公共管理服务尚未完善，流动人口与城市居民、流动人口之间的紧张矛盾会带来社会风险与社会动荡，若处理不当则有可能上升为群体性事件，而政府又无法有效及时地处理社会事件、回应民众诉求，不利于社会稳定与经济增长，也影响了中共的政权合法性。因此引发的是严重的"大城市病"，即出行难、求学难、求职难、看病难等生存难题。农业人口在流往城镇工作之后，难以融入当地生活，再加上城乡二元分割的户籍制度让社保的异地支付困难。据报告显示，中国农民工劳动人口中，仅有16.7%被养老社保覆盖。这类劳动人口的消费能力与意愿的提升实则非常有限，他们的恩格尔系数高，需要把大部分收入花在温饱型消费上或为未来进行储蓄，难以刺激消费。因此，学者认为城镇化无法有效扩大中国经济的内需市场，可持续发展更是无从谈起。

其次，也有些学者认为目前的城镇化是土地城镇化，不可持续，更无法推动经济的可持续发展。地方政府通过低价购入土地，再高价租出，形成地方政府财政收入的最大支柱 - 房地产带来的土地红利。而随着地方政府收购的土地越来越多，在未来可以供地方政府继续进行土地城镇化的土地将越来越少，难以持续。同时，地方政府为达到目的而实施的强行拆迁、暴力拆迁等行径会极大地影响政府在民众心中的形象，负面地影响官民信任，甚至提高中国政府陷入塔西佗陷阱的风险。一旦民众不再信任政府，便不会积极配合政府为推动经济增长的重大措施，让这类经济增长策略的实际落实效率与有效性降低，从而无法推动中国经济的可持续发展。

他们也认为城镇化中的特色小镇发展不成熟，千篇一律，并无创新点，无法推动中国经济的可持续发展。中国全国有超过5000个特色小镇，但都无自己特色，全是照抄浙江的成功经验，没有自己的创新与发展，何谈新经济增长点。另外，他们认为特色小镇极其依赖地方政府的财政支持，加大了地方政府的财政支出，为地方政府带来严重的财政压力。他们也认为特色小镇其实具有房地产化的趋势，许多小镇看起来是科技产业群落，实则是房地产项目，为地方政府或个别企业所牟利。因此，他们认为城镇化无法推动中国经济的可持续发展。

不过，综上比较，我还是认为城镇化在很大程度上推动了中国经济的可持续发展。首先，中国政府已推进"新型城镇化"，讲究"以人为本"，完善社保、推动公共服务均等化，从而帮助农民劳动人口流入城市工作居住后融入城市生活，有效带动他们的消费能力与意愿，推动中国经济的可持续发展。新型城镇化旨在消除"经济上接纳、社会上歧视、文化上排斥、制度上限制"的局面，推动"同工同酬、同工同权"，化解流动人口为城镇社会带来的社会动荡。随着社保的覆盖广度与深度被完善，从改革开放以来，全中国已摆脱绝对贫困，从农村流向城镇的劳动人口可以融入城市，而职业培训等政策也帮助他们流入主流劳动市场，提高他们的可支配收入，从而提升消费能力与意愿。短期来看，这可以拉动城镇的消费对GDP的贡献。而长远来看，这有潜力扩大中国的内需市场，消解阶层固化，让底层劳动人民也可以向上爬，实现阶级跃升，抵消了人口红利与土地红利流失所带来的负面经济影响。所以，城镇化推动了中国经济的可持续发展。

最后，中国政府已陆续推出法规与政策来规范特色小镇的发展。由于特色小镇目前还是一种新兴产业，尚处于发展初期，有一段野蛮生长、探索发展方向的时期是正常的。中国政府在2018年已经下令对全国范围内的特色小镇定期进行评优，优胜劣汰，淘汰产能低下的特色小镇。这将规范特色小镇的发展，让其逐渐成熟发展，成为科技创新的重大推力，带来经济的可持续发展。

综上所述，笔者认为城镇化在很大程度上推动了中国经济的可持续发展。

**Question**: 试根据资料，结合你自已的认识，评价中国政府解决老龄化问题的策略，并就如何更妥善地解决老龄化问题提出建议。(25分)

**Set 1: 鼓励生育**

**指出政府努力**: 根据资料F，"中央政治局指出将实施一对夫妻可以生育三个子女政策及配套支持措施"。此后整顿学区房及校外辅导机构的政策接连出台。

**解释政府努力**: 中国近年来人口出生率持续走低，少子老龄化社会特征明显。只有提高生育率，改善人口年龄结构，才能缓解中国的老龄化。据资料G，中国在1980-2015年实施了"独生子女"政策。当下在老龄化日趋严峻的背景下，通过改革生育政策，对适龄生育群体提供各方面的社会福利及公共服务支持体系，从而提高生育率，从长远、根本上解决老龄化问题，促进社会稳定发展。

**评价政府努力**: 政府在鼓励生育方面的策略还是取得了一定成效，值得肯定。首先从宏观政策层面上，从原来的限制，到现在的鼓励、支持；其次，政府对生育二胎及三胎的家庭给予了资金、教育、升学等各方面的补贴。2024年新出生人口比2023年增加了52万人，实现了阶段性的"止跌反弹"。

**指出不足**: 中国快速的工业化、现代化使家庭生活成本和养育孩子的成本不断推高。全面二孩政策不及预期、三孩政策效果并未显现，未能扭转中国人口出生总体下滑的趋势。2023年中国的生育率为1.3，远低于2.1的人口替代水平。

**提出建议**: 我建议，中国政府构建更完善的生育支持体系。在资金扶持上，加大生育补贴，对二胎、三胎明确给出较高的补贴金额，这样能让年轻夫妇"愿意生"；在养育孩子的公共服务上，加快完善社区托儿、育儿公共服务支持体系，政府负担了部分养育儿成本后，可以减轻养育孩子的成本及付出的精力，让年轻夫妇"敢生"；在政策层面上，保障父亲与母亲平等的产假和育儿假，保障职业母亲的生育权利。

**综合评价建议**:

从可行性来看，资料F提出，中国在解决老龄化方面有制度优势，且提供生育补贴对居民生育意愿有提振的作用。而且，中国政府负债率低，财政支出空间大，能够提供较高的生育补贴及生育福利，此建议的可操作性还是较强的。

从有效性来看，提高生育是缓解老龄化的核心。通过在资金补贴、养育孩子过程中政府提供的育儿、托儿等各服务体系，以及在政策方面对父母的权益保障，使民众"能生"、"愿意生""敢生"。从建议的全面性和针对性来说，其有效性较高。

局限：在资金补贴和社区育儿、托儿的投入上各地方政府因财政能力不同会存在一定的差异，带来不同地区的公平问题。

获得成功的可能性：各地的生育支持体系关系本地长远发展，都会尽力而为。全国各地政策保底不封顶，对生育的夫妇来说，各方面的支持体系能较大程度解决生育的成本和压力后还是会倾向于生育。再综合考量这一建议的可行性和有效性，我认为，此建议符合中国国情，能够在较大程度上获得成功。

**Set 2: 延迟退休**

**指出政府努力**: 根据资料I，中国官方文件《中共中央关于进一步全面深化改革 推进中国式现代化的决定》："按照自愿、弹性原则，稳妥有序推进渐进式延迟法定退休年龄改革。"

**解释政府努力**: 根据资料G，未来十年将有三亿人离开中国的劳动力市场。同时资料G也指出，中国的养老金可能在2035年耗尽。同时，中国也是世界上退休年龄最低的国家之一。灵活的延迟退休既可以保留部分劳动力服务于中国经济发展，同时也延缓养老金的发放，缓解养老金不足的压力，同时与世界其它国家相比，中国也有理由和条件延迟退休。

**评价政府努力**: 据资料I，中国首次提出"自愿"原则是个很大的进步，给与劳动者选择的余地。可根据个人的情况决定是否延迟退休。

**指出不足**: 根据资料I，不少网民质疑，因为"在职分配不公，退休分配不公。这会导致想退的是苦和累的岗位，不想退的都是轻松的岗位。

**提出建议**: 我建议，中国政府统筹制定延迟退休人员的岗位、薪资待遇等方面的原则和范围，通过各地企业贯彻执行。延迟退休人员岗位调整：退居二线，减少工作量，作为经验传授、指导或辅助岗位。这样不挤占年轻人的工作机会，又可以继续工作，创造经济价值的同时，能自力更生，延后养老金的领取，解决老龄化问题。适当减少高工资延迟退休人员薪资水平。对底层延迟退休的工人保障基本维持原有工资水平，对高薪资延迟退休人员的工资适当下调，这样更公平。

**Set 3: 发展银色经济**

**指出政府努力**: 根据资料H，中国政府公布了发展"银发经济"增进老年人福祉的意见，提出了推进产业集群发展等26项举措，目标是完善和发展相关产业。

**解释政府努力**: 中国老龄化不断加速。老年群体不断增大。资料H指出2023年老年人接近2亿2000万。老年群体对养老服务体系、医疗带来了沉重的负担。仅仅依靠政府力量无法满足老年群体的需求。政府通过市场化手段，能扩大养老产品及服务的供给。

**评价政府努力**: 政府通过养老服务及养老产品的市场化发展，基于银色产业的潜力，会刺激老年产品和服务市场的壮大及不断创新，服务于老年群体，同时创造经济价值，这一做法是直接有效的，值得肯定。据资料H，美的在2021年推出了面向老年人的家电。海尔集团也致力老年人产品的开发。

**指出不足**: 根据资料H，老年人对高科技产品认知度不高。同时，银发行业竞争激烈，企业盈利不足。这会导致银发经济发展缓慢，无法通过市场化提供满足2亿多人的老年产品和养老服务。

**提出建议**: 我建议，中国政府从生产端和消费端入手，扶持银色产业发展，满足规模庞大的老年群体的需求。

在生产端：对提供不同老年产品和服务的企业加强扶持、补贴，使这一行业慢慢成长壮大。①针对重要医疗器械生产，复健、护理和养老服务等发挥重大政府补充功能的企业，给予政策、税收、津贴等支持，部分甚至可以采用政府购买服务方式加强政商合作，以促进养老服务及养老科技的发展，满足老龄化社会需求。②针对一般性老年生活用品或医疗保健品，通过国家补贴的方式，降低产品价格，促进老人的购买与使用。

在消费端：针对老年人对老年科技产品认知度不高。建议政府在社区医院、养老院等各类社区平台，配置和宣传这类产品，同时也可以通过志愿者在社区活动或宣传培训等方式讲解示范，让老人能接触到、愿意了解学习、进而接受购买，为自己的养老生活带来便利。

# 11. 逻辑线建构 Logical Chain Construction

## Example 1: 社会阶层分化 - 中产阶级

- **Economic**: 中产是"消费的前卫" -> 拉动内需 -> 经济增长
- **Political**: 中产是"政治的后卫"但不缺位 -> 法治建设 -> 社会稳定
- **Social**: 中产崛起 -> 优化社会结构 -> 缓解贫富分化

## Example 2: 社会阶层分化 (社会稳定)

- 阶层分化 -> 贫富悬殊 -> 阶层矛盾尖锐
- 阶层分化 -> 阶层固化 -> 公平缺失

## Example 3: 加强媒体管制 (社会稳定)

- **Positive**: 意识形态控制 + 内容监管 + 舆论主导
- **Negative**: 威胁言论自由 + 固化"城堡政治"

## Example 4: 绿色转型 (可持续发展)

- **绿色经济**: 经济增长建立在环境和资源承载容量内
- **低碳经济**: 低碳产业结构 + 能源使用低碳化
- **循环经济**: 3R原则 + 共享资源平台
