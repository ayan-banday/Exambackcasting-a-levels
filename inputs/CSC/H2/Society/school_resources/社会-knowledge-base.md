### 01. 梁 J1 第3课题第1讲：社会保障与社会稳定
- **Source:** 梁老师 J1
- **Lecture position:** 课题三 第1讲 (J1 first delivery)
- **Sub-topic:** 社会保障 / 社会稳定 / 社会治理 / 三次分配
- **Key concepts (5 with definitions):**
  - 社会保障 — 国家通过立法对国民收入再分配，对年老/疾病/伤残/失业等导致生活困难的成员给予物质帮助和社会服务的制度体系。基本特征：公平性、普遍性、法治性、互济性。
  - 社会保险 — 社会保障的核心，"五险一金"中的"五险"：基本养老、基本医疗、生育、工伤、失业保险。
  - 社会稳定 — 社会全员的基本需求都得到满足，绝大多数成员能够遵守共同的社会规范，使社会在政治、经济、文化和社会等方面相对平稳、有序、和谐的状态。
  - 三次分配 — 厉以宁1994年提出：初次讲效率、二次讲公平、三次讲社会责任。中国"一次分配不到位，二次分配不公平"导致马太效应。
  - 社会治理 — 国家/政府、非政府组织、市场/企业、公民等多元主体协调，推进社会有序、持续、和谐发展。
- **Core argument:** 社会保障是社会稳定的"安全网"、社会公平的"调节器"、经济运行的"减震器"。中国社保从毛时代城乡二元分割→邓时代启动改革→江朱时代搭建框架→胡温时代全覆盖→习时代驶入快车道。中国已建成世界最大社保安全网（13.79亿持卡，覆盖97.7%），但仍面临不充分（覆盖深度低、支出占GDP仅3.21%）、不公平（城乡/地区/群体差距）、不可持续（老龄化、经济下行）、碎片化（多龙治水）四大问题。
- **Specific data / cases / years:**
  - 2024年社保卡持卡13.79亿人，覆盖97.7%人口
  - 2021年社保支出14万亿元，占GDP约13%（注：与后述3.21%存在矛盾，可能指广义vs狭义）
  - 2020年社保支出占GDP的3.21%，2021年下降到2.96%（远低于OECD的26.7%）
  - 流动人口养老/医疗/工伤保险覆盖率18.14%/16.66%/11.95%
  - 2023年60岁及以上29697万人(21.1%)，65岁及以上21676万人(15.4%)
  - 2023年企业退休人员月均养老金比2012年增加一倍，月均失业保险金从707元提高到1814元
  - 2016年ISSA授予中国"社会保障杰出成就奖"
  - 1991年33号文件三层次养老保险；1995年统账结合；2010年《社会保险法》；2014年城乡居民基本养老合并；2016年城乡居民基本医保合并；2015年机关事业单位养老打破"双轨制"

### 02. 梁 J1 第3课题第2讲：城镇化与流动人口
- **Source:** 梁老师 J1
- **Lecture position:** 课题三 第2讲 (J1)
- **Sub-topic:** 城镇化 / 流动人口 / 户籍制度 / 三农问题 / 农民工
- **Key concepts (5 with definitions):**
  - 城镇化 — 第二、第三产业向城镇聚集，农村人口向城镇转移的过程。2024年中国城镇化率67%。
  - 新型城镇化 — 2014年提出，"四化同步"（工业化主导、农业现代化基础、信息化引领、城镇化载体），核心是农民工市民化。
  - 流动人口 — 离开户籍所在地，"人户分离"为核心特征。2021年3.85亿，占总人口27.2%。
  - 户籍制度 — 1958年《户口登记条例》，世界最严人口移动控制制度，城镇/农村二元分割。
  - 推拉理论 (Push-Pull) — Everett Lee提出，迁出地推力 + 迁入地拉力共同作用。
- **Core argument:** 改革开放后中国从"乡土中国"低流动性向"迁徙中国"高流动性转变。流动人口为中国工业化提供人口红利（每增1%带来GDP增长0.54%），但也产生"大城市病"和留守老人/儿童问题。新型城镇化核心是农民工市民化，需建立中央-地方成本分担机制（每位农民工市民化成本13万元）。
- **Specific data / cases / years:**
  - 2024年城镇化率67%；2025年常住人口城镇化率67.89%
  - 户籍人口城镇化率46.7%（2021），低于常住18个百分点
  - 流动人口：2010年2.20亿→2020年3.76亿→2021年3.85亿
  - 2020年省内流动2.51亿，省际流动1.25亿（增幅85.7% vs 45.4%）
  - 2022年农民工2.96亿
  - 1978年安徽凤阳小岗村包产到户；1984年城市改革；1994年分税制
  - 流动人口对GDP贡献：1978-2015年平均19.99%；1978-1989年最高57.79%；2003-2008年超40%
  - 北京外来人口对GDP贡献率最高36.2%；上海34.55%
  - 农民工市民化人均公共成本约13万元
  - 城乡居民收入比2.69
  - 2018年农村留守儿童697万人，96%隔代抚养
- **Cross-课题 connections:** 经济（出口导向、人口红利）、社保（农民工社保覆盖）、民族（新疆7.5事件源于韶关流动人口冲突）
- **Maps to 集锦 question(s):** Q22, Q24, Q25

### 03. 梁 J1 第3课题第3讲：公民社会的兴起与中国社会治理
- **Source:** 梁老师 J1
- **Lecture position:** 课题三 第3讲 (J1)
- **Sub-topic:** 公民社会 / 非政府组织 / 社会治理 / 善治 / 社会运动
- **Key concepts (5 with definitions):**
  - 公民社会 — 国家和市场之外的所有非政府组织或民间关系的总和，"第三部门"，具有非官方性、独立性、自愿性。
  - NGO — 不隶属政府的民间组织，独立性、非营利性、志愿性。
  - 社会治理（善治） — 国家与社会良性互动、协同治理。基本要素：合法性、透明性、责任性、法治、回应有效。
  - 风险社会 — 1986年贝克(Beck)提出，工业社会以后人类进入风险社会。
  - 双重管理 — 1989年《社会团体登记管理条例》，民政登记+业务主管单位双轨控制。
- **Core argument:** 改革开放后国家向社会放权，公民社会复兴。亨廷顿：政治稳定的关键是政府能否将社会变迁制度化。中国NGO发展受双重管理体制制约，2015年起遭全面打压（《境外NGO管理法》2017年实施）。中共党内对"公民社会"概念存在分歧：周本顺称之为"陷阱"，俞可平主张支持。中国"强政府-弱社会"使其无法成为真正意义的公民社会。
- **Specific data / cases / years:**
  - 1981年中国儿童少年基金会成立（中国第一个真正意义的NGO）
  - 1995年北京世界妇女大会（NGO发展里程碑）
  - 2008年汶川地震（NGO元年）
  - 2017年《境外NGO管理法》生效，主管部门由民政部改为公安部
  - 2024年底中国基金会9867家，公募基金资产32万亿元
  - NGO平均每年募集超500亿元公益资金
  - 2010年中国民政部调查：96%环保志愿组织全职员工属低收入群
  - 2023年底社会组织88.16万个（2022年89.13万，首次负增长）
  - 上海调查：60-70%社会组织负责人有党政背景
  - 案例：自然之友、天则智库、中华志愿者协会、韩红爱心基金会、怒江反坝、自由之家
- **Cross-课题 connections:** 政治（民主、监督）、经济（市场监管）、外交（公共外交、软实力）
