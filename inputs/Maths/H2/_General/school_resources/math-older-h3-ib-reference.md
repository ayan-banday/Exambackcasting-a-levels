## Part 1: Older Papers 2008-2009 (Pre-9740/9758 era)

### Syllabus context

- 2008-2009 papers use code **9740** (H2 Math) which was the predecessor to **9758** (current syllabus, from 2017 onward)
- Paper structure was nearly identical: P1 (3 hr, all pure) + P2 (3 hr, Section A Pure 40m + Section B Stats 60m)
- Major changes 9740 → 9758:
  - **Removed from 9758:** Polar coordinates, second-order DE (homogeneous DEs reduced), Maclaurin series via repeated differentiation made simpler, some hypothesis testing nuances
  - **Modified:** Vectors content tightened (less foot-of-perpendicular variation), complex numbers loci simplified
  - **Retained:** ~90% of content — functions, graphs, sequences/series, induction, vectors, complex numbers, calculus, DEs, P&C, probability, distributions, sampling, hypothesis testing, correlation/regression

## Math Supplementary Patterns (Synthesis)

### Evolution: 9740 (2008-2009) → 9758 (2017+)

**Topics RETAINED in 9758 (high priority — older papers are usable):**
- Inequalities (algebraic + graphical, polynomial, modulus)
- Functions (one-one, inverse, composite, domain restrictions)
- Graph transformations (1/f(x), f'(x), y^2 = f(x), |f(x)|)
- Sequences and series (AP/GP, recurrence, induction, method of difference)
- Binomial theorem (positive integer + general index, validity)
- Maclaurin series (standard + repeated differentiation)
- Vectors (lines, planes, points, projections, distances, reflections)
- Complex numbers (Cartesian + polar, loci, equations z^n = w, conjugate properties)
- Differentiation (implicit, parametric, related rates, stationary points, Maclaurin)
- Integration (substitution, by parts, partial fractions, area, volume of revolution)
- Differential equations (separable, linear, substitution-reducible — but **first order only** in 9758)
- Probability (conditional, independence, Bayes implicit)
- Permutations and combinations
- Discrete distributions (binomial, Poisson)
- Normal distribution + linear combinations
- Sampling and CLT
- Hypothesis testing (z-test, t-test)
- Correlation and regression

**Topics REMOVED or REDUCED in 9758 (older papers may have these — skip):**
- **Second-order differential equations** (e.g., 4y'' + 4y' + y = 0) — REMOVED from 9758
- **Polar coordinates** — was occasionally in 9740, removed in 9758
- Some complex number proofs using De Moivre with very high powers
- Statistics: Some legacy hypothesis testing variations (paired t-test conventions changed)

**Topics NEW in 9758 (older papers won't have these):**
- Application questions (real-world contexts) given much heavier weight
- More structured questions blending two topics
- Statistical reasoning questions (commenting on assumptions, validity)

**Format changes:**
- 9740 → 9758 timing: P1 stayed 3 hr, P2 stayed 3 hr — same paper length
- Question count similar (10-12 per paper)
- Mark allocation similar (100 per paper, 200 total)
- 9758 papers tend to have slightly more sub-parts and more context wrappers

### H3 Difficulty Markers Transferable to H2 Advanced Sub-Questions

Cambridge's "hard" question construction techniques (visible in H3, occasionally surface in H2's final sub-parts):

**1. Multi-step proof chain with bridging insight**
Example: H3 2014 RI Q1 — Show (i) y_n = y_{n-1}y_{n-2}/(y_{n-1}+y_{n-2}+2), (ii) 0 < y_n < 1, (iii) y_n < (1/2)y_{n-1}, (iv) hence series converges. Each step uses the previous; missing one breaks the chain.

**2. Unfamiliar context wrapping a familiar technique**
Example: H3 2020 RI Q2 — Substitution x = 1/t in integral I = ∫f(x)/[x(f(x)+f(1/x))] dx looks unfamiliar but reduces to standard substitution + symmetric integrand → I = (ln a)/2.

**3. Synthesis across topics**
Example: H3 2014 RI Q8 — Spruce budworm DE combines DE qualitative analysis + Maclaurin series + bifurcation diagram. Each sub-part uses a different syllabus skill.

**4. Reverse direction of standard reasoning**
Example: H3 2017 RI Q4 — Given two regression lines, deduce something about Σ a_i / b_i where (b_i) is a permutation. Standard direction = derive regression line; reverse = use to prove inequality.

**5. Existence/uniqueness arguments**
Example: H3 2020 RI Q5 — Show solution to y' = f(y), y(0) = 1 is unique using Lipschitz condition. Then construct counter-example for non-Lipschitz case w' = 2√w.

**6. Combinatorial bijections**
Example: H3 2020 RI Q3(iv) — Show number of arrangements (10 people, each gets different neighbour after return) = Σ_{k=0}^9 (-1)^k C(9,k) (10-k)!. Bijection between arrangements and derangements with constraints.

**7. Modular arithmetic / number theory**
Example: H3 2020 RI Q8 — Show ((p-1)/2!)^2 ≡ -1 (mod p) using Wilson's theorem, then construct elements whose squares sum to p.

**8. Inequality bounding with creative function choice**
Example: H3 2014 RI Q2 — AM-GM on five "1"s and x^6 gives x^6/(x^2+1)^4 ≤ 1/16 for |x| ≤ 1; then bound integral.

**9. Recurrence to closed form via substitution or generating function**
Example: H3 2020 NYJC Q4 — Coin scoring recurrence p_n = (1/3)p_{n-1} + (2/3)p_{n-2}, solve to find p_7.

**10. Pigeonhole on unexpected partition**
Example: H3 2020 HCI Q8 — Polynomial S(x) with S(a) = S(b) = S(c) = S(d) = 2009; show no n with S(n) = 2020 by considering factors of S(n) - 2009.
