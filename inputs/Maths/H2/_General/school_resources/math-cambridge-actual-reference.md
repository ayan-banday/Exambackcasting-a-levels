## Recurring exam-style stems (from actual papers, NOT prelims)

**"Show that..."**
- Used when an algebraic identity needs verification with rigour.
- Examiner expects FULL working with no shortcuts; "by GC" not accepted as proof.
- Common pattern: "Show that f(x) can be written in the form..." (2019 P1 Q3, 2022 P1 Q4).
- "Show that ... satisfies ..." for differential equations (2014 P1 Q11 cone, 2018 P1 Q10 RLC circuit).

**"Hence..." vs "Hence or otherwise..."**
- "Hence" REQUIRES using the previous part's result. Tutorial work showing this is fragile — if you don't use it, you lose marks even with correct independent answer.
- "Hence or otherwise" allows independent method but rewards using previous result. Default to "hence."
- Common in MOD problems (Σ part i then Σ from r=11 to ∞ part ii) — 2019 P1 Q6.

**"By using the substitution..."**
- Explicit substitution given in question. Must perform u-substitution exactly as specified.
- Often in integration (2022 P2 Q1 u²=x+2; 2014 P1 Q8 trig substitution u=sin θ).

**"Without a calculator" / "Do not use a calculator"**
- Non-calculator questions require ALL algebraic steps shown.
- Common in: complex number factorisation, root finding via polynomial division, exact integration (2019 P1 Q2 partial; 2020 P1 Q7 trig integration; 2022 P1 Q1, Q4).
- GC may be used to CHECK but not as the method.

**"Find the EXACT value..."**
- Requires algebraic form (surds, fractions, π, e, ln). No decimal.
- Common in: integration evaluations, sum to infinity, definite areas, complex moduli.

**"In terms of..."**
- Express the answer using specified variables (often as proxies for constants).
- Don't substitute numerical values for the unknowns.

**"Hence or otherwise show that the curve has exactly one real root..."**
- Use monotonicity (gradient sign analysis) + Intermediate Value Theorem signal change for exactly-one-root proofs (2017 P1 Q5).

## Calibration: prelim vs actual Cambridge

**Style differences (verified across the 26 files):**

**Cambridge actual papers tend to:**
- Use cleaner contextual setups (e.g., 2019 Q11 ice freezing — clean physical model)
- Specify exactly what form the answer should take ("in the form p{(x+q)³+r}", "where a, b, c are integers")
- Ask multi-stage applied questions (especially in 9758) — 2019 Q12, 2020 Q11
- Have shorter sub-parts (2-4 marks each) but more of them
- Use "Hence" deliberately to force linking parts
- Test interpretation and judgment more (especially in Stats: "Comment on the suitability", "Explain why...")

**Prelim papers (JC mock papers) tend to:**
- Have longer sub-parts with more marks each (5-8 mark sub-parts common)
- Be more algebraically heavy without context (more "find the value of x s.t. ...")
- Include more "trap" questions designed to catch syllabus subtleties
- Use more obscure substitution choices in integration
- Have somewhat random / disjointed topic blends (less integrated)
- Test recognition of standard forms (MF26 page references implicit)
- May include questions slightly beyond core syllabus (especially in vectors, complex loci)

**Patterns to preserve as Cambridge style for practice:**
- Multi-stage applied questions with physical/economic/biological context
- Explicit "show that" steps with parameter-tracking
- Hypothesis testing in stats always context-anchored (not pure z-table look-up)
- MOD problems with extension to "deduce sum from r=k onwards"
- Vector questions with normal computed via cross product
- DE problems with separable + boundary condition

**Patterns to discount as "school style":**
- Random multi-topic blends (e.g. complex + vectors + integration all in one Q)
- Questions requiring obscure factor formula manipulations beyond MF26 standard
- Heavy reliance on "by GC" for non-trivial polynomial roots
- Questions where the algebra is the main challenge rather than the concept

## Mark scheme conventions (extracted across all papers)

**M1 (Method mark):** Awarded for correct procedure/method, even if computational error.
- Example: Setting up implicit differentiation correctly even if a sign is wrong.
- Example: Setting up Σ from r=1 to n with correct general term but arithmetic slip.

**A1 (Accuracy mark):** Awarded only for the correct final answer (or intermediate result if specified).
- Often paired: M1 A1 sequence shows method then answer.
- A1 follows M1 — you cannot get A1 without the corresponding M1 (or independently if directly computational).

**B1 (Independent mark):** Awarded for a standalone correct statement or result.
- Often for definitions, statements of assumptions (binomial conditions FIST), or contextual conclusions in hypothesis testing.

**Method marker priorities (what earns marks):**
1. **Setting up the equation/expression correctly** (often M1)
2. **Applying the correct technique** (M1)
3. **Reaching the correct numerical/algebraic answer** (A1)
4. **Writing the answer in the form requested** (A1 may be withheld if form is wrong)

**Acceptable alternatives:**
- For curve sketching: GC-generated curve with all features labelled is acceptable.
- For series convergence: explicit limit notation (n→∞) or "→ 0" expression is acceptable.
- For complex number arguments: polar (cos θ + i sin θ), exponential (re^(iθ)), or trigonometric form all accepted.

**Common deductions:**
- Missing "+C" in indefinite integrals: -1 mark
- Missing modulus in ln integrations: -1 mark when domain requires it
- Wrong rounding (e.g., asking 3sf and giving 2sf): typically not deducted unless severe
- Missing units in applied contexts: -1 mark possible
- Not stating assumptions in hypothesis testing: full mark not awarded for the assumption mark

**"Show that" vs "Find":**
- "Show that": MUST end with the given expression matched exactly; full algebraic steps needed.
- "Find": Answer suffices if working clearly shows method (in some cases, GC can be used directly).
