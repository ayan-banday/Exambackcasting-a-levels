# PART 2 — ASSESSMENT OBJECTIVES & WHAT EACH PAPER REWARDS `[OFFICIAL]`

- **AO1 — 对知识的理解与应用:** understand + apply knowledge of contemporary China's economy / politics / society / international relations + related concepts.
- **AO2 — 对课题的分析与评价:** explore a set topic + its 发展趋势; analyse / evaluate / synthesise different views; build a 前后一致、言之有据 argument; draw sound inferences and conclusions from strong evidence.
- **AO3 — 对资料的诠释与评价:** interpret / analyse / evaluate / synthesise sources; infer outcomes/trends from sources; analyse the viewpoints of different sources; **propose strong recommendations to solve problems**.

**Key marking note `[OFFICIAL]`:** "AO1 是 AO2 和 AO3 评价的一部分" (syllabus, 试卷蓝图 备注). AO1 is **embedded, never scored alone** — no marks for knowledge dumped without analysis (AO2) or without being tied to sources (AO3, Paper 1). **Paper 1 = AO1+2+3. Paper 2 = AO1+2 only** (no source-handling).

# PART 4 — PAPER 1 DEEP ARCHITECTURE (案例分析) — `[OFFICIAL]` structure, `[SCHOOL]` method

Each sub-question has a fixed function, mark, Bloom level, method, and signature trap. Worked thread = the **2024 specimen 案例分析一: 中国软实力** (sources A–E). The step procedures and traps below are now **verbatim-corroborated** by 朱's 2025 案例分析答题注意事项 SOP (`[SCHOOL]`).

**Time budget `[SCHOOL]` (朱's SOP):** P1 = 165 min. A组 read ≤15 min · 1(a) ≤14 · 1(b) ≤20 · 1(c) ≤18 · 1(d) ≤27. B组 read ≤15 · Q2 ≤56.

## 1(a) 解释题 [6] — Understand→Analyze
- **Asks:** explain a 概念/现象/趋势/特征/关系 from a named source. Specimen: *"试根据资料 A 关于中国软实力的相关数据，解释中国软实力的特征."*
- **Method `[SCHOOL]`:** 描述 (是什么, from the source) → 解释 (为什么, source + own knowledge). To reach 三 (5-6): **2 features + 1 reason, OR 1 feature + 2 reasons**; best is **2 paired (1特征+1原因) segments, one per paragraph (一一对应)**. Must use **all** charts/info given.
- **Trap `[SCHOOL]`:** pure description → **cap 2/6** (drops to 层级一). Only one pair → cap mid-band. Ignoring one of two charts.

## 1(b) 观点对比题 [9] — Analyze→Evaluate
- **Asks:** compare TWO named sources' viewpoints. Specimen: *"试比较资料 B 和 D 关于中国提升软实力的观点."*
- **Method `[SCHOOL]`:** 相同点 → 不同点 (find both from 总体立场/局部观点/方式手段/原因/结果成效/影响/趋势) → **结合资料 + 自己的认识 analyse the 异同** → clear 同>异 / 同<异 conclusion. **明确区分整体立场 (overall stand) 与局部观点 (partial viewpoint)** — 朱's SOP flags this as the recurring error.
- **Band note `[OFFICIAL]`:** 三 (7-9) = *分析* (not just 解释) the 异同. (The explicit "同>异/同<异" verdict is `[SCHOOL]` house style — rewarded, not in the official band.)
- **Trap `[SCHOOL]`:** describing/摘录 two sources without comparing → cap in 层级一. Source 出处 (国内/国外、官媒/民间) is **辅助论证 only** — analyse the viewpoints themselves.

## 1(c) 评价资料适用度 [8] — Evaluate
- **Asks:** evaluate ONE source's **适用度 (usefulness)** for explaining a stated point. Specimen: *"若要解释中国提升软实力面对挑战，试评价资料 C 的适用度."*
- **Method `[SCHOOL]` (朱's 4-step):** 概括 (1-2句) → **2 优点/有效性** ("若要说明…，资料C的优点如下") → **2 局限/缺点** ("但是，美中不足的是…") → 比较优缺点 → **明确 大/小 verdict**.
- **Limitation angles `[SCHOOL]`:** 无法直接说明问题 · 缺乏纵向比较(单一年份) · 无法整体涵盖(个别领域/层面) · 缺乏广泛代表性(样本不足/受访者背景未给) · 带预测成分(不好妄下结论).
- **THE 1(c) trap (most-cited) `[SCHOOL — verbatim in 朱's SOP]`:** "题目问的是'资料有用吗?'，而不是'资料信息说的，你同意吗?'" — evaluating whether the source's *view is right* instead of its **适用度**. Also: **never say "中等 / 在一定程度上适用"** — commit to 大 or 小. Never say 适用 for strengths then 不适用 for weaknesses (self-contradiction).

## 1(d) 资料是否支持论点 [12] — Evaluate (degree-of-support)
- **Asks:** to what extent do 3 sources (usually C/D/E) **说明/支持** a claim about 政府努力. Specimen: *"资料 C, D 和 E 在多大程度上说明中国政府在提升软实力方面所做出的努力？试加以分析."*
- **Method `[SCHOOL]`:** 正面 (sources DO show the efforts, 从道理/论据) → 反面 (sources lack 针对性 / mention efforts that are 不足/遇挑战) → compare on ①针对性 ②有效性 → degree judgment. (Two routes in 朱's SOP: thematic, or source-by-source then compare.)
- **THE 1(d) trap (biggest) `[SCHOOL — verbatim]`:** "要分析的是，资料能否说明努力，而不是去评价政府的努力." The meta-question is the **sources' explanatory power**, not the policy.

## B组 Q2 评价 + 建议 [25] — Evaluate + Create
- **Asks `[OFFICIAL]` form is flexible:** *"试根据资料，结合你自己的认识，评价中国政府的[努力/策略/对X政策]，并就如何[目标]提出建议."* Specimen: *"评价中国政府的对美策略，并就如何建立中美之间的'新型大国关系'提出建议."*
- **Mark history `[SCHOOL — verbatim in 朱's SOP]`:** this题型 has appeared every 会考 since 2017; it was **15 marks 2017–2023 and became 25 marks from 2024**. (So 2026 = 25-mark version, matching the syllabus.)
- **Engine (the only way to 五) `[SCHOOL]`:** TWO parallel cycles of **[评价政府努力(from 资料) + 提出建议]**; each recommendation run through 落实 (分步骤 / 分层面 / 分领域 / 分责任主体) + 有效性 + 可行性 + 局限性 + 成功可能性 (the 四维 — Part 6.4). "评价努力" and "建议" are **equally weighted**.
- **Traps `[SCHOOL]`:** one cycle instead of two; 建议照搬资料 (must be **创造性转化**); 建议 万金油 ("加强教育、完善制度" → rejected as 不具针对性); 建议 disconnected from the 不足 it should fix; 政府努力 sourced from own knowledge instead of 资料.

# PART 5 — PAPER 2 DEEP ARCHITECTURE (问答题) `[SCHOOL]`

## 5.1 The universal essay skeleton (every essay, every 题型) — corroborated verbatim by 沈's deck
1. **界定关键词 + 表明立场** — define key terms; declare 立场 explicitly in the intro (no stance → caps at Tier 2).
2. **立场分析 [正]** — 3 distinct supporting angles (沈: "从三个不同角度切入"). Each paragraph = **PEEL**: 论点(Point) → 论据(Evidence/Example) → 论证(Explanation/Elaboration) → 逻辑(Link).
3. **平衡分析 [反]** — 2 genuine counter-points (沈: "两个平衡点"; introduced "有人认为/有学者表示"). Strawman = fake balance = dismissed.
4. **比较分析 / 程度判断 [合]** — 沈: "反驳所有的平衡点后，你为何仍坚持此立场？从影响范围/程度/问题性质/解决难度…进行比较." Do NOT flip stance.
5. **批判性总结.**

## 5.2 The 题型 selector `[SCHOOL]` — read the stem, pick the template (沈's deck names 7 types; 朱-style verb rule for edge cases)

| 题型 | Trigger words | Stance method (from 沈's flow diagrams) |
|---|---|---|
| **是非题** | 是/能/有助于/威胁了/将/应该/利大于弊 | 正 argue claim → 反 refute the **direct opposite** ("有人认为…") → 合 逐个反驳, 坚持立场. |
| **最字题** | 最大/最重要/最根本/最关键/最严峻 | AGREE: 立场 = topic factor → 平衡 = introduce **2** other factors ("有人认为…也有人认为…") → 比较, topic factor wins. DISAGREE: 立场 = **先做题目因素的局限** + introduce **1** more-critical factor → 比较, your factor wins. |
| **关键题** | 关键/根源/罪魁祸首/动力源 | Same engine as 最字 (沈 treats 关键题 as its own slide): AGREE → 2 other factors; DISAGREE → 局限 + 1 more-key factor. |
| **程度题** | 在多大程度上 (推动/提升/阻碍/影响) | Commit to 高度/较大/一定/较小程度. 2×3 matrix: 立场 analyses 因→果 **作用** (if 较大) or **局限** (if 较小); 平衡 analyses the opposite; 比较 reaches 程度判断. |
| **条件题** | 必须…才能 / 只有…才能 / 唯有 / 只要…就能 / 前提 | 反方 = TWO layers: **自身局限** ("即使有X也不足以Y") + **其他条件** ("即使没有X也能Y"). 合 = 题目条件 VS 自身局限 + VS 其他条件. |
| **比较题** | 大于/多于/比…更 / 利大于弊 | 立场 = the bigger side → 平衡 = the other side → 比较 + 程度判断. |
| **非典型** | unclear / new | apply 正-反-合 anyway. **Verb rule `[SCHOOL]`: 在多大程度上 + 能够 → 是非题; + 有赖于/取决于 → 条件题. Read the verb after the degree phrase.** (沈's deck: "中国的崛起在多大程度上有赖于良好的中美关系？"→前提条件题; "中国在多大程度上能够凭借软实力成为世界强国？"→是非题.) |

> **Misreading 题型 wastes the whole essay** (wrong template). The verb rule and "最字/关键 ⇒ 引入其他因素 + 解决难度/性质 axis" are the two highest-value classification moves.

## 5.3 Worked 题型 examples `[SCHOOL]` (real stems from 沈's deck + 2025 promos + 集锦)
- **是非题 / 投资 (沈 例1):** *"依赖投资驱动的增长策略不利于中国经济的可持续发展。"* 同意 → 立场: 地方债↑/投资结构不合理/加剧区域不平衡; 平衡: 固投稳定器/改善城乡居住; 比较: 长期弊大于利、房价压力 → 坚持同意.
- **最字题 / 服务业 (WA2 范文):** *"扩大服务业开放是中国推动经济可持续发展的最佳策略。"* 不同意 → 立场: 自身挑战(人才软件不足) + 外部困境(中美博弈/小院高墙, 跨外交) → 平衡: 要素/市场/制度三层开放好处 → 比较: 实践中博弈削弱 + 绿色发展是更优选择 → 坚持不同意.
- **关键/绿色 (沈 例2):** *"推动绿色发展是中国高质量经济增长的最有效途径。"* 不同意 → 更有效是扩大内需(释放中产消费, 三低四高); 比较: 迫切性 + 解决难度(绿色面对央地博弈) → 坚持不同意.
- **意识形态合法性 (沈 例3 / 2024 specimen Q):** *"加强意识形态建设是当前中共巩固政权合法性的主要途径。"* 不同意 → 现实政绩合法性 is the real base; 平衡: 意识形态弥补绩效空缺; 比较: 现实民生问题更主要 → 坚持不同意.
- **程度 / 政治透明度 (沈 例4):** *"政治透明度不足在多大程度上阻碍了中共对国家的治理？"* 较大程度 → 立场: 腐败泛滥/社会公平缺失; 平衡: 廉政建设消除部分负面; 比较: 制度改革离现代化仍远、运动式反腐治标不治本 → 较大程度.
- **是非 / 宗教 (沈 例6):** *"宗教复兴对中国的社会稳定利大于弊。"* — 信仰需求 vs 宗教组织/西方干涉; 比较: 宗教事务个案管制.
- **程度 / 外交 (2024 specimen Q4):** *"中国在多大程度上会取代美国成为世界领导者？"* split verdict by 领导 definition — 经济(GDP/一带一路/RCEP/人民币) 较大; 制度/价值观/军事同盟 较小.

# PART 6 — THE ANSWER-CONSTRUCTION ENGINE `[SCHOOL]`

## 6.1 正-反-合 with real balance
平衡 must be a genuine opposing position with real 论据, not a token sentence. 合 refutes each 反方 from a *higher dimension* without abandoning your 立场 (沈: 正 thesis / 反 antithesis / 合 synthesis).

## 6.2 The comparison-axis toolkit `[SCHOOL — verbatim in 沈's deck]` (name the axis in 合)
**性质:** 辅助 vs 关键作用 · 次要 vs 主要手段 · **治标 vs 治本** (短期/表面 vs 长期/根本). **效应:** 理论 vs 实践 · 局部 vs 整体 · 个别领域 vs 跨领域 · 微观(地方管理) vs 宏观(顶层设计). Plus **结构性 vs 技术性 (减量 vs 增量改革) — the most-used axis in 最字 essays.** Tier-5 rule: **name the axis + reach a 程度判断.**

## 6.3 跨课题 (the single hardest reward — gates 19+) `[OFFICIAL gate, SCHOOL method]`
Every essay must cross ≥1 extra 课题. Treat the cross-link as the **natural endpoint of the causal chain**, not a bolt-on. The syllabus itself names the cross-范畴 logic for each 课题 (跨范畴 column, Part 9). Standard chains: 经济转型↔政治改革(央地财权) · 经济↔社会(中产/城镇化/社保) · 经济↔外交(一带一路/中美贸易) · 政治合法性↔经济绩效 · 政治↔社会(NGO/网络参与/媒体) · 社会↔外交(民族主义/少数民族↔国际干涉).

## 6.4 The 建议 four-dimensional analysis `[SCHOOL — verbatim in 朱's SOP]` (Section B + any 建议)
Each recommendation, after 落实 (分步骤 / 分层面 宏观↔微观 / 分领域 / 分责任主体 政府企业人民):
1. **有效性** — 针对性 / 治标治本 / 时效 / 案例
2. **可行性** — 实施方式 / 渠道 / 利益主体 / 资源支持
3. **局限性** — 副作用 + 制度因素 (无法全覆盖/财政不足) / 人为因素 (既得利益者阻力)
4. **总结 (成功可能性)** — "对该建议的成功抱谨慎的乐观" (= the `[OFFICIAL]` 成功可能性 requirement for 五).

## 6.5 建议-by-domain matrix `[SCHOOL — verbatim in 朱's SOP]` (where to look for ideas)
- **经济类** → 理清政府/市场边界 (efficiency) + 提质增效升级 (productivity).
- **政治类** → 权力分配 (财权/事权) + 权力运行 (问责/监督).
- **政策类** → 决策 / 执行 / 监督 三环节.
- **治理类** → 赋权社会: 制度化/非制度化利益表达 + 知情/表达/参与/监督权 → 获得/幸福/安全感.
- **外交类** → 创造利益交汇点 / 扩大共同利益 + 外交斡旋 / 第三方调节管控分歧.

# PART 12 — THE EXAMINER'S MENTAL MODEL `[SCHOOL]` decoded from `[OFFICIAL]`

Beneath the surface, 9629 is not testing whether you *know about* China — it is testing whether you can **think like an analyst of contemporary China under uncertainty**:
- **AO1 knowledge is the floor, never the score.** Every mark above 层级二 is for *what you do* with the knowledge: analyse trends, weigh competing views, judge sources, recommend. Knowledge dumped = capped low.
- **The exam rewards balanced, cross-cutting causal reasoning over one-sided advocacy.** The 18→19 wall (平衡 + 跨课题) is the whole grading philosophy in one rule: a single-范畴, one-sided essay is structurally incapable of 四级, no matter how much data it carries.
- **It rewards judgement, not hedging.** 1(c) must commit to 大/小; essays must commit to a 程度/立场 and defend it through the counter-arguments. "中等 / 在一定程度上" is penalised.
- **It rewards the Singapore vantage point.** The syllabus 说明 names "从新加坡的角度考虑新中关系" and 环球意识 — the strongest answers read China's rise through its regional/global consequences, not from inside the CCP frame.
- **Sources are evidence to be cross-examined, not quoted.** P1 is an exercise in 信息素养: usefulness, representativeness, 纵向比较, prediction-vs-fact — the examiner wants you to interrogate the 资料, not believe it.
