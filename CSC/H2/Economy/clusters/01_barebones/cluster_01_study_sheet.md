## Meta-frame

**中国经济增长模式转型：要素驱动 / 投资驱动 / 出口驱动 → 创新驱动 / 消费驱动。目标：跨越"中等收入陷阱"，实现"高质量发展"。**

Every 经济 essay ultimately positions itself relative to this transformation.

---

# P1 — 出口导向型经济 (Export-oriented model — 已到达局限)

**L1 macro:** 依赖 "两头在外" / 世界工厂 / 三驾马车中的出口马车。已到达结构性局限，必须转型。

**L2 sub-arguments:**

- **P1.1** 对外开放与出口导向型经济发展 — how 改革开放 + 沿海特区 + 外资引进 built the export engine
- **P1.2** WTO 与全球价值链 — how 2001 accession scaled the model to "世界工厂"
- **P1.3** 外部挑战：外贸依存度过高 + 中美贸易战 — the vulnerability the model created
- **P1.4** 内部挑战：内需不足 + 三驾马车失衡 — how one-legged growth distorts the domestic economy
- **P1.5** 三红利转换：人口红利 → 创新红利；市场化红利 → 制度红利；全球化红利 → 双循环 — the pivots the transition requires

---

# P2 — 投资驱动 + 国企 / 银行 / 地方债 nexus

**L1 macro:** 分税制 → GDP 晋升锦标赛 → 基建 / 房地产 / 四万亿 → 僵尸企业 → 地方债。投资边际回报递减，模式不可持续。

**L2 sub-arguments:**

- **P2.1** 分税制改革 + GDP 晋升锦标赛 — the incentive structure that produced local-government investment mania
- **P2.2** 投资驱动型经济增长方式 — the mechanics (政府主导 + 高投资率 + 资本密集型)
- **P2.3** 边际回报递减 + 房地产萎靡 — why more investment now buys less growth
- **P2.4** 地方债务风险 + LGFV — how the model got financed off-balance-sheet
- **P2.5** 银行不良资产四大来源 — 非金融企业债务 + 居民债务 + 地方政府债务 + 中小金融机构

---

# P3 — 扩大内需 + 消费主导型转型 (双循环)

**L1 macro:** 三驾马车再平衡。双循环。十四五。两新一重。核心 = 让内需接棒出口。

**L2 sub-arguments:**

- **P3.1** 中国内需三重失衡 — 消费/投资 比例失衡 + 居民消费不足 + 服务消费占比过低
- **P3.2** 双循环与内需 — the 2020 policy pivot (国内大循环为主体 + 双循环互补)
- **P3.3** 消费拉动三大障碍 — **没钱花 + 不敢花 + 花不掉**
- **P3.4** 有效投资 / 两新一重 — how investment reorients toward new infrastructure + urbanization + water/transport
- **P3.5** 城镇化 = 内需最大潜力 — why urbanization is the biggest structural lever

---

# P4 — 供给侧改革 + 国企混改

**L1 macro:** 三去一降一补 + 抓大放小 + 管资本 + 混改 + 现代企业制度。目标 = 让国企有效率但保党的领导。

**L2 sub-arguments:**

- **P4.1** 供给侧结构性改革 — **三去一降一补** (去产能/去库存/去杠杆/降成本/补短板)
- **P4.2** 抓大放小 — the SOE restructuring principle (keep the big, release the small)
- **P4.3** 现代企业制度 — the corporate governance goal (产权清晰/权责明确/政企分开/管理科学)
- **P4.4** 混合所有制改革 — the mechanism ("混"是手段, "改"是核心, "效"是目标)
- **P4.5** 国企双重性 (公益性 + 企业性) + 两个一以贯之 — the tension between party leadership and market efficiency

---

# P5 — 科技开放 + 自主创新 (卡脖子)

**L1 macro:** 引进 → 消化 → 吸收 → 再创新。市场换技术。中美博弈 "小院高墙"。创新驱动 = 跨越中等收入陷阱的钥匙。

**L2 sub-arguments:**

- **P5.1** 引进-消化-吸收-再创新 — the historical technology upgrade path (拿来主义 / 市场换技术)
- **P5.2** 开放式创新 vs 自主创新 — why closed-door innovation fails (与狼共舞才能锤炼核心技术)
- **P5.3** 卡脖子问题 + 小院高墙 — how US decoupling hits Chinese high-tech
- **P5.4** 全要素生产率 (TFP) + 创新驱动 — the productivity mechanism for cross-陷阱 escape
- **P5.5** 新质生产力 + 三个面向 — Xi-era framing (面向世界科技前沿 + 国民经济主战场 + 国家重大战略需求)

---

# P6 — 服务业开放 + 高质量发展

**L1 macro:** 制造业服务化。生产性服务业。制度型开放。自贸区 / 自贸港。服务业 = 未来 GDP 主引擎。

**L2 sub-arguments:**

- **P6.1** 服务业开放三层次 — 市场开放 + 要素开放 + 制度开放
- **P6.2** 制度型开放 + 自贸区 / 自贸港 — how opening moves from border to behind-border (规则/监管/透明度)
- **P6.3** 生产性服务业 + 制造业服务化 — services as the "黏合剂 / 助推器" of manufacturing upgrade
- **P6.4** 负面清单 + 外资准入 — the mechanism narrowing what foreign services can't do
- **P6.5** 服贸三低一大短板 — 占外贸比重低 / 数字化水平低 / 知识密集型比重低 / 服贸逆差大

---

# P7 — 绿色发展 / 能源 / 环境 / 双碳

**L1 macro:** 绿色 + 循环 + 低碳。三高一低 → 生态文明 → 双碳目标。绿色 = 高质量发展的核心约束。

**L2 sub-arguments:**

- **P7.1** 绿色发展 + 循环发展 + 低碳发展 — the 十八大 3-part strategic framing
- **P7.2** 三高一低 + 粗放型经济 — the old pattern being replaced (高投入 + 高能耗 + 高污染 + 低效益)
- **P7.3** 能源结构失衡 + 化石能源依赖 — the structural problem (煤炭主导 / 油气不足)
- **P7.4** 四个革命 + 一个合作 — the energy transition strategy (消费/供给/技术/体制革命 + 国际合作)
- **P7.5** 五位一体 + 生态文明 — the constitutional framing (经济 / 政治 / 文化 / 社会 / 生态)
