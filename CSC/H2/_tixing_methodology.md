## §0 The universal structure (all 题型 share this) / 通用结构 (所有题型共享)

Every CSC essay has **3 analytical moves**: / 每篇 CSC essay 都有 **3 个分析动作**:

```
1. 立场分析 (Stance analysis) — 论证 你的观点 的正面
2. 平衡分析 (Balance analysis) — 论证 对立面 (真实, 非象征)
3. 比较分析 (Comparison analysis) — 对比 两面, 得出你的立场为何胜出
```

**Golden rule / 黄金规则:** "正 → 反 → 合" (thesis → antithesis → synthesis). Every essay MUST have all 3 moves. Missing any = incomplete.

**How this differs from Western essay writing:** Western essays lead with thesis + reasons. Chinese CSC essays are DIALECTICAL — you must genuinely engage the opposite side, then explicitly compare. The 比较分析 段 is what separates Tier 4-5 from Tier 三.

## §1 是非题 (True/False question)

### Definition / 定义
The stem states a clear position. You must judge **是 (yes) OR 不是 (no)** and defend the judgment. / 题干给明确观点. 判断 是/不是 并辩护.

### Trigger keywords / 触发关键词

- **"…是…"** (X is Y)
- **"…能(够)…"** (X can Y)
- **"在很大程度上(作用)…"** (largely, plays role in)
- **"…可以(难以)…"** (X can/cannot Y)
- **"…应该…"** (X should Y)
- **"…有助(利)于…"** (X helps/benefits Y)
- **"…威胁了(导致了、侵蚀了、改善了、阻碍了)…"** (X threatens/causes/erodes/improves/obstructs Y)
- **"…将、势必、已经、正在…"** (X will / must / already / currently)

### Past-year examples / 历年题例

- 「一党专政下的中国无法根除贪污和腐败问题.」试评论. 【2019】
- 「中美之间的冲突不是必然的, 而是可以避免的.」你在多大程度上同意上述观点? 【2020】
- 「贪腐问题在很大程度上威胁中国社会稳定.」试评论 【2018】
- 「区域发展不平衡将严重阻碍中国的可持续发展.」试评论 【2016】
- 「中国政府已经成功遏制了腐败.」你在多大程度上同意这个观点? 【2022】

### 论证框架 / Argument framework

**立场分析** = 论证题目观点 (同时也是你的观点) 的具体方面

Depending on stem keywords, argue the specific aspect:
- "…是…" 的方面 / "…is…" aspect
- "很大程度(作用)…" 的方面
- "…可以(难以)…" 的方面
- "…有助(利)于…" 的方面
- "…威胁了(导致了、侵蚀了、改善了)…" 的方面
- "…将、势必、已经…" 的方面

**平衡分析** = 直接找 题目观点的对立面, 反驳立场的观点
- Stay tightly on 题目关键词 (don't drift to unrelated factors)
- Introduce via: "有人认为…" / "有不同学者表示…" / 别人身份带出对立方观点

**对立面 mapping / 对立面 映射:**

| 立场关键词 | 对立面 |
|---|---|
| 是 | 不是 |
| 可以 | 不可以 |
| 有助(利)于 | 无助于 / 不利于 |
| 威胁了(导致了、侵蚀了、改善了) | 没有威胁(导致、侵蚀、改善) |
| 将、势必、已经 | 不会、没有 |

**比较分析** = 对比是与非的两面, 看哪一面的影响力更大, 得出与你的观点一致的判断结果
- 建议: 将平衡分析的分论点**逐个驳倒**

### CRITICAL: If you disagree with 题目观点 / 若否定题目观点

**Swap the structure:**
- **立场分析** = 你自己的立场 (即 "不是、不可以、无助于、没有威胁" 这一方)
- **平衡分析** = 题目观点 (即 "是、可以、威胁了" 这一方)

**★ 同意立场与否定立场的答题思路不同 — MEMORIZE this swap.**

## §2 最字题 (Extreme factor question)

### Definition / 定义
判断某因素是否是**共同作用于结果的不同因素中最大/最重要/最关键**的那个. / Judge whether the stated factor is the **strongest** among multiple factors causing a result.

### Trigger keywords / 触发关键词

- "…是达成/导致…(某现象、结果、问题) 的极端因素"
- "…是构成 X 的 **最大/最重要/最根本/最关键**(因素)"

### Past-year examples / 历年题例

- 「国有企业改革是中国经济发展面临的**最严峻**挑战.」试评价 【2018】
- 「能源短缺是中国发展面临的**最大**挑战.」试评论 【2021】
- 「外交政策是影响中国提升软实力的**最大**因素.」试评论 【2023】
- 「依法治国是中国实现国家治理现代化的**最关键**因素.」试评论

### 论证框架 / Argument framework

**★ 同意题目立场 (agreeing X IS the most critical factor):**
- **立场分析** — 分析题目因素 (为什么它是最关键)
- **平衡分析** — 带入 **2 个其它因素** 分析 (显示你了解其他因素但仍认为题目因素更强)
- **比较分析** — 将题目因素与 2 个其它因素**逐个比较**, 突出题目因素是最关键因素

**★ 否定题目立场 (disagreeing — X is NOT the most critical):**
- **立场分析:**
  - ❶ 指出题目因素为什么**不是**关键因素 (指出其局限)
  - ❷ 带入 **1 个** 你认为**比题目因素更重要**的其他因素
  - **注意:** 无需指出它是最关键因素, 只需论证它比题目因素更重要、更突出即可
- **平衡分析** — 分析题目因素 (客观承认它有一定作用)
- **比较分析** — 将你认为的更重要因素与题目因素比较, 说明为什么题目因素**不是**最关键, 为什么你提出的因素**更重要**

### Key insight / 核心洞察

最字题 requires **multi-factor comparison**. 你不能只谈题目因素 — 必须引入其他因素比较. 这就是为什么单一 论证 (只谈题目因素) 会失分.

## §3 因素是非题 (Factor True/False — HYBRID) ★★★ MOST COMMON ★★★

### Definition / 定义
Hybrid of 是非题 + 最字题. 两个关键词之间的联系指向某一因素对结果的作用, 带有 "不同因素作用于结果的辨别" 特征. / Hybrid: judges if a factor causes/underlies a result. Focus is on **causal relationship** between two keywords.

### Trigger keywords / 触发关键词

- "…罪魁祸首"
- "…根源"
- "…重中之重、至关重要"
- "…动力源"
- "…是构成 X 的关键"
- "…(某结果/问题) 主要是…(某因素造成的)"

### Past-year examples / 历年题例

- 「一党专政是中国政治问题的**根源**.」试加以讨论 【2014】
- 「中国的贫富差距, **主要是**经济发展不均衡所造成的.」试讨论 【2016】
- 「城镇化是推动中国发展的**动力源**.」试加以讨论 【2020】
- 「扩大内需是确保中国经济可持续发展的**关键**因素.」试评论 【2022】
- 「贫富差距问题是影响中国社会稳定的**关键**因素.」试评论 【2023】
- 「能源问题是中国环境恶化的**罪魁祸首**.」试评论
- 「中产阶级对于中国社会管理**至关重要**.」试评论 【2024】
- 「**中共政权的合法性是以政绩为基础的**.」你在多大程度上同意此观点? 【2024】

### Non-typical variants / 非典型因素是非题

- 试评价 中国政治腐败的问题**在多大程度上是**改革开放带来的后果? 【2008】
- 中国的社会稳定**在多大程度上取决于**中国的经济发展? 【2010】

### 论证框架 / Argument framework

**★ 同意题目立场 (X IS the root/key):**
- **立场分析** — 分析题目因素是导致 (某结果) 的**根源、关键等**
- **平衡分析** — 以**自身的平衡论证为主**, 辅以其他因素 (其他因素不是必须)
  - ❶ 论证 题目因素**不是**根源、关键等… (重点)
  - ❷ 带入 **1 个**其它因素, 分析其对结果的作用 (辅助)
- **比较分析:**
  - ❶ 比较题目因素的**作用与局限**, 得出 **作用 > 局限**
  - ❷ 比较题目因素和其他因素, 得出 **题目因素 > 其他因素** 的作用

**★ 不同意题目立场 (X is NOT the root):**
- **立场分析:**
  - ❶ 论证 题目因素**不是**根源、关键等… (重点; 说明题目因素对结果的作用**局限**)
  - ❷ 带入 **1 个**你认为的重要因素并分析 (辅助, 不是必须)
- **平衡分析** — 论证 题目因素**是**导致 (某结果) 的根源、关键等 (承认反面)
- **比较分析:**
  - ❶ 比较题目因素的作用与局限, 得出 **局限 > 作用**
  - ❷ 比较题目因素和其他因素, 得出 **其他因素 > 题目因素** 的作用

### Key insight / 核心洞察

因素是非题 **答题以是非题为主, 反驳观点时可带入 1 个其它因素**. 以**自身反驳为主, 其它因素为辅**. This is subtly different from 最字题 — 最字题 requires 2 other factors and heavy comparison; 因素是非题 mostly stays on the题目因素 itself.

**Ethan's Cluster 3 Q5 REFRAME move (党国体制 是 root) — this is a 因素是非题 approach!**

## §4 多大程度题 (Degree question)

### Definition / 定义
Asks: how much / to what degree does A affect / cause / promote / obstruct B? / 判断 A 对 B 的作用程度.

### Trigger keywords / 触发关键词

- ❶ "A **在多大程度上** (推动、提升、阻碍、加剧…) B?"
- ❷ "A **在多大程度上影响** B?"

### Past-year examples / 历年题例

- 中国的崛起**在多大程度上**促进了区域安全? 【2012】
- 「党对军队的绝对领导」**在多大程度上**阻碍中国的政治发展? 【2014】
- 大众民族主义**在多大程度上**影响中国政府处理领土纠纷? 【2018】
- 经济合作**在多大程度上**推进了中国的周边外交?
- 现代化**在多大程度上**促使了中国家庭结构的转型?

### 论证框架 / Argument framework

**❶ TYPE 1 — "A 在多大程度上 (作用了) B?" (single-direction effect)**

You MUST commit to a degree — **较大程度** OR **较小程度** (never hedge to 中等).

| **立场: 较大程度** | **立场: 较小程度** |
|---|---|
| 立场分析: A 对 B 的作用力 | 立场分析: A 作用于 B 的局限 |
| 平衡分析: A 作用于 B 的局限 | 平衡分析: A 对 B 的作用力 |
| 比较分析: 将 A 作用于 B 的正面效果 与 局限对比, 突出正面作用大还是局限大, 界定程度大小 | (same but reversed) |

**❷ TYPE 2 — "A 在多大程度上影响 B?" (asks about IMPACT — single or double-sided)**

**先判断影响是单面的还是双面的:**

| **单面影响** | **双面影响** |
|---|---|
| 立场分析: 分析单面影响 (通常负面) | 立场分析: 先后分析积极影响和消极影响 |
| 平衡分析: 找这一单面影响的对冲因素 | 平衡分析: 客观承认影响不是绝对的, 然后分析影响局限及对冲因素 |
| 比较分析: 将单面影响与对冲因素比较, 看哪方面更突出, 界定作用程度 | 比较分析: ①比较积极影响与消极影响, 明确界定哪个更大 ②比较主体影响和局限, 界定影响程度 |

### Key insight / 核心洞察

**MUST commit to a specific degree word — 较大 / 较小 / 一定. 不要 hedge.** Verdict without degree = automatic Tier 三.

## §5 条件题 (Condition question)

### Definition / 定义
Has fixed 条件—结果 pairing, "因" and "果" direct relationship. Two sub-types: **必要条件题** + **充分条件题**. / Two sub-types: necessary condition + sufficient condition.

### §5.1 必要条件题 (Necessary condition) / Necessary Condition Question

**Meaning:** 缺少了这一条件, 就无法达成其结果. 因此这一条件是必须的、不可或缺的.

**Trigger keywords / 触发关键词:**
- "…**必须**…(条件), 才能…(结果)"
- "…**只有**…(条件), 才能…(结果)"
- "要…(结果), **就必须**…(条件)"
- "要…(结果), **唯有**…(条件)"
- "**如果不**…(条件), **就无法**…(结果)"

**Past-year examples:**
- 中国要取得全面现代化的发展, **就必须**进行政治体制改革 【2011】
- 「中国**必须**确保社会稳定, **才能**使经济持续增长」【2014】
- 中国要提高国际影响力, **唯有**保持高速经济增长 【2016】
- 「中共要维护政权合法性, **就必须**改革现有的政治体系」

**同意题目立场 framework:**
- 立场分析: 题目条件因素对达成预期结果的**重要性、必要性**, 论证其**不可或缺**
- 平衡分析: 论证要达成预期结果, 题目的条件因素**不是必须的**, 按如下层次:
  - ❶ 即使**没有**(题目条件)…, 也能…(达成结果) [直接抽掉题目条件, 依据历史或当下事实论证]
  - ❷ 即使**有**(题目条件)…, 也**不足以**(达成结果)…
    - 1) 题目条件本身有局限, 不足以构成必要条件
    - 2) 不通过题目条件, 借助其它条件、途径也能达成预期结果
- 对比分析: 强调题目条件作为必要条件对预期结果发挥**不可或缺**作用
  - ①题目因素自身局限和其作用对比, 突出其作用对预期结果的重要性
  - ②题目因素与其它因素对比, 突出题目因素所发挥的不可或缺作用

**否定题目立场 framework:**
- 立场分析:
  - ❶ 即使**没有**(题目条件)…, 也能(取得预期结果)… [以客观事实论证]
  - ❷ 即使**有**(题目条件)…, 也**不足以**(取得预期结果)… [局限 + 其他因素]
- 平衡分析: 题目的条件因素对达成预期结果的积极作用
- 比较分析:
  - ①题目因素对于取得预期结果的局限**大于**效益
  - ②其他因素比题目因素对取得预期结果所发挥的作用**更显著**

### §5.2 充分条件题 (Sufficient condition)

**Meaning:** 判断题目中的"充分条件"能否成立 — 即达成某目的或造成某结果, 是否**只需要具备这个单一条件因素即可**.

**通常情况: 单凭一个条件因素往往难以达到一个预期结果, 因此此题大多数情况下采用否定题目观点.**

**Trigger keywords / 触发关键词:**
- "**只要**…**就能**…"

**Past-year examples:**
- 「**废除户籍制度就能**解决人口流动所带来的问题」 试评论 【2012/H1】
- 「**只要全面推进供给侧结构性改革**, 中国**就能**确保经济继续发展」你同意这个观点吗?
- 「**只要完善社会保障制度**, 中国**就能**实现社会的和谐与繁荣」试讨论

**★ 否定题目观点 (default for 充分条件题) framework:**

- 立场分析:
  - ①解释题目条件因素本身对于取得预期结果的**局限性**, 使其不构成充分条件
  - ②解释题目条件因素**不是**取得预期结果的**唯一**条件, 还需要其它重要因素 (带入 1 个其它因素)
- 平衡分析: 客观承认题目条件因素对于取得预期结果的**重要价值 / 积极作用**
- 对比分析:
  - ①比较题目因素对取得预期结果的**作用与局限** (在比较过程中强调题目因素对取得预期结果的**不足**以说明它不是充分条件)
  - ②从性质、作用力、影响范围及程度等方面比较, 指出其它因素的重要性、必要性, 强调题目因素对达成预期结果**不构成充分条件**

## §6 比较题 (Comparison question)

### Definition / 定义
Stem explicitly gives 2 sides to compare. / 题目明确给出两个比较面.

### Trigger keywords / 触发关键词
- "…**大于**…"
- "…**多于**…"
- "…比…**更**…"

### Past-year examples / 历年题例
- 「流动人口给中国带来的社会问题**大于**其对中国经济发展的贡献」你在多大程度上同意上述观点? 【2008】
- 「户籍制度改革给中国社会带来的益处**多于**弊端」试加以讨论 【2011】
- 「中美之间存在的竞争**大于**合作」试评价上述观点 【2019】
- 「经济全球化对中国的发展**利大于弊**」试评价 【2023】

### 论证框架

**通常题目中明确给出比较的两个方面, 立场分析一个方面, 平衡分析另一个方面, 最后比较两个方面并进行程度判断.**

- **立场分析** — 先谈你认为**大的、多的、积极的**一面
- **平衡分析** — 分析**对立的**一面
- **比较分析** — 比较两个方面, 突出你的观点, 做出程度判断

### Key insight / 核心洞察

比较题 CANNOT accept single-side arguments. Both sides MUST be developed. Default framing: acknowledge both, land on your side with clear degree judgment.

## §7 非典型 / 新型题 (Atypical / new question type)

### Definition / 定义
Doesn't fit any of the 6 above, OR combines features of 2 types, OR is a completely new expression.

### Past-year examples
- 「少数民族的管理是近年来中国政府所面对的**棘手问题**」试加以讨论 【2013】 (是非)
- 「中国政府**必须**改变计划生育政策」你在多大程度上同意上述观点? 【2013】 (是非)
- 中国**在多大程度上**能够凭借软实力成为一个世界强国? 【2017】 (是非)
- 「当代中国的主要经济问题**是**由其增长策略所造成的」你在多大程度上同意这个观点? 【华中考题】 (是非)

### 论证框架

**★ 抛去题型的束缚, 回归到题目本身, 立足关键词, 找准题眼**:

- **正面分析** (立场)
- 找其**最直接、最重要的对立面**进行平衡论证
- **最后**根据自己的立场和平衡的各论点进行比较

**结构上保证有"正—反—合"即可.**

## §8 Summary — the 7 题型 at a glance / 7 题型 速查

| # | 题型 | Trigger | Default 立场 | 平衡 approach | 比较 approach |
|---|---|---|---|---|---|
| 1 | **是非题** | X 是/能/可以/有利于 Y | Depends on stem | 直接找对立面 (不带其他因素) | 逐个驳倒对立面 |
| 2 | **最字题** | X 是最大/最关键/最根本 | Usually DISAGREE | 带入 2 个其它因素 | 突出题目因素 vs 其他 |
| 3 | **因素是非题 ★★★** | X 是根源/关键/罪魁祸首 | Depends; often DISAGREE (structural REFRAME to deeper root) | 带入 1 个其它因素 (辅助) | 作用 vs 局限 + 题目 vs 其他 |
| 4 | **多大程度题** | 多大程度… | **较大程度 OR 较小程度** (never 中等) | 正面 vs 局限 (or 积极 vs 消极) | 界定程度大小 |
| 5 | **条件题** (必要 / 充分) | 必须/只要 X 就 Y | Necessary: judge case; Sufficient: usually DISAGREE | Depends on sub-type | 局限 vs 效益; 题目 vs 其他因素 |
| 6 | **比较题** | X 大于/多于 Y | Depends on which side dominates | Analyze opposite side | 突出主张一侧 + 程度判断 |
| 7 | **非典型** | Non-standard | Anchor on stem keywords + find opposite | Direct opposite | 正-反-合 |

## §9 Universal 论证 rules across all 题型 / 所有题型通用规则

1. **每篇必有 3 分析动作**: 立场分析 + 平衡分析 + 比较分析. 缺一 = 不完整.
2. **立场 in ¶1 upfront** — first sentence declares verdict + previews reasons.
3. **平衡 是真实, 非象征**. 一段, 不是一句. 真实承认对立方, 然后解释为什么你的立场仍胜.
4. **比较 是 essay 的高峰** — 逐个驳倒对立面 OR 逐一对比 factors — 这是 Tier 4 vs Tier 三 的分水岭.
5. **术语 精度** > 学者名字. 官方话语 (党国体制 + 使命型政党 + 全过程人民民主 + 中华民族共同体意识 + 塔西佗陷阱 + 政绩困局) 是主要 markers.
6. **数据 + 案例 + 具体日期** = AO1 marks.
7. **跨课题 句** = Tier 4 unlocker.
8. **结论 restates 立场** — 不要 trail off.

## §10 Common failures across 题型 / 各题型通用失误

Based on Ethan's Cluster 1-3 tests + Extended Q1-Q3:

1. **单面 论证** — 只谈立场方, 无平衡. → Tier 三 天花板
2. **平衡 是 token 一句** 而非 full paragraph → Tier 三 天花板
3. **缺 比较分析** (直接从平衡到结论, 无对比) → Tier 三 天花板  
4. **多大程度 未 commit degree** (说 "有效" 而非 "较大程度") → Tier 三
5. **最字题 只谈 题目因素** (未带入 2 其他因素) → Tier 三
6. **因素是非题 未 REFRAME** (未识别题目因素是 root 还是 派生) → Tier 三
7. **比较题 单侧发展** (只谈自己主张一侧, 平衡侧薄弱) → Tier 三
8. **立场 not upfront** — 定义漫游 3 段才 declare → Tier 三 automatic

## §12 是非题 — Full blueprint / 完整蓝图

### 12.1 Paragraph count / 段数

**7 段, ~1000-1100 字, 40-45 min:**

```
¶1  引言 (Introduction)             ~80-100 字
¶2  立场分析 分论点 1               ~150-180 字
¶3  立场分析 分论点 2               ~150-180 字
¶4  立场分析 分论点 3               ~150-180 字  (可选; 3 个更强)
¶5  平衡分析                        ~150-180 字
¶6  比较分析 (peak paragraph)       ~250-300 字  ← THE Tier 4/5 unlocker
¶7  结论                            ~80-100 字
```

### 12.2 Each paragraph's function + template / 各段功能与模板

**¶1 引言** — 3 elements: (1) 重述题目关键词 (2) 明确立场 (3) 预告 3 分论点 + 平衡方向

> "近年来, [题目现象/背景 1 句]. 笔者 **不同意** [题目论断]. 本文将从三方面论证: 首先 [分论点 1], 其次 [分论点 2], 再次 [分论点 3]. 尽管有观点认为 [平衡方向 1 句], 但综合比较可见立场立论明显胜出."

**¶2/3/4 立场分析 分论点** — 5 elements each: (1) 主题句 (2) 机制展开 (3) 数据锚 (4) 具体案例 (名+年+结果) (5) 小结回到 verdict

> "**首先, [分论点 1 topic sentence].** [机制: A → B → C 因此 D]. 数据显示, [具体数字 + 年份]; **[案例名 (职位, 年, 结果)]** 印证这一逻辑 — [1 句意义]. **由此可见, [分论点 1 支持立场]**."

**¶5 平衡分析** — 3 elements: (1) 过渡引入 (2) 真实呈现对立方 (3) 收尾为 ¶6 铺垫

> "**然而, 不可否认**, [对立方立场简述]. 有观点主张 [对立方分论点 1], 具体表现: [对立方机制 + 数据 + 案例]. 类似地, 亦有学者指出 [对立方分论点 2]. 从表面上看, 上述论证具有一定合理性. **然而, 深入分析比较之下, 上述论据均可反驳**."

**¶6 比较分析 (THE peak)** — see §12.3 model below

**¶7 结论** — 3 elements: (1) 综上所述 (2) 重申立场 (3) 升华 / 跨课题

> "**综上所述**, [题目论断] 不成立. 从 [立场核心论证] 观之, [核心结构性判断]. 更深层地, **跨课题至 [经济/外交/社会]**, [1 句跨课题机制] — 印证 [立场核心]. **因此, 本文重申立场**: [verdict]."

### 12.3 MODEL 比较分析 段 / 模型段

Stem: 「**一党专政下的中国无法根除贪污和腐败问题.**」【2019】立场: 同意

> **综合以上分析, 两方面比较可见立场立论明显胜出.**
>
> **其一,** 平衡方指出习时代反腐运动取得实质成效 — 打老虎拍苍蝇 + 巡视组 + 国监委 (2018) + 监察法 + 留置 制度化, **12 年立案省部级 553 人 + 厅局级 4.8 万人 (2012-2024)**. **然而, 数据本身反证腐败之深** — 若腐败非结构性, 何以需 500 万党员受处分才触及表层? 且反腐呈现明显派系性 — 周永康 (江派)、令计划 (团派)、孙政才 (习潜在竞争者) 落马, 而习核心圈完整保留. 反腐沦为政治工具, 非中立制度反腐. **平衡方数据反成立场佐证**.
>
> **其二,** 平衡方主张民法典 (2020, 1,260 条) + 立案登记制 (2015) 显示法治进步 → 反腐制度化. **然而, 此点忽略 18届4中天花板** — "党的领导是社会主义法治最根本的保证". 无独立司法 + 无宪法法院 + 政法委监督法院 → 法治结构性无法约束党权 → 一把手 (陈良宇/薄熙来/孙政才/周永康均一把手落马) + 灯下黑 (公安部禁毒局四局长 2014) 现象持续. 技术性法治存在, 结构性反腐不可能.
>
> **其三,** 平衡方援引苏东巨变教训, 主张中共走制度渐进更稳. **此点承认合理**, 但恰恰印证立场 — CCP 因 Gorbachev glasnost 1985 → 苏共崩溃 1991 教训, 结构性拒绝独立媒体 + 反对党 + 独立司法, 而这些正是根除腐败所需的权力监督基础设施. **苏东教训本身决定中国无法根除腐败**.
>
> **综合三点比较, 平衡方论据均无法撼动立场核心 — 一党专政结构性无外部权力监督 → 根除腐败结构性不可能. 立场立论稳固.**

### 12.4 If DISAGREE with 题目 — swap structure / 若不同意题目, swap 结构

Per official guide §7.1 — swap ¶2-4 (立场分析) 与 ¶5 (平衡分析) 内容:
- 立场分析 (¶2-4) = 你的立场 (即 "不是/不可以/无助于/没有威胁" 这方)
- 平衡分析 (¶5) = 题目观点 (即 "是/可以/威胁了" 这方)
- 比较分析 (¶6) = 逐个驳倒题目方 分论点

**Paragraph structure same, content swapped.**

### 13.3 MODEL 比较分析 段

Stem: 「**权力不受制约 是 当代中国治理面临的最根本挑战.**」立场: 同意

> **综合以上分析, 通过 系统比较 三大治理挑战, 可见 权力不受制约 确为最根本挑战.**
>
> **其一, 权力不受制约 vs 央地财政失衡.** 平衡方指出 央地失衡 (1994 分税制导致 地方 财权 vs 事权 倒挂 → 土地财政 + LGFV 隐性债务 IMF 估计 $9 万亿 2024) 是当前最紧迫挑战. **然而**, 央地失衡本质上 是 **不受制约党权** 的 派生表征 — **周黎安 晋升锦标赛** 论指出 地方官员 在 GDP 目标下 押注 土地财政 + LGFV, 但根本原因 是 中央 单向 干部考核权 (党管干部) 未受制约 → 造成 短期政绩激励扭曲. 若 权力受制约 (独立预算审查 + 民选地方问责), 央地失衡问题 本质可解. **因此 央地问题 = 派生, 权力问题 = root**.
>
> **其二, 权力不受制约 vs 中产崛起+政绩困局.** 平衡方援引 **亨廷顿 政绩困局** — 中产扩大 (**4% 2001 → 42.3% 2024**) → 诉求从物质到政治问责 → Mode 1 无法满足 → 塔西佗陷阱 → 政治合法性侵蚀. **然而**, 亨廷顿陷阱 之所以 无出口, 恰恰因为 权力不受制约 → CCP 无法 授予 Mode 2 (选举 + 独立媒体 + 反对党) 而 不威胁 党的领导. 若 权力受制约, 亨廷顿陷阱 可通过 政治开放 疏导 (韩国 1987 + 西班牙 1975 民主转型 就是 疏导路径). **中产 挑战 = mechanism, 权力 挑战 = 根源**.
>
> **综合两点比较, 央地 + 中产 两大挑战 均是 权力不受制约 这一 root 的派生表征. 阿克顿 定律 '权力使人腐败, 绝对权力绝对腐败' 正是 中国治理 一切困境的诊断源头. 因此立场立论稳固.**

```
¶5  平衡分析 影响 非绝对 + 对冲因素        ~150-180 字
¶6  比较分析 ①积极 vs 消极 ②主体 vs 局限   ~280-320 字  ← peak
¶7  结论 (界定 主导影响 + 程度)            ~80-100 字
```

### 15.2 Template 关键差异

**引言 must commit degree:**
> "笔者认为, [A] **在较大程度上** [作用/影响] [B]. 本文将从三方面 论证 A 的主导作用力, 然后 平衡分析 A 的局限, 最后比较正面效果与局限, 界定 **较大程度但非完全** 的判断."

### 15.3 MODEL 比较分析 段

Stem: 「**自 2014 以来, 中国的网络治理体系在多大程度上有效维护了国家的意识形态安全?**」立场: **较大程度但非完全**

> **综合以上分析, 通过 系统 比较 正面效果 与 局限, 可见 中国网络治理体系 在较大程度上但非完全 维护了意识形态安全.**
>
> **其一, 正面效果 vs 结构性 局限.** 立场方指出 2014 分水岭 后 (中央网络安全和信息化领导小组 + 网信办 + 网络主权论述) 建立了 **全球最完整 4 层控制系统** (防火长城 + 国内平台 微信月活 13 亿 + 网信办 内容审查 + 算法治理 2022 + AI 治理 2023 + 实名认证 2017 + 国家网络身份认证 2025.7.15) + 6 项法律里程碑. 这些技术能力真实且领先西方 — 谷歌 2010 退出 + ChatGPT 2023 封禁 + 国产 文心一言/通义千问/Kimi 兴起. **然而, 平衡方 2022 白纸 breach 显示** 高强度民怨 + 突发危机 (乌鲁木齐火灾) 仍能 通过 微信群 + Telegram 加密通信 跨城市组织, 最终迫使 Zero-COVID 政策逆转. 正面 vs 局限比较: **技术性维稳 层面 较大程度有效 (数据支持); 结构性 breach 层面 有内生边界 (案例支持)**.
>
> **其二, 主体影响 vs 长期对冲因素.** 立场方指出 短期 意识形态安全 得以维护 — 2019 香港反修例 + 2022 白纸 均 未成 政权颠覆. **然而**, 长期对冲因素累积: (1) 代际差异 — 年轻代 翻墙率 上升; (2) 跨境信息 (留学生 + 海外华人 + 跨境企业) 持续渗透; (3) AI 新前沿 — 生成式 AI 不断产生 不受管控 surface; (4) 塔西佗陷阱 — 李文亮 Wall 2020 + 白纸 案例 累积 政府 长期 公信力侵蚀. 主体正面效果 短期胜, 长期 对冲因素 累积.
>
> **综合两点比较, 界定 较大程度但非完全 — 短期 意识形态安全 技术能力全球领先; 长期 结构性 breach + 塔西佗累积 有内生边界. 因此 网络治理有效但非完全, '较大程度' 是最精确判断.**

### 16.1 Paragraph count / 段数

### 16.2 MODEL 比较分析 段 (充分条件题)

Stem: 「**只要完善社会保障制度, 中国就能实现社会的和谐与繁荣.**」立场: 不同意

> **综合以上分析, 通过 全维度比较, 可见 完善社会保障制度 是 化解社会矛盾 重要工具 但 不构成 充分条件.**
>
> **其一, 从性质与作用力比较.** 立场方指出 社保制度 已达 世界最广覆盖 — 社保卡 **13.68 亿 (96.8% 普及, 2023)** + 医保覆盖率 96%+ + 人均寿命 **78.6 岁**. 数据显示 Mode 1 (服务) 极致优化. **然而, 从作用力性质看**, 社保覆盖 是 **物质需求 层面** 的化解, 无法触及 **精神与政治需求 层面**. 亨廷顿 政绩困局 精确诊断: 中产扩大 (**4% 2001 → 42.3% 2024**) 后 诉求 从物质 升级到 政治参与 + 法治 + 独立媒体. 社保完善 **越强, 中产升级诉求 越显性** — 无法通过 更完善社保 反向缓解.
>
> **其二, 从影响范围比较.** 立场方指出 完善社保 能 有效 化解 底层 群体性矛盾 (养老 + 医疗 + 失业). **然而**, 影响范围 局限于 **物质层面 群体性事件**. 结构性事件 (2015 709大抓捕 + 2020 香港国安法 + 2022 白纸运动) 均 非 社保 问题 — 是 **政治参与 + 身份认同 + 治理透明度** 问题, 属 完善社保 覆盖范围 之外. 因此 影响范围 局限.
>
> **其三, 从程度维度比较, 需引入 其他重要因素.** 除社保之外, **政治参与渠道 制度化 + 法治体系 完善 + 央地财政 平衡 + 民族政策 精细化** 均是 化解社会矛盾 的必要条件. 平衡方 主张 社保 完善 单独即可, 但 上述四项 均是 与 社保 平行 的必要因素, 缺一不可.
>
> **综合三点比较, 完善社保制度 是 化解社会矛盾 必要条件 之一, 但 非 充分条件. 单凭社保 无法 实现 和谐与繁荣, 需 与 政治参与 + 法治 + 央地 + 民族 政策 协同. 因此立场 立论稳固.**

## §17 比较题 — Full blueprint / 完整蓝图

### 17.1 Paragraph count / 段数

**7 段, ~1000-1100 字, 45 min. 整篇 essay 本身就是 比较 — ¶6 比较分析 是 明确判决段.**

```
¶1  引言 (声明: X > Y OR X < Y 立场)            ~80-100 字
¶2  立场分析 你主张一侧 分论点 1                ~150-180 字
¶3  立场分析 你主张一侧 分论点 2                ~150-180 字
¶4  平衡分析 对立面 分论点 1                    ~150-180 字
¶5  平衡分析 对立面 分论点 2                    ~150-180 字
¶6  比较分析 (两方 系统对比 + 程度判决)         ~280-320 字  ← peak
¶7  结论                                        ~80-100 字
```

### 17.2 MODEL 比较分析 段

Stem: 「**「党领导下的技术性治理」比「西方式政治性问责治理」更能保障中国长期社会稳定与发展.**」立场: **部分同意** (短期 Mode 1 胜, 长期 Mode 2 不可替代)

> **综合以上分析, 通过 两方系统比较, 可见 需 时间维度 partition — 短期稳定 层面 技术性治理 胜, 长期稳定 层面 政治性问责 不可替代.**
>
> **其一, 短期稳定 维度: 技术性治理 明显胜出.** 中国 Mode 1 系统 (12345 政务热线 + 接诉即办 三率 **90%+** + 一网通办 + 最多跑一次 + 网格化) 全球顶级. **接诉即办 北京 2019 陈吉宁 主导** — '有一办一 → 接诉即办 → 主动治理 → 未诉先办' 递进, 累计接诉数千万件. 相较西方问责治理: 选举周期短视 (4-8 年 周期) + 政策震荡 (Trump 2016-20 + Brexit 2016) + 决策慢 (基础设施 + 疫情响应 均慢于中国). **短期维度 技术性治理 数据 + 案例 全面胜出**.
>
> **其二, 长期稳定 维度: 政治性问责 结构性不可替代.** 长期看, Mode 2 缺失 → 亨廷顿 政绩困局 (中产 **4% → 42.3%**) → 诉求无出口 → 累积 → 塔西佗陷阱 (**2008 三聚氰胺 15+ 年不信国产奶粉** + **2020 李文亮** + **2022.11 白纸运动 迫使 Zero-COVID 逆转**) → **维稳费 2019 = 1.4 万亿 超军费**. 历史比较: **1987 韩国** (全斗焕 → 卢泰愚 允许直选) + **1975 西班牙** (Franco 死 → 民主转型) 均是 强人政权主动允许 Mode 2 → 长期稳定 + 经济持续增长. 中国 结构性拒绝此路径 (**苏东巨变 教训** — Gorbachev 1985 → 苏共 6 年崩溃 1991), 承担 长期塔西佗累积风险. **长期维度 政治性问责 胜**.
>
> **其三, 关键区分: 缺陷性质 不同.** 西方 Mode 2 缺陷 是 **周期性 + 可修复** (选举纠错); 中国 Mode 1 结构性缺陷 是 **累积性 + 不可逆** (塔西佗陷阱). **因此 长期稳定 层面, Mode 2 缺陷 是 管理型问题, Mode 1 缺失 是 系统性风险**.
>
> **综合三点比较, 部分同意题目 — 短期 技术性治理 胜, 长期 政治性问责 不可替代. 中国 走 独特路径, 承担 短期稳定 与 长期风险 的结构性 tradeoff. 立场 立论 稳固.**

## §18 非典型 / 新型题 — Full blueprint / 完整蓝图

### 18.1 Paragraph count / 段数

**5-6 段基本 (可扩至 7), ~900-1000 字, 40-45 min. Structure 保证 "正—反—合".**

```
¶1  引言 (识别 stem 关键词 + 声明立场)           ~80-100 字
¶2  立场分析 (正面) 分论点 1                     ~150-180 字
¶3  立场分析 (正面) 分论点 2                     ~150-180 字
¶4  平衡分析 (直接对立面)                        ~150-180 字
¶5  比较分析 (正-反-合)                          ~250-300 字  ← peak
¶6  结论                                         ~80-100 字
```

### 18.2 Key rule / 关键规则

**"抛去题型的束缚, 回归到题目本身, 立足关键词, 找准题眼."**

- 找 stem 中 最主要的 概念对 (e.g., "少数民族管理" vs "棘手问题" — 是非维度)
- 找 直接对立面 (无需引入其他因素)
- 保证 结构 有 正-反-合

### 18.3 MODEL 比较分析 段

Stem: 「**少数民族的管理是近年来中国政府所面对的棘手问题.**」【2013】 立场: 同意 (确为棘手)

> **综合以上分析, 通过 系统比较, 可见 少数民族管理 确为 中国政府 近年 棘手问题, 结构性无 简单化解.**
>
> **其一, 表面成效 vs 结构性张力比较.** 平衡方指出 CCP 民族政策 表面 有真实成就 — 1984 民族区域自治法 制度框架 + 西部大开发 (2000+) + 援疆援藏干部体系 + 中华民族共同体意识 (习 2014.5 首提 第二次中央新疆工作座谈会, 2017 19大 入党章) + 基本公共服务均等化 覆盖 民族地区. **然而, 表面 vs 深层比较**: 5 层少数民族问题 (政治自主 + 文化语言保护 + 宗教自由 + 经济公平 + 党视角三股势力 安全威胁) — CCP 只能化解 第 4 层 (经济), 前 3 层 结构性 无法完全化解 因 **党国体制** 不能授予 真正政治自主 + 独立宗教组织 + 完全语言保护. 表面成效 vs 结构性张力 —**张力 无法通过 policy iteration 消除**.
>
> **其二, 政策工具 vs 反弹效应比较.** 平衡方主张 第二代民族政策 (identity dissolution 通过 中华民族共同体意识) 是 化解 identity 张力 的创新工具. **然而**, identity 不能 仅由 discourse 塑造 — **教培中心 ~100 万+ (2017-2024)** + **西藏 自焚 150+ (2009-13)** + **2020 内蒙古 蒙古语教学抗议** + **2019-20 香港 反修例 + 国安法** — 强制同化 制造反弹 + 国际成本 (**2021 US Uyghur Forced Labor Prevention Act** + **2022 UN 人权专员报告**). 政策工具越强 → 反弹越强 + 国际成本累积 → 长期治理成本 上升.
>
> **综合两点比较, 少数民族管理 结构性 无法通过 政策工具 完全化解, 因根植于 党国体制 不能授予自主 vs identity 政治性诉求 的内生张力. 苏东巨变 教训 (苏联 ethnic republics 1991 分离) 决定 CCP 不能开放此路径. 因此 少数民族管理 确为长期棘手问题, 立场 稳固.**
