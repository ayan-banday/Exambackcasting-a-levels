## §3 Critical term distinctions — DON'T MIX / 关键术语区分 — 不要混

### 党政关系 family / 党政关系 家族

| Term / 术语 | Era / 时代 | Substance / 实质 |
|---|---|---|
| **一元化** | Mao 1949–78 | Party = State (totalist; State is empty shell) / 党即国家 |
| **党政分开** | Deng 1980–89 (FAILED) | SEPARATION attempt; failed after 1989 / 分离 (失败) |
| **党政机构并列** | 江胡 1989–2012 | Parallel institutions, ambiguous leadership / 并行机构, 模糊领导 |
| **党政分工** | Xi 2013+ | Division of labour, EXPLICIT Party leadership / 分工, 明确党的领导 |

**Xi's defining slogan / 习的定义口号:** "**只有党政分工, 没有党政分开**"

### 法治 family / 法治 家族

| Term / 术语 | English / 英文 | What it means / 含义 |
|---|---|---|
| **法治** | Rule **OF** law | Law SUPREME, constrains ruler / 法律最高, 约束统治者 |
| **法制** | Rule **BY** law | Law is INSTRUMENT of ruler / 法律是统治者工具 |
| **党主法治** | Party-supremacist rule of law (**Western critical label**) | "Party rules OVER rule of law" — accusation / 西方批判标签 |
| **党导法治** | Party-led rule of law (**Chinese self-label**) | "Party guides rule of law" — Xi's framing / 中国官方自称 |

### 权力分立 / 权力分工

| Term / 术语 | Context / 语境 | Meaning / 含义 |
|---|---|---|
| **三权分立** | Western (US, UK) / 西方 | Separation: 行政/立法/司法 co-equal, mutual checks / 行政/立法/司法 同等, 互相制约 |
| **三权分工** | Chinese / 中国 | Division of labour: 决策 (党+人大) / 执行 (国务院) / 监察 (国监委+纪委合署) — all under Party / 决策/执行/监察 — 党下分工 |

### 一把手 vs 灯下黑 — different concepts / 不同概念

- **一把手** = top boss at each level (省委书记, 市委书记, etc.) — STRUCTURAL problem (top untouchable from within his jurisdiction) / 每级最高领导 — 结构问题
- **灯下黑** = enforcers themselves can be corrupt — OPERATIONAL problem (2014 公安部禁毒局四局长 took drug trafficker bribes) / 执行者本身腐败 — 运营问题

**Use BOTH in any 反腐 limit discussion / 任何 反腐 局限讨论用两个。**

### 央地关系 vs 党政关系 — TWO DIFFERENT AXES / 两个不同轴线

- **党政关系** = vertical axis: Party vs State institutions / 纵向轴: 党 vs 国家机构
- **央地关系** = horizontal axis: Central vs Local levels / 横向轴: 中央 vs 地方层级
- **DON'T conflate.** Q4 stems about 三权分工 / 总书记 / 常委 = Axis 1. Q stems about 中央 / 地方 / 分税制 / LGFV = Axis 2.

### 政绩困局 / 塔西佗陷阱 / 阿克顿定律 — different concepts / 不同概念 (causal chain) / (因果链)

```
阿克顿定律 (power corrupts) — diagnostic frame for centralisation
       ↓
政绩困局 / 亨廷顿陷阱 (good 政绩 → 中产 → demands → can't satisfy)
       ↓
塔西佗陷阱 (trust collapse, irreversible)
```

**Memorize as a CHAIN, not synonyms / 背为因果链, 不是同义词。**

## §5 Default 立场 cheat sheet per 题型 / 默认立场 速查表

| 题型 / Stem type | Default verdict / 默认立场 | Anchor / 锚点 |
|---|---|---|
| **因素是非题** "X 是 合法性 的 基础" | **DISAGREE** | 政绩 > 意识形态; substitutability test |
| **因素是非题** "经济增长 / 政绩 是 最 重要" | **DISAGREE** | 亨廷顿 trap — 好政绩 also erodes |
| **因素是非题** "完善 X 是 化解 民众诉求 根本途径" | **DISAGREE** | Mode 1 vs Mode 2 — technical ≠ political solution |
| **因素是非题** "完善的法治体系 是 制度反腐 前提" | **AGREE** | linkage works in this direction |
| **条件题** "X 必须 改革 才能 实现 治理现代化" | **DISAGREE** | structural lock; 苏东巨变 lesson; incremental WITHIN architecture is possible |
| **是非题** "中央政府 对 地方治理 有 充分控制" | **DISAGREE 较大程度** | 碎片化威权主义 (Lieberthal-Oksenberg) |
| **是非题** "党国体制 能 有效 应对 治理挑战" | **PARTIAL** | 集中力量办大事 (短期) + 自我纠错 失败 (长期) |
| **是非题** "X 法治思想 推行 将实现 真正 法治" | **DISAGREE** | 党导法治 ≠ 法律主治; 18届4中 ceiling |
| **是非题** "民主集中制 为 治理 提供 充分自我纠错" | **DISAGREE** | structural lock; 苏东巨变; 不可逆 cases (大跃进, 一胎化, Zero-COVID) |
| **是非题** "X 反腐 能 有效 遏制 腐败" | **DISAGREE** | 治标不治本; 制度反腐 受 党国体制 限制 |
| **是非题** "高压反腐 是 改善治理质量 最有效 手段" | **DISAGREE** | 治理质量 multi-dimensional; 不作为 counter-effect; 综合改革 更有效 |
| **最字题** "X 是 最大 / 最根本 挑战" | DEPENDS — apply **解决难度 axis** | 结构性 > 技术性; deeper root is 不受制约权力 / 党国体制 |
| **程度题** "X 多大程度 有利于 Y" | Commit to **高 / 较大 / 一定 / 较小** | **NEVER hedge to 中等**. For 国监委 → 制度反腐: 较大程度 |
| **比较题** "习 X 比 江胡 Y 更能 保障 长期稳定" | **PARTIAL** | execution yes (习胜), correction no (江胡略胜) |

**Default move catalog / 默认动作目录:**
- "Most effective" / "最有效" → **DISAGREE** (almost always)
- "Most fundamental" / "最根本" → apply 解决难度 axis; deeper root is 不受制约权力
- "Most severe" / "最严峻" → DEPENDS; deeper root usually 不受制约权力 / 党国体制
- "Sufficient to..." / "充分..." → **DISAGREE** (almost always for governance)
- "Will achieve real..." / "实现真正..." → **DISAGREE** (almost always for governance reform)
